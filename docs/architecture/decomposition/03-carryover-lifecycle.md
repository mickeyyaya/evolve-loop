## 1. Context

`state.json:carryoverTodos[]` is the memory the next cycle's planner reads: the router prompt's 20-slot `## Carryover todos from previous cycles` section (phase_advisor.go:842-863). Five producers mint into it — the failure P0 (failure_learning.go:158-161), the judgment P1 (judgment_lesson.go:102-105), the promoted defect (failure_learning.go:779-793, an export with zero production callers), the memo file (carryover_merge.go:74-80) and the OPEN audit prescription (prescription_carryover.go:95-101) — with three dedupe/retire semantics that coexist undocumented: the ID-only persist-time union (:614-622, alloc.go:115-116), the fingerprint-first mint admission (:745-752 and its hand copy :776-779), and the ID+fingerprint PASS-closeout retirement ship applies over raw entries (:678-711 ← postship.go:83). The 2026-08-10 flood (124 of 254 entries were per-cycle re-mints, :640-642) and the cycle-1538 resurrection (carryover_triage_retire.go:5-19) were both drift between siblings nobody owned.

The lifecycle's persist has two branches with different semantics (:556-562 legacy whole-state `WriteState`, which drops unmodeled keys per cyclestate/state.go:11-12; :568-571 the serialized RMW that merges ONLY `FailedAt` and `CarryoverTodos`), and the RMW branch is driven by no core test — every existing one uses `fakeStorage`, which has no `UpdateState` (orchestrator_test.go:50-59). Six hand-written `[orchestrator] WARN …` lines (failure_learning.go:560, :572; carryover_merge.go:50, :56; prescription_carryover.go:69, :75) have no code, no owner and no test pinning their text (grep 2026-09-13: the only `prescription-carryover` mention in a test is a comment, prescription_carryover_test.go:4). The priority vocabulary is spelled five times in two vocabularies (`"P0"` :729 and as a literal :786; `"P1"` judgment_lesson.go:32; `"high"` prescription_carryover.go:98; `"medium"` carryover_merge.go:72) and given meaning only by the advisor's rank table (phase_advisor.go:821-836); `"PRESCRIPTION: "` is spelled in two packages with a stale cross-reference (prescription_carryover.go:15 cites defect_ledger.go:181, actual :231); the in-cycle `now+30d` stamp is spelled twice (carryover_merge.go:62, prescription_carryover.go:81); the fingerprint regex (:636) and the two Action spellings it normalizes (:761, :775) live in different functions. The closeout ORDER — memo merge → prescription merge → triage retire → persist — is a comment (cyclerun.go:329-335, "Ordering is load-bearing").
