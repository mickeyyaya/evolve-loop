## Purpose

`internal/router` is the deterministic phase-routing kernel. It digests the artifacts each phase writes into `RoutingSignals` (`Digest`), picks the next phase (`Route`), clamps the advisor's whole-cycle plan to the integrity floor and to each phase's model guardrails (`ClampPlanToFloorWith`, `ClampPlanModelRouting`), routes ship failures to a recovery phase (`Recover`), and answers "should this phase run" for self-skipping phases (`PhasePolicy`). The discipline throughout is "model proposes, kernel disposes".

## Design

- **Leaf package.** `core` imports router, so router imports neither `core` nor `modelcatalog`. Phase names and verdicts cross as plain strings. Core shapes are mirrored as plain data: `Blocker` mirrors `core.ShipError`, `CarryoverTodo` mirrors `core.CarryoverTodo`, and `projectRootFromWorkspace` inverts `core.RunWorkspacePath`. The `Proposer` and `Planner` interfaces live here and are implemented in core. The catalog lookup is injected into `ClampPlanModelRouting` as a function.
- **No environment reads.** Every dial arrives in the injected `config.RoutingConfig`; `config.Load` is the sole env interpreter. `TestRouter_NoEnvReads` walks the package AST for `os.Getenv` calls, so comments and string literals do not trip it.
- **Route is ordered rules, clamp last.** Rule 0: a retrospective defers to `failureadapter.Decide` (the same mapping as the orchestrator's `decideAfterRetro`), then applies the advisor's failure proposal above it. Triage `FAIL`, or an explicit empty `top_n`, ends the cycle because nothing downstream is authorized. Audit `FAIL` diverts to a learning phase: `policy.json:failure_floor` (`AuditFailRoutesTo`) is the one surface when set and supersedes the deprecated enable chain. Everything else walks the effective order (`Cfg.Order` when set, else `canonicalOrder`, so a registry-less config behaves as before).
- **`shouldRun` precedence.** Mandatory (an `EnableOff` is clamped back on) > conditional pin > unavailable-phase drop > the advisory plan (at Stage ≥ Advisory with a plan) > enable flag and content trigger under the insertion cap. On the plan path: a declarative `skip_when` gates the plan for non-floor phases; a plan that runs an operator-disabled phase records `floor-overrides-enable-off`; and the cap still applies to `EnableContent` non-floor phases. An operator-forced (`EnableOn`) plan phase is cap-exempt.
- **Advisor-only context.** `RouteInput` carries environmental fields that only the advisor's prompt reads: `BenchedCLIs`, `UnavailablePhases`, `GoalText`, `CarryoverTodos`, `Catalog`, `OnDemandPhases`, `LastReason`, `Lessons`, and the bridge launch fields (`Workspace`, `ProjectRoot`, `ActiveWorktree`, `Cycle`, `Env`). Pure `Route` ignores them, which keeps it deterministic. `Catalog` and `OnDemandPhases` travel together because the menu and the index of what is off the menu are two halves of one statement. `ActiveWorktree` is required under fleet mode because the tmux driver refuses an empty worktree.
- **Plan wire format.** The advisor emits, and callers serialize, a bare JSON array of `PhasePlanEntry` (`plan.Entries`), never the `PhasePlan` wrapper; that is why `Entries` has no json tag. `PhasePlanEntry.CLI`/`Tier` are `omitempty`, so a plan that never sets them marshals byte-identically to the earlier wire form. `MintSpec.Description`/`WhenToUse` reuse `phasespec.PhaseSpec`'s json keys so the minter threads them through without translation. `MintSpec.WritesSource` is tri-state so an omitted value takes the safe minted default while an explicit `false` stays a read-only opt-out.
- **The floor clamp.** `ClampPlanToFloorWith` enforces two implications: `reach(ship) ⇒ build ∧ audit ∧ (tdd unless the TDD pin releases it)` and `run(build) ⇒ audit ∧ ship`. It only completes the run set, never weakens it, and records one `Clamp` per forced phase. Before the floor it drops unknown and unavailable entries (`dropUnknownPhases`). With a validated unified commitment it lifts `plan-review` and `build-planner` to the deep tier (`unified-commitment-planning-tier`). `IntentRequired` forces intent on every plan shape, not only ship-bound ones, because the static path's `NextFromStart` does the same. `ClampPlanToFloor` is the default-floor wrapper (`DefaultShipFloor`), kept identical to the original behavior so `floor_test.go` stays the default-preserving proof. The clamp is a plan-level prefilter: it forces audit to run, while the ship phase's audit binding (tree SHA, EGPS `red_count==0`) and `SpineSatisfiedUpTo` guarantee audit passed.
- **The model-routing clamp.** `ClampPlanModelRouting` re-validates each entry's proposed `{cli, tier}`. A tier below the envelope minimum is clamped up and a tier above the maximum is clamped down, CLI untouched. Other violations go through the existing `policy.ValidatePin` and then the injected catalog lookup; a failure empties the pair to `{cli:"", tier:""}`, which the resolver reads as "use the profile default". A profile without an envelope gets `universalTierFloor` (`{Min: balanced, Max: top}`), so the floor is universal while envelope-less profiles keep every tier up to `top`. `RejectionsFromClamps` renders clamps into the `advisor-rejections.json` shape; the `Forced` text names "floor" or "ceiling" because its consumers grep for those words.
- **Digest is the only on-disk shape reader.** It fails open: a missing or corrupt artifact yields `Present:false` and never forces an optional phase. It accepts both `handoff-build`/`handoff-builder` and `handoff-audit`/`handoff-auditor`. It unwraps the ADR-0050 payload envelope (`unwrapPayload`) and falls back to the flat form. It folds each handoff's top-level `signals` into the generic plane (`foldGeneric`: bare keys get the phase prefix, dotted keys are kept, last write wins) and lifts each completed phase's report-sentinel failure block into `<phase>.failure_class` and `<phase>.defect_count` (`foldFailureSentinel`, via `phasecontract.ReadFailureBlock`).
- **Fallbacks when handoff JSON is absent.** Scout reads `scout-report.md` (presence, `goal_type:`, `deliverable_kind:`); triage reads `triage-report.md` (`cycle_size_estimate:`, `deliverable_kind:`); build reads `changedpkgs.FromGitChecked(root, "HEAD")`, so `FilesTouched` is a package count, not a file tally; audit reads `acs-verdict.json` through the same `extractAudit`. `readReportFallback` is the one ladder the two report fallbacks share. The header keys are exported constants (`HeaderGoalType`, `HeaderDeliverableKind`, `HeaderCycleSize`) so `TestPersonaTemplates_CarryTheHeaderLines` pins the personas to the exact words the kernel reads.
- **Triage commitment.** `triage-decision.json`'s `top_n` array gives `CommittedCount`; its `unified_projection` (valid only as `small|large` with at least two members) gives `UnifiedSize`/`UnifiedMemberCount`. `commitmentKnown` separates an explicit empty `top_n` from a missing decision.
- **Conditions are Specifications.** `evalCondition` resolves a field path against the typed structs first, then the generic plane. A severity field accepts a word value (`"HIGH"`) through `ParseSeverity`. Generic bools render as `"true"`/`"false"` so `eq`/`ne` work. `evalCondRule` ANDs a rule's head clause with its `And` clauses (ADR-0099).
- **Strategies.** `StaticPreset` is triggers plus spine. `LLMProposal` asks a `Proposer`, then defers to the same `Route`; a nil or failed proposal degrades to the static decision. `Select` picks once at the composition root. Both delegate `Recover` to the pure chain.
- **Recovery is a Chain of Responsibility** (`recoveryChain`), first match wins, terminal catch-all to the debugger. Order: fleet rebase conflict → debugger; integrity → end; `CONTROL_PLANE_VIOLATION` → build; ship-local codes (`shipLocalCodes`) → debugger; precondition, `AUDIT_BINDING_*` or `EGPS_RED_COUNT` → audit; `GIT_FLEET_REBASE_NEEDED` → audit; transient → ship; anything else → debugger.
- **`PhasePolicy`.** `Enabled` mirrors `shouldRun` without the insertion cap. `ShouldRunPhase` splits by stage: below Enforce it is pure enable-flag resolution because the static state machine owns sequencing there; from Enforce up it defers to `Enabled`, so a conditionally pinned phase cannot be flag-disabled. `PolicyForProject` reloads config per phase and applies `policy.json`'s `mandatory_phases` and failure route exactly as the composition root does, so a phase made mandatory only by policy does not skip itself. A malformed policy is ignored there and hard-fails later at dispatch. `FailureRouteFromPolicy` folds `always_learn=false` into a `memo` default route, but an explicit `audit_fail_routes_to: "retrospective"` wins.
- **Plan validation and mismatch.** `ValidatePlan` is pure and report-only; the floor clamp stays the sole disposer. `PlanMismatch` reuses `triggerFires`, so the re-plan threshold can never disagree with the trigger. `knownPhaseSet` is deliberately generous: canonical order, configured walk, mandatory, triggers, conditionals, the offered catalog, and phases minted by the plan through either channel (`plan.MintPhases` or an inline `PhasePlanEntry.Mint`).
- **Recon digest.** `BuildReconDigest` is pure and sorted. Keyword hits are word prefixes, not substrings, so "prefix" does not count as "fix" and "latest" does not count as "test", while "docs" still counts as "doc". `reconGoalKeywords` is a sorted array literal, so the result needs no re-sort and the table cannot be mutated at run time. A zero digest renders nothing, which keeps the prompt byte-identical when recon is off.
- **Recipe projection.** `RenderRecipeProjection` renders `config.goal_recipes` into the router persona's "Goal-Type Recipes" table. `TestRouterPersonaRecipeTable_NoDrift` locks the persona block between the `GENERATED:goal-recipes` markers to that output.
- **`AssembleHandoffs`** is the router→phaseio bridge. It lives here, on top of `Digest`, so phaseio stays a leaf and there is one on-disk reader. `HandoffsFromSignals` lets a caller that already digested project without a second read; its only real conversion is the severity ordinal to its word.

## Invariants

- **Every override is recorded.** A mandatory re-enable, a cap, a plan veto of the operator's off, a skip_when gate, a dropped entry and a clamped proposal each leave a `Clamp`, so the routing-plan artifact explains the decision.
- **Clamps are pure.** `ClampPlanToFloorWith` and `ClampPlanModelRouting` return a new plan and leave the caller's untouched, because the re-plan comparison needs the original.
- **On the plan path, floor phases are never capped or skip_when-gated.** `isFloorPhase` (intent, scout, tdd, build, audit, ship) exempts them, because the floor is non-configurable and a config veto must never become a floor bypass.
- **The evaluator is re-asserted.** `ClampPlanToFloorWith` appends `EvaluatorFloorPhase` to any floor that lacks it, rather than trusting `policy.FloorPhases`. `TestEvaluatorFloorPhase_SingleSource` pins the twin; its fixture must omit the evaluator, or the append branch is never taken.
- **Absent TDD rule means pinned.** With no conditional rule for tdd, `tddPinned` returns true, the more mandatory side.
- **Typed fields are always present; absent generic fields fail closed.** A generic field that was never emitted evaluates false for every operator, in both `insert_when` and `skip_when`. Typed fields keep their zero values: `cycle_size != trivial` must hold with no signals, or the TDD pin would silently release at cycle start. A present empty string keeps normal string semantics. `deliverable_kind` is projected (triage > scout > `code`) and always present.
- **The deliverable-kind default is `code`.** It is the conservative side: `deliverable_kind != document` holds at plan time, so the tdd pin is released only by a digested document declaration. An unrecognized word normalizes to `""` and never releases anything. `DeclaredDeliverableKind` keeps "nobody said" apart from "somebody said code".
- **Severity parsing fails low.** An unknown word is `SevNone`, so it never escalates routing.
- **Presence is artifact-backed.** A role is `Present` only when its phase is in `completed` and a real artifact exists, so a fabricated completed list cannot satisfy the spine gate.
- **Absence is clean, a read-miss is loud.** A missing artifact is a silent `Present:false`. Any other read failure (EISDIR, permission, corrupt fallback, an `acs-verdict.json` without a verdict, an ungatherable git tree) appends to `DigestDegraded`, and a degraded digest keeps the spine gate fail-open. An empty report counts as not delivered.
- **A FAIL audit verdict flows through.** The `acs-verdict.json` fallback carries a red verdict honestly; the spine's audit anchor then refuses ship.
- **The payload is the authority.** Digest reads the unwrapped payload, so the envelope's promoted top-level signals must be a copy of the payload's. `TestDigest_PayloadWrapped_FoldsInnerSignals` pins the read side.
- **An empty commitment needs an explicit array.** A `null` or non-array `top_n` is degraded and unknown, never "empty", so a malformed decision cannot end a cycle.
- **BLOCK is the failure floor.** The advisor's `RecoveryAction` is adopted only when the failure adapter does not block. An unknown action is clamped and never enters the evidence. On retry only `FailureInsertPhases` (fault-localization, bug-reproduction) may be inserted; both precede tdd, so the walk continues into the retry. That map is the one home of the list; the advisor prompt renders from it.
- **Some learning phase always runs after an audit FAIL.** `LearningRichness: memo` routes memo only when memo is enabled; otherwise it is clamped back to the retrospective. The proposal is always recorded in the evidence. A proposal that agrees with a policy-chosen memo route records no clamp, because nothing was forced.
- **A per-transition proposal only annotates the walk.** `applyProposal` records the justification and clamps any divergence; it never changes `NextPhase`.
- **PSMAS is additive only.** Triage's `phase_skip[]` applies only when `PSMASEnabled` is set and triage signals are present, and only to phases that are optional this cycle. Mandatory phases and the tdd pin always win. Names are normalized (`tdd-engineer` → `tdd`) because triage writes persona vocabulary. Unknown names are ignored.
- **Recovery order carries meaning.** The fleet rebase conflict is the one integrity-class code that recovers, so it sits above the integrity block. Integrity sits above every code-keyed handler, so an integrity-classed error blocks even when its code is ship-local. The control-plane and ship-local handlers sit above precondition re-audit because those codes must never loop back to audit. The fleet rebase handler sits above transient retry because that transient code needs a fresh audit of the rebased tree.
- **The model clamp is absolute.** A persuasive `Justification` never widens the envelope. A nil profile skips the guardrail checks (the catalog check still applies), and an empty `AllowedCLIs` is a preference, not a restriction (B2). The catalog is keyed by base family, so the lookup uses `policy.BaseCLI(e.CLI)`, but an honored entry keeps its original CLI string (I1).
- **Hybrid cadence gate.** With a plan, `shouldPropose` consults the proposer only at build, audit and retrospective, where new objective signals appear. Without a plan every transition proposes, so Shadow forensics are unchanged. Extend `isBranchTransition` when a phase starts producing new post-phase signals.

## Findings

- **cycle-230**: three PASS audits and zero ships, because ship-local preconditions routed back to audit. Those codes now go to the debugger. `MANIFEST_GATE` joined the set in cycle-1064. See ADR-0039 and runtime-reference.md.
- **F37 / cycle 1689**: a control-plane edit would have looped re-audit on the same diff; `CONTROL_PLANE_VIOLATION` now routes to build. See ADR-0064.
- **ADR-0049 G13a and S5b**: a fleet rebase conflict is overlapping work for the debugger; a divergence is rebased and re-audited on the merged tree, never a blind ship retry.
- **cycles 238/240, the advisory soak**: D1, a plan `run:false` must veto a firing trigger. D2, `ne` on a never-emitted generic signal returned true (`"" != value`), so catalog phases with `goal_type != <other>` triggers fired when scout emitted nothing; absent generic fields now fail closed. D3, the plan path skipped the insertion cap, and nine optional inserts ran against a cap of six. D4, a plan computed without `EVOLVE_REQUIRE_INTENT` dropped the intent gate; the clamp now forces it.
- **cycle-252**: the Go router extracted triage's `phase_skip[]` but never used it. It was wired behind `PSMASEnabled`, with the vocabulary normalization above.
- **cycle-283 and the operator policy of 2026-06-11**: a completed build was discarded with audit and ship unreached. That produced the converse implication `run(build) ⇒ audit ∧ ship`.
- **Handoff JSON has been extinct since about cycle 215.** Each fallback closed one silent gap. Build (cycle-589, the third recurrence of `warnship_apicover_ci_gap`): `sig.Build` stayed zero on every real cycle, so cycle-587 shipped a new package the router never saw. Scout and audit (the L1 spine-floor fix, 2026-07-16): the missing signals produced 1914 WARN-clamped routing decisions across the surviving run history, and that noise was the only thing blocking the PhaseRecovery shadow→enforce flip. Triage (ADR-0076 slice A): without it every size-conditioned budget multiplied by 1.0. Goal type and deliverable kind ride the report headers (ADR-0099).
- **2c0559a5 (an e2e-tier red)**: an `acs-verdict.json` that parsed but had no verdict produced `Present:true, Verdict:""`, an unsatisfiable anchor that read as a clean absence and hard-blocked ship. Schema drift now degrades.
- **cycle-436 (MR1/MR2)**: per-phase `{cli, tier}` proposals and their guardrail clamp. **cycle-463 (T4)**: a below-floor tier clamps up rather than emptying the proposal. **cycle-480**: 72 of 91 profiles declared no envelope, so a `fast` proposal fell through `ValidatePin` as a mere preference; the compiled universal envelope closed that. **L5 (2026-07-16)**: above-maximum tiers were never clamped; the ceiling was added, and review caught that a universal `Max: deep` would have silently foreclosed `top` for every envelope-less profile. **F2**: the raw suffixed CLI (`claude-tmux`) was passed to a catalog keyed on the base family, so every suffixed proposal missed.
- **cycle-1140**: the plan path ignored `skip_when`, so an advisor-inserted optional ran on every cycle class, measured at 0.83M–1.67M cache-read tokens per insert (per-phase context costs: [token-usage-history-2026-07-20.md](../../research/token-usage-history-2026-07-20.md)).
- **cycle-563**: the fix for a silently dropped post-ship memo dispatch had to leave an explicitly disabled memo skipped.
- **cycle-1275**: the minter started satisfying the catalog metadata contract itself, from the advisor's `MintSpec` description and when-to-use, instead of padding `metadataAllowlist`.
