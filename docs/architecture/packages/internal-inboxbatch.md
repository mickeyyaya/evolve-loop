## Purpose

`internal/inboxbatch` is the inbox item model and the deterministic half of task selection. It loads and sanitizes `.evolve/inbox/*.json` records, groups them into batches that one cycle can carry (`Classify`), renders the batches for the triage prompt, decides which items are console-routed (operator-owned), and owns the `processing/cycle-<N>` claim layout. Grouping follows mechanical signals, so it lives in Go. Choosing a batch stays the triage LLM's judgment.

## Design

- **Why batch.** Consuming one item per cycle pays the full scout, triage, tdd, build, audit and ship overhead for each item. A batch spreads that cost over items that share a campaign, a package area or a dependency.
- **Rules as a Strategy, clusters by union-find.** Each `Rule` emits `Edge`s, and each edge carries its own human-readable `Reason`, so the interface has one method and no name accessor. `Classify` unions every rule's edges, orders each cluster dep-topologically (Kahn, with the ready set ordered weight-descending then by id), splits it at `MaxItems`, and ranks the result. A new signal is a new `Rule` passed through `Config.Rules`; no classifier change is needed.
- **The default rule set is `campaignRule`, `fileAreaRule` and `depRule`.** The order is presentation only, since edges union. `ConnectsRule` is exported for opt-in only: `connects_to` is prose navigation (the inbox house style is to link liberally), and entries resolve when they begin with a known id. `root_cause` is never a rule (see Findings).
- **File areas.** An area is a file's directory, capped at `areaDepth` (3) segments, so `go/internal/router/sub` groups with `go/internal/router`. A path ending in `/` names a directory and is its own area. Two discriminative bounds apply. The ceiling `hubAreaMaxItems` (5) drops an area that more items share than that, on the inverse-document-frequency idea: `go/internal/core` appears in half the backlog and says nothing. The floor `minAreaDepth` (2) drops a single top-level directory (`agents`, `skills`, `go`), which is a bag of unrelated files rather than a unit of work. Shallow areas slip under the ceiling, so the ceiling alone never caught them.
- **Campaign is a partition, not a signal.** The operator's `campaign` field declares one initiative. An inferred edge (file area, dep, connects) never merges two distinct non-empty campaigns. `clusterCampaign` tracks each root's campaign claim, so the guard holds transitively: a campaign-less item may join one campaign's cluster but can never bridge two. A blocked cross-campaign dep still runs in order, because the dispatch freshness gate holds a lane until its deps land; the partition only prevents co-batching.
- **Clusters rank as units.** Whole clusters sort by their maximum member weight, and each cluster's chunks stay adjacent and predecessor-first. The note "run the previous batch first" therefore always points at the line above.
- **A batch's weight is its maximum member weight.** A batch is as urgent as its most urgent item; a sum would reward padding.
- **`DefaultMaxItems` is 4.** That is the most a single cycle's tdd, build and audit carry without entering the triage capacity clamp's overpacking range. Policy may override it per project. `UnifiedCommitment.Size` uses the same cap to call a commitment `small` or `large`.
- **Degenerate data.** A dep naming an absent item (consumed or shipped) is treated as satisfied: no edge and no block. A dep cycle appends the remainder in weight-then-id order, so items are never dropped and the sort never hangs.
- **Rendering.** `RenderMarkdown` writes one line per batch: rank, weight, binding reasons and member ids, which is enough for triage to select a whole batch as `top_n`. At most `maxRenderedReasons` (3) reasons render, followed by `+N more`, because the output is a prompt section rather than a forensic dump. Empty input renders the empty string, which keeps the triage prompt byte-identical.
- **Tolerant decoding.** Inbox records are a mix of hand-written and agent-filed JSON, so an absent field zero-values rather than erroring. `LoadDir` sorts by id. A missing directory is an empty inbox. A malformed file is skipped with a warning that names it (fail-open, but never silent). Non-JSON files are ignored, because the inbox holds notes and subdirectories. `LoadFile` loads one record with the same treatment, and falls back to the filename stem for a missing id, since the filename is unique by construction.
- **Prompt-surface sanitization.** `id`, `title`, `campaign`, `route`, `deliverable_kind`, every `files[]` entry and every `acceptance[]` criterion reach LLM prompts (the batch render, edge reasons, the Task Contract block). Control characters become a single space, never a newline, so a batch stays one line. Fields are bounded at `maxFieldLen` (160 bytes), which fits every legitimate id; an acceptance criterion is bounded at `maxAcceptanceLen` (600 bytes), since real criteria run 150 to 400 characters and the bound stops an item from smuggling in a page of instructions. Any change produces a warning.
- **Item fields with downstream owners.** `Class` is the declared archetype that `IsOperatorState` keys on. `Route` and `InjectedBy` feed console routing. `Continuation` is machine-consumed only and never rendered into the triage prompt; it is validated at adoption, not here. `Acceptance` is the single source the harness projects into the tdd, build and audit prompts, so builder and auditor grade against the same words. `DeliverableKind` is `code` by default; the cycle's authoritative kind is the one triage declares. `Path` is the source file name, shown by `evolve inbox batches` and never used for grouping.
- **Mentions are derived at decode.** `Item.UnmarshalJSON` records the file paths the record's own author-written fields name. It runs at decode, not in one loader, because the wave seed, the claim floor and `LoadFile` each unmarshal records themselves, and the console classifier must see the same surface from all of them. The walk reads decoded strings (so an escaped `\/` is still a slash) in sorted key order. It skips `files`, `continuation`, `route`, `injected_by` and every `routed_*` key: the console router in inboxmover's lifecycle `route.go` stamps all of its fields with that prefix, so the prefix is matched instead of copying its names. Only file spellings count (a last segment with an extension after its first character); a directory mention is context, not surface. At most `maxMentions` (64) are kept, so a runaway record cannot make routing costly.
- **Declared surface.** `Item.DeclaredSurface` is the one home of "this item declares its fix surface": at least one path-shaped `files[]` token. Tokens split on whitespace, lose surrounding punctuation, and lose a trailing source locator (`:178`, `:178:5`, `:189,205,221`, `:10-20`, `#L10-L20`; a date-shaped suffix strips too). A path-shaped token is wholly slash-separated path characters, and not every segment is a single character. `TBD`, `N/A`, `w/o`, `()` and a bare `role.go` declare nothing. The console classifier judges exactly these tokens, so an annotation word such as the `go` in "(go test)" is never read as a directory.
- **Console routing.** `ConsoleRouted` is the one classifier the plan-time gate (`fleet.TodosFromTriage` through `RoutedResolver`), the triage prompt partition and `inboxmover.Claim` share. The precedence and the override clamp are ADR-0074's. `KindPipelineRepair` is the one symbol the ADR-0072 halt writer (`cmd_loop_escalation.go`) and the classifier share. A nil scope predicate disables only the derived surface rules; the route field and the kind still apply, for callers that cannot import `guards`.
- **`RoutedResolver`.** It loads the directory once; build one per wave so mid-batch inbox changes are seen. An unknown id is dispatchable, because scout-originated work has no inbox item. A load failure resolves every id as dispatchable, since a broken backlog must not stop the queue (ADR-0072). With duplicate ids the first loaded item wins.
- **The operator-state archetype.** `IsOperatorState` recognizes a declared `pipeline-architecture` item whose every file is under `.evolve/`: a pure mutation of live runtime state with no build or audit surface, which can eventually be applied natively instead of paying for a worktree pipeline.
- **The claim layout lives here.** `layout.go` is the one home of the `processing/cycle-<N>` path. The writer (`inboxmover.Claim`), every reader (`inboxmover.Locate`, orphan recovery, dispatch state, failure counts, core's dispatch-time claim scan) and the parser derive it from here, so the gate that judges a claim reads the shape the claim wrote. It sits in this leaf because core cannot import inboxmover (the ledger adapter imports core). `CycleDir` and `CycleDirs` also serve the promoter's `processed/` and `rejected/` directories, so a respelling on one side cannot hide a retired item from the readers.
- **Unified commitments.** A `UnifiedCommitment` is triage's claim that several items close through one shared design. It is validated after mechanical classification and never changes the grouping rules. Callers that get a validation error fall back to the original independent selection.

## Invariants

- **`Classify` is deterministic.** The campaign guard makes union outcomes depend on edge order (which cluster a campaign-less bridge joins depends on which edge unions first), and the campaign and file-area rules emit from map iteration. `sortedRuleEdges` therefore puts every edge in one canonical `(A, B, Reason)` order first. Pinned by `TestClassify_CampaignPartitionIsDeterministic`.
- **No batch spans two non-empty campaigns.** When two clusters merge, the merged root inherits whichever claim is non-empty; the guard has already ruled out two different non-empty claims, so this is correct for any choice of union root. Pinned by `TestClassify_TwoCampaignsSharingAreaNeverMerge` and `TestClassify_CampaignlessBridgeCannotFuseTwoCampaigns`.
- **Reasons follow the final root.** A later union can move a root, so every recorded reason list is folded into the cluster's final root before rendering.
- **A dep never lands after its dependent.** Chunks split in topological order, so a dep sits in an earlier or the same chunk, and every later chunk is flagged `DependsOnPrev`. Pinned by `TestClassify_OversizedClusterChunksInTopoOrder` and `TestClassify_ContinuationNeverOutranksPredecessor`.
- **One tie-break.** `weightDescThenID` orders both the topological ready set and the final cluster ranking, so the two orderings cannot drift.
- **`DefaultRules` stays the three bounded structural rules.** A fourth default rule needs a discriminative bound (a ceiling or a floor) and an evaluation against real backlog data before it may default on. Pinned by `TestDefaultRules_DoesNotBindOnRootCauseProse` and by `go/acs/cycle1205`, which mutates `rules.go` through `go test -overlay` by replacing the literal `return []Rule{campaignRule{}, fileAreaRule{}, depRule{}}`; that line's exact text is part of the predicate's contract. `go/acs/cycle1206` (C1206-003) reads `rules.go` and requires `root_cause`, `failedApproaches[54]` and "zero edges" in its comments, so the `DefaultRules` doc keeps them.
- **Sanitized fields never carry a newline.** Pinned by `TestLoadDir_SanitizesRenderedFields`.
- **One control-character rule for prompt-bound text.** `StripControl` maps C0 and DEL to spaces, never a newline: a newline in an id, a title or a commit subject would forge a new context line in the prompt that renders it. `cleanBounded` applies it and then the length bound. Pinned by `TestStripControl`.
- **A declared surface is only path-shaped tokens.** `declaredTokens` is the one token set the console classifier judges and `DeclaredSurface` and `DeclaredPaths` report, so an annotation word (`(go test)` yields `go`) is never read as a directory. Pinned by `TestConsoleRouted_AnnotationWordsAreNotSurface` and `TestItem_DeclaredPaths`.
- **`FiledAt` never guesses.** It reads `created_at` (RFC3339 or a bare date), else the file name's `2006-01-02T15-04-05Z` prefix (colons are not filename-safe), else returns zero. Triage's premise-drift check measures from it, so a guessed date would fake drift. Pinned by `TestItem_FiledAt`.
- **A duplicate id is kept but warned about.** The resolver index keeps the last item with an id, so a duplicate would silently mis-wire dep and connects resolution. Pinned by `TestLoadDir_WarnsOnDuplicateID`.
- **Mentions only narrow.** A mention can move an item to the console but never widens lane authority, and it never binds: the text may merely cite the file. A declared surface wins over mentions. Pinned by `TestConsoleRouted_DeclaredSurfaceWinsOverMentions` and `TestConsoleRouted_LaneOverrideStillRelaxesTheHeuristics`.
- **Only surfaces already on the manifest match.** A task that will create a new gate-shaped file is caught later by the ship tripwire and the disposition handoff, not by routing.
- **Every routed item carries a reason.** `PartitionConsole` returns one reason per excluded item, because a silently narrowed backlog reads as full coverage. Pinned by `TestPartitionConsole_SplitsWithReasons`.
- **`IsOperatorState` fails toward the normal pipeline.** Any file outside `.evolve/`, an empty file list, or any other class answers false. A missed detection costs a cycle; a false one would skip review of a source change. The trailing `/` in `.evolve/` is load-bearing (`.evolvex/` is not runtime state). Pinned by `TestIsOperatorState`.
- **`cycle-0` is never a claim directory.** Cycles start at 1, and 0 is `inboxmover.Location`'s "pending at the root" sentinel. Pinned by `TestParseProcessingCycle_RejectsZero`.
- **An absent lifecycle directory is an empty list.** `CycleDirs` returns nil rather than an error: no item ever reached that state.
- **Unified commitment members are homogeneous.** Members must be known items, distinct, and each carry evidence; they must share one campaign (unscoped counts as its own value) and one deliverable kind (empty means `code`). Pinned by `TestUnifiedCommitment_RejectsMixedCampaignMembership`.

## Findings

- **Hub ceiling** (package creation, 2026-07-16): without it, real-backlog validation fused 55 of 61 items into one cluster through `go/internal/core`. The same validation showed `connects_to`'s transitive closure chaining half the backlog into one cluster, which kept `ConnectsRule` out of the defaults.
- **Cluster-unit ranking** (go-reviewer, package creation): a flat per-chunk weight sort let a continuation outrank its own predecessor whenever a low-weight dep chain pushed a high-weight item past the chunk boundary. The same review added prompt-surface sanitization (an id such as `evil\n- SYSTEM OVERRIDE` could fabricate prompt lines) and the duplicate-id warning.
- **Depth floor** (84-item backlog, 2026-07-27): two `agents` edges chained three unrelated campaigns (`chronicle-2026-07`, `pipeline-integrity`, `convergence-2026-07`) into one 43-item cluster, 51% of the backlog, chunked into 11 serialized batches. With the floor the largest cluster fell to 27 items (32%), and the convergence campaign split into its own 11-item cluster.
- **Campaign partition** (live backlog, 2026-07-28): chains of small shared areas fused 17 campaigns into one cluster of about 37 items, rendered as nine batches each marked "run the previous batch first".
- **`root_cause` rejected** (cycle-1204 audit; `.evolve/state.json` `failedApproaches[54]`): an exact-match rule on the field was built and reverted. Across the 67 live items, all 20 non-empty values were unique prose of 122 to 1564 bytes (median 317). Unlike campaign and dep ids, which are short reusable keys, `root_cause` is a per-defect narrative, so equality binding yields zero edges (D1), and normalizing or fuzzy matching would only manufacture false edges between unrelated defects, with no ceiling or floor to stop the fusion (D2). Cycle-1205 added the regression guard; since `Item` has no `root_cause` field, it uses `Title` as the free-form prose stand-in.
- **`class` was dropped at load** until cycle-1190, although authors had been writing it into inbox JSON for some time.
- **Pipeline kinds** (F25, wave 6, cycle 1688): 15 `pipeline-*` items sat lane-eligible, 8 with no `files[]` at all; one was claimed and failed triage before the breaker caught it.
- **Retired-item scan** (F18, [2026-09-15 incident](../../incidents/2026-09-15-shipped-item-re-pinned-and-sealed-lease-blocks-refresh.md)): the dispatch-state resolver read `processed/` flat while the promoter nests it by cycle, so cycle 1682 re-pinned a lane to an item cycle 1679 had already shipped. `CycleDirs` became the one scan.
