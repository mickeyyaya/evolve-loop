## Purpose

`internal/adapters/bridge` is the production `core.Bridge`. It assembles the prompt a phase agent receives and delegates dispatch to the in-process `internal/bridge.Engine`. It is also the composition root that turns `.evolve/policy.json` into engine `Deps`: timings, recovery dials, the context-fill threshold, the token resolver, the wall corroborator and the Signal Center.

## Design

- **Prompt assembly is a chain of wrappers.** `Launch` applies `injectContract`, `injectPolicyPrefix`, `injectRulesPrefix`, `injectSkillOverlays`, `injectOperatorDirectives` and `injectCorrectionPrefix` in that order. Each wraps the previous result, so the last applied lands outermost. Top to bottom the prompt reads: Correction, Operator Directives, Skills, Rules, Policy, contract block, body, path footer and contract tail.
  - Correction is outermost so the agent reads a rejection first. Directives sit just below it, so standing operator guidance never displaces an active correction. Skills sit at the persona altitude, just above the profile rules.
  - Everything above the body is invariant per phase and tier, so it forms the cacheable prefix. The per-cycle path goes after the body, where it is also the most recent instruction.
  - Every block is prompt text, never a launch flag, so the same assembly works for every driver, headless and tmux, and never passes through `launchCmdLine`, which does not shell-quote.
- **Interactive policy.** `resolvePolicy` takes `policy.InteractivePolicyFor` (the per-agent `workflow.interactive_policies` entry, else the global `workflow.interactive_policy`). A value other than `recommended_or_first` wins. When policy.json resolves to `recommended_or_first`, the profile's typed policy (`req.InteractivePolicy`) applies, and failing that the default. `escalate` injects nothing, `auto_yes` injects its own block, and any other value gets the `recommended_or_first` block, so a typo cannot break the loop's autonomy. The blocks are constant strings under about 200 tokens, which keeps the cached prefix stable. The `EVOLVE_INTERACTIVE_POLICY` and `EVOLVE_<AGENT>_INTERACTIVE_POLICY` env vars are no longer read: `go/acs/cycle25` pins zero `envchain.Resolve` calls in `resolvePolicy`.
- **Contract selection.** The contract id is `req.Agent`, or `req.Contract` when set. An explicit contract must be registered, or `Launch` fails before dispatch. The resolver defaults to `phasecontract.BuiltinResolver`. `SetContractResolver` installs a catalog resolver so user and minted phases get spec-derived contracts, and `nil` restores built-ins. A zero-value Adapter degrades to built-ins through `contractResolver`.
- **Contract rendering.** A resolved contract puts `RenderContractBlockStage` before the body and `RenderContractTail` (the footer line, then the XML `<deliverable-contract>` block) after it. An unresolved contract with an artifact path gets a synthesized minimal contract and `RenderContractFooter` only. With no artifact path the body passes through. Only direct callers reach that last case, because `validate` rejects an empty `ArtifactPath` at `Launch`.
- **Phase-I/O failure instruction.** At `StageAdvisory` or above, `RenderContractBlockStage` tells contracts with `RequireFailureContextPhaseIO` (build, scout, triage) to self-report failure through a structured sentinel. The gate is advisory, not enforce, so the advisory soak exercised the new sentinels before the enforce flip. Off and shadow keep the prompt byte-identical, because the classifier's sentinel pass is not stage-gated: a sentinel emitted at off would change cycle classification. The Adapter's zero value is `StageOff`; the cycle root calls `SetPhaseIOStage`.
- **Two engine construction paths.** `engineFactory` (set by `New` and `NewDefault`, replaced by a fake in tests) serves `Probe` and the plain `Launch`. When `onStopReview` is set, `Launch` builds its engine directly, because the cycle-scoped `OnStopReview` callback must go into that launch's `Deps`. Both production paths build `Deps` through `productionEngineDeps`, so they cannot drift. `New()`'s factory passes only `Env`.
- **`productionEngineDeps` wiring.** Timings come from `policy.BridgePolicy` (zero means the engine's built-in). Per-phase artifact budgets come from `PhaseArtifactTimeouts()` ([runtime-reference](../../operations/runtime-reference.md)). `TokenResolver` is `tokenusage.DefaultResolver` over `$HOME/.claude`, with `HOME` read from the request env first and the process env second. `CorroborateWall` is `DefaultWallCorroborator(nil, os.Stderr)`: a pane exhaustion match escalates rc 85 only after a live one-token probe confirms it, so wall vocabulary in an agent's own work cannot forge a quota wall. The corroborator is wired only here, so engine tests keep the nil seam.
- **`NewDefault` is fail-open.** A missing or unparseable policy.json leaves a zero `Policy`: built-in timings, a zero context-fill threshold (the engine applies its default), and compiled-default recovery dials through `policy.BridgeRecoveryStages`, the Loader's own parser. Roots that never call the setters (the per-phase registry factories, `cmd_campaign`) therefore still honor policy.json. The cycle root overrides both dials with Loader-validated values through `wireBridgeStages`.
- **Signal Center.** It is a constructor argument, not a setter, so it cannot be forgotten, and `nil` is the Null Object. `Signals()` is the read seam the phase runner uses to adopt the Center from the injected Adapter, so every runner built over the production bridge reports into the root's Center without per-site wiring.
- **One validation rule.** `validate` delegates to `gobridge.ValidateRequest`, so the adapter and the engine reject the same request with the same error string. `internal/bridge/launch_outcome_seam_test.go` pins that `ValidateRequest(req)` appears only in this file and `engine.go`.
- **`SetModelCatalogDirFn`** forwards to a package global in `internal/bridge`. It is process-wide, not per Adapter.
- **External pins on `bridge.go`.** It is listed in the integrity-surface manifest (`internal/guards/integrity_surface_manifest_test.go`). `cmd/evolve/cmd_bridge_engine_roots_test.go` counts its three `bridge.NewEngine` calls. `go/acs/cycle25` requires `req.InteractivePolicy` in the file.

## Invariants

- **Empty input is identity.** Every inject function returns the prompt unchanged for empty input, so an unused feature leaves the dispatched prompt byte-identical. Pinned by `TestInjectCorrectionPrefix`, `TestInjectOperatorDirectives`, `TestInjectRulesPrefix_EmptyRulesUnchanged` and `TestInjectSkillOverlays_NoopPaths`.
- **Nothing per-cycle before the body.** The prefix is byte-identical across runs of the same phase, which keeps it cacheable. Pinned by `TestLaunch_PolicyBlockStableAcrossRuns` and `TestLaunch_InjectsDeliverableContract`.
- **A polled path is always disclosed.** Whenever the request carries an `ArtifactPath` the engine will poll, the prompt names it, whether contract resolution hit or missed. Pinned by `TestLaunch_UnresolvedAgentWithArtifactStillGetsPathFooter`.
- **A resolver miss gets no impossible instructions.** The synthesized footer carries no self-check and no sentinel template, because `evolve phase verify <agent>` exits 10 for an unregistered phase and no verdict vocabulary is registered. Pinned by the same test's negative assertions.
- **One restatement in the tail.** After the body there is exactly one path declaration and one `<deliverable-contract>` block. The prefix block may quote the footer marker as a cross-reference. Pinned by `TestLaunch_AppendsDeliverableContractTailBlock`.
- **Failure-bearing exemplar in the tail.** For a contract with `RequireFailureContext` (audit), the tail's sentinel exemplar is the schema-2 form with the failure block. The tail is the copy the agent follows, and a bare PASS exemplar there would be imitated on the phase whose verdict gates ship. Pinned by `TestLaunch_AppendsDeliverableContractTailBlock`.
- **A missing skill never fails a launch.** It is WARNed and skipped. Pinned by `TestLaunch_MissingSkill_StillDispatches`.
- **Validated context-fill threshold.** `NewDefault` reads `policy.ContextFillConfig()`, never the raw field, so an out-of-range value arrives as the built-in 60. Pinned by `TestProductionDepsContextFillRejectsOutOfRange`.
- **Both dials on every production path.** Pinned by `TestProductionEngineDeps_CarriesBothRecoveryDials` and `TestNewDefault_SeedsRecoveryDialsFromPolicy`. `SetFatalPaneStage` never moves the program dial (`TestSetFatalPaneStage_WiresField`).
- **A real token resolver.** The wired resolver scans real transcripts, not a stub (`TestProductionEngineDeps_ResolverAppliesRealFixture`), and the real `engineFactory` closure wires it (`TestEngineFactory_WiresTokenResolver`).
- **`Signals()` tolerates a nil receiver** and returns exactly the injected Center. The runner adopts it through an optional interface, where a typed-nil `*Adapter` can arrive. Pinned by `TestAdapter_SignalsReturnsTheInjectedCenter`.
- **Configure before sharing.** The setters are unsynchronized; `Launch` only reads the Adapter's fields. Wire an Adapter fully before it is used.
- **Tests see the fake engine only on the factory path.** A test that sets `onStopReview` reaches the real engine; `TestLaunch_OnStopReviewBranchStillValidatesViaEngine` relies on that.

## Findings

- **cycles 612–619** ([token-telemetry-zero-postmortem](../../research/code-audit-2026-07/token-telemetry-zero-postmortem.md)): production launches recorded zero tokens because no composition root wired `Deps.TokenResolver`, and fail-open hid the gap. Cycle 623 added `productionEngineDeps` as the one `Deps` builder for both production paths.
- **cycle-1424** ([incident 2026-08-10](../../incidents/2026-08-10-continuation-absorbing-fail.md)): a minted phase was dispatched with no contract block and no path while the engine polled for its report. The agent was never told the path: a 600 s artifact timeout, exit 81, a system-failure halt. The fix discloses the path in a footer. The adversarial review blocked the full tail because of its impossible self-check.
- **cycle-1444**: the context-fill threshold was a `Deps` field that only tests set, so the operator's `context_fill` block was dead config until `NewDefault` resolved it. Cycle 1446 then found that the eval's and the ACS predicate's `-run` patterns selected only one of the two wiring tests, so half the contract was never gated.
- **False walls** ([incident 2026-08-15](../../incidents/2026-08-15-false-walls-and-repick-class.md)): a lane editing the exhaustion fixtures put wall vocabulary in its own pane and forged a quota wall. The live-probe corroborator wired at this root is the fix.
- **Fatal-pane dial split** (ADR-0044 amendment): before it, roots that never called the setters pinned the program dial to shadow whatever policy.json said. Both dials now seed from policy.json on every root.
