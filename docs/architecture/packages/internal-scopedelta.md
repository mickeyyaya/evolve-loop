# internal/scopedelta

> Decision and threat model: [ADR-0087](../adr/0087-scope-delta-adjudication.md) (the six classes, `CARVE`, the never-drop accounting, and the four anti-gaming discriminators D1–D4). The review findings that shaped the accounting seam, the reason floor and the gaming layer: [the proxy-as-verdict findings](../../incidents/2026-08-12-proxy-as-verdict-findings.md), groups B and C. This page keeps the package-level detail those do not.

## Purpose

`internal/scopedelta` adjudicates the work a phase agent produced outside its declared scope, on what the change means rather than on the fact that it is outside. It classifies each out-of-scope path, proposes a disposition (keep, carve or refuse), and accounts for every changed path, so a path that is neither in scope, nor computed closure, nor adjudicated blocks the ship instead of vanishing silently.

## Design

- **Pure.** No I/O, no clock, no globals: every decision is a function of its arguments, which is what lets the tests pin the whole contract.
- **`Class` names why a path sits outside the scope.** A single boolean cannot carry a disposition, and each class wants a different answer:
  - `closure`: the in-scope change is not correct without it (call sites of a changed signature, the covering test of a new export, a doc the change falsified). Computed by a rule, never declared. Kept.
  - `discovered`: a real, unrelated defect found while working. The finding is valuable and the fix is unreviewed risk. Carved.
  - `opportunistic`: a refactor or cleanup the agent thought was nice. Carved.
  - `misunderstood`: the agent believed this was the task. It is evidence about the item's wording, not about the agent.
  - `boundary`: a protected, operator-owned surface (ADR-0074). Policy, not merit: refused whatever the justification, and preserved.
  - `cross-lane`: belongs to a sibling lane's scope. Carved and handed over.
  - `in-scope`: not a delta at all. It makes `Classify` total, so a caller that passes the whole changed set never has the cycle's own declared work carved away (`TestClassify_InScopePathIsNotADelta`).
- **`Disposition` is what happens to the path.** `keep` ships with this cycle; `carve` removes it from the ship and preserves it as a queued item; `refuse` does not admit it and preserves it for the operator.
- **`Scope` is what the cycle was licensed to touch.** `Declared` holds the paths the cycle's contract and lane scope named, `Protected` the operator-owned surfaces a lane may not edit regardless of merit, `LaneOthers` the scopes of this wave's sibling lanes, and `Cycle` the cycle number the artifact rule keys on.
- **Path matching.** An entry matches the path itself or any path under it, with or without a trailing `/`. The separator is still required, so `docs/research` never matches `docs/researchers/x.md`, and an exact file entry never prefix-matches a longer name. Empty entries match nothing. Pinned by `TestScope_InScope_DirectoryPrefixesAndExactPaths` and `TestScope_ProtectedWithoutTrailingSlashStillProtects`.
- **`Declaration` is the producing agent's own account of a path**, the cheap half of the contract: the agent already knows why it touched the file. It can propose a class and a justification; it cannot make a path closure.
- **`Entry` is one adjudicated path**: class, disposition, the reason the decision is defensible, and the evidence. `PatchRef` names the preserved hunks of a carve or refusal; a carve without one is silent disposal, and `Validate` refuses it. `Preserve` records that the work survives though it is not admitted. `Effect` and `Corroboration` are the D3 and D1/D4 evidence (below).
- **`ClosureRule` is a Strategy, one rule per invariant**, so "is this closure?" always has a mechanical answer and the set can grow from observed firings. `Name` puts the licensing rule on the record. `DefaultClosureRules` is deliberately small: a rule that cannot be decided from the paths alone belongs in adjudication. It holds three rules (`TestClosureRule_DefaultsImplementTheInterface`):
  - `same-package-test`: a `_test.go` file in a directory a declared path lives in. Refusing it drops a change's covering test for being out of scope.
  - `cycle-artifact`: `go/acs/cycle<N>/` and `.evolve/runs/cycle-<N>/` for this cycle. They are minted per cycle and are how the cycle proves itself, so treating them as foreign is a bookkeeping error.
  - `go-build-metadata`: `go/go.mod`, `go/go.sum` and `go/.apicover-enforce`, and only when a declared path is a `.go` file. A new internal package must be enrolled in `.apicover-enforce` or the coverage gate reds, so carving that line lands the package with its own gate disabled. Without the Go-cycle condition every cycle could edit the module graph. Pinned by `TestDefaultClosureRules_CoverBuildMetadataAChangeMechanicallyRequires`.
- **`Classify` precedence is fixed and not negotiable by the producer**: in scope, then protected (boundary, refused, preserved), then computed closure (kept), then sibling lane (cross-lane, carved), then the declared class, defaulting to `opportunistic`. A declared `closure` no rule confirms is downgraded to `opportunistic`, because honouring it would make "necessary collateral" a universal passphrase. The result is a proposal: an adjudicator may move a discovered defect from carve to keep with a reason, never a boundary refusal. Pinned by `TestClassify_ClosureIsComputed_UnconfirmedClaimsAreDowngraded` and `TestClassify_ProtectedSurfaceIsPolicyNotMerit`.
- **The reason floor is inverted: strip the category's vocabulary and require something substantive to remain.** `categoryVocabulary` is the language a reason can be built from while saying nothing: the category, its negations, and filler. A reason is LLM-authored, so paraphrase is the normal case, and a denylist of set phrases cannot keep up with it. `reasonWordRE` treats hyphens and slashes as separators, so `out-of-scope` and `n/a` tokenise to their parts and the compound spelling cannot walk past a vocabulary built from the simple one. The floor applies to every disposition: a refusal must name a risk, a keep must say why the surface belongs in this cycle, and a carve must also name its patch. Pinned by `TestEntry_Validate_ReasonMustSayMoreThanTheCategory`, `TestEntry_Validate_RejectsScopeAsItsOwnJustification`, `TestEntry_Validate_KeepAlsoNeedsAReason` and `TestEntry_Validate_CarveMustNameItsDestination`.
- **`Summary` is the feedback half.** Enforcement alone repeats the repo's meta-defect, diagnosis that never becomes a queued fix. `TaskStatementSuspect` is set when `misunderstood` paths are a strict majority of the delta: the item was ambiguous, re-dispatching the same agent against the same wording reproduces it, and the fix belongs in triage. One misread path is noise. The zero value is usable and an empty delta never sets it. Pinned by `TestSummarize_SurfacesScopeMisunderstandingAsATaskDefect`, `TestSummarize_DominanceIsStrictMajority` and `TestSummary_ZeroValueIsUsable`.
- **`Account` is the one seam: is every changed path decided, and is every decision defensible.** Callers use it; `Unaccounted` stays exported for the narrower question and for tests that want the halves apart. For each entry it refuses a second, contradictory decision for the same path; re-derives a declared `closure` against the rules and a declared `in-scope` against the scope; runs `Validate` (is the decision stated properly); and runs `Admissible` (does the evidence carry it). Every failure lands in `Invalid` and names its path (`TestAccount_ErrorsNameTheOffendingPath`). `OK` requires both lists empty, and the zero `AccountResult` is the clean answer.
- **A path that carries an entry is never unaccounted, even when the entry is invalid.** It was decided, badly, and "you never decided this" would send the operator after the wrong defect; the invalid entry blocks just the same. Pinned by `TestAccount_ReportsUnaccountedAndInvalidTogether`.
- **`SurfaceOf` separates the judged (`subject`) from the judging (`signal`), D2.** It is deliberately coarse and over-inclusive: a false signal costs an honest change one extra corroboration, while a false subject is a cheat that never had to prove anything. Signal paths are:
  - prefixes: `go/acs/` (acceptance predicates), `agents/` and `.agents/` (the grading personas), `skills/` (the procedures reviews follow), `.evolve/policy` (the dials gates read), `.evolve/profiles` (permission profiles), `.evolve/runs/` (graded artifacts and their evidence), `.evolve/evals/` (eval definitions), `go/internal/policy/` and `go/internal/config/` (the compiled gate defaults the JSON only overrides), `go/internal/guards/` (live deny hooks), `go/internal/core/` (the phase state machine and escalation), `go/internal/phases/audit/` (the phase that grades), `go/internal/phases/ship/` (the phase that admits), `.github/workflows/` (CI);
  - basename suffixes: `_test.go`, `.jsonl`, `-baseline.json`, `predicates_test.go`, and the gate configuration `.apicover-enforce`, `go.mod`, `go.sum` (an enrollment edit can silently disable another package's coverage gate; the code keeps a one-line why for this, since no test pins it);
  - gate code anywhere: a path containing `/gate`, `/phases/ship/` or `repocontract`, or a `_gate.go` file.
  `TestSurfaceOf_SeparatesTheJudgedFromTheJudging` mixes product code into its fixture on purpose, so the distinction stays about a file's role, not its package.
- **`Effect` is the direction a change moves the bar, D3.** `EffectUnknown` is the zero value and the honest default: direction is not always mechanically decidable, and a guessed `tightens` would put a confident label on the judgement an adjudicator needs to make (`TestSurface_AndEffectUnknown_AreTheHonestDefaults`).
- **`Corroboration` is evidence from outside the author, D1 and D4**, every field something a third party can re-run or look up: `FailsWithout` with the verbatim `Command` that reds without the change; `QueuedItemID`, a pre-existing inbox item, whose value is the ordering (the finding existed before this agent claimed it); `CoverageLine`, a profile line proving a new branch executes.
- **`Admissible` gates only `KEEP`.** Carve and refuse preserve the work without shipping it, so being wrong about them costs nothing. For a keep: `closure` and `in-scope` skip the evidence layer (closure is established by a rule the producer cannot influence; in-scope work is not a delta); a signal-surface keep must declare its direction, and one that loosens is never admitted on the producer's word, so it is carved for a pass with nothing riding on the outcome; every other keep needs corroboration, and `FailsWithout` without a command is rejected. Pinned by `TestAdmissible_ComputedClosureNeedsNoFurtherProof`, `TestAdmissible_InScopeWorkIsNeverAskedToCorroborate`, `TestAdmissible_UnknownDirectionOnASignalSurfaceIsNotSafe`, `TestAdmissible_LooseningTheJudgingApparatusIsNeverKeptOnTheProducersWord` and `TestAdmissible_KeepRequiresCorroborationFromOutsideTheAuthor`.
- **`GamingSignals` reports shape across the whole delta.** A single "I fixed an adjacent bug" is unfalsifiable, and sometimes true; a delta mostly aimed at the apparatus, mostly loosening, or mostly resting on narrative-only keeps describes its producer however each entry reads. Signals are strict majorities, never presences, and a delta under three entries reports nothing, because the modal honest delta is one covering test and a signal that fires routinely is one operators learn to skip. `closure` and `in-scope` entries are not evidence about intent and are not counted. Pinned by `TestGamingSignals_SurfaceThePatternNoSingleEntryShows` and `TestGamingSignals_DoNotFireOnTheModalHonestDelta`.

## Invariants

- **Never drop.** A changed path that is neither in scope, nor covered by a closure rule, nor carried by an entry is `Unaccounted`, and a non-empty result is a pipeline defect the caller blocks on, the scope counterpart of an unaccounted defect disposition. An entry that does not validate never makes a path accounted-and-shippable. Pinned by `TestUnaccounted_IsTheWholePoint` and `TestAccount_UnvalidatedEntriesDoNotCountAsAccounted`.
- **The record cannot overturn policy.** `Validate` rejects a `boundary` entry with any disposition but `refuse`. Pinned by `TestEntry_Validate_BoundaryRefusalIsNotNegotiable`.
- **Closure is computed, never claimed, at the admitting seam too.** `Admissible` trusts a producer-supplied class, so it must never be the only check between a declared class and a ship; `Account` re-derives `closure` and `in-scope` first. Pinned by `TestAccount_DeclaredClosureIsReDerived`.
- **One path, one decision.** Contradictory duplicate entries are invalid instead of whichever the consumer reads first deciding what ships. Pinned by `TestAccount_RefusesContradictoryDuplicateDecisions`.
- **Well-formed is not supportable.** An entry that passes `Validate` but fails `Admissible` still blocks. Pinned by `TestAccount_InadmissibleKeepsBlockTheShip`.

## Findings

- A denylist of "out of scope" phrases was bypassed by ordinary paraphrase ("not this cycle's scope", "different scope", "unrelated"); the inverted vocabulary floor replaced it.
- A `Protected` directory written without its trailing `/` used to be an exact-path rule no file matched, so the whole protected surface fell through to carve: fail-open on the one class that is policy.
- `Unaccounted` alone counted an entry as accounted merely for existing, so a carve naming no patch satisfied the invariant it was meant to violate; the never-drop invariant held only by caller discipline until `Account` joined the two questions.
- A majority rule without a floor degenerates to a presence rule at one entry and fired on the commonest honest delta.
