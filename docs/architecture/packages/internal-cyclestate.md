# internal/cyclestate

> Related: [ADR-0072](../adr/0072-system-failure-policy-and-halt.md) (system failures and the fail-reason carriers), [ADR-0049](../adr/0049-concurrent-multi-cycle-execution.md) (the `UpdateState` lock, revision counter and allocation lease), the cycle outcome and allocation rows of [runtime-reference.md](../../operations/runtime-reference.md), [setup-onboarding.md](../setup-onboarding.md) (the setup marker's raw merge), [retry-hooks-and-spine-telemetry.md](../retry-hooks-and-spine-telemetry.md) (spine fail-opens), [internal-dossier.md](internal-dossier.md) (how `CycleResult` reaches the dossier) and [internal-triagecap.md](internal-triagecap.md) (the throughput window). This page keeps the package-level detail those do not.

## Purpose

`internal/cyclestate` is the cycle's shared vocabulary and on-disk state. It holds the `Phase` identity and its constants, the per-phase verdict and cycle-outcome labels, the DTOs serialized to `.evolve/state.json` and `.evolve/cycle-state.json`, and the execution-result records (`CycleResult`, `TokenUsage`, `Diagnostic`) the orchestrator builds as a cycle runs. Every concurrent lane of a fleet batch reads and writes these types.

## Design

- **Zero-dependency leaf.** These are the most-depended-on symbols in the module. They were hoisted out of `core` so the foundation everything imports depends on nothing (the Stable Dependencies Principle) and cannot pull an import cycle through the graph. The package imports only the standard library. `core` re-exports the symbols through type aliases, const re-declarations and a thin `IsVerdict` wrapper, so older call sites did not change and new code may import the leaf directly.
- **Pure data.** No I/O, config, routing or git. Persistence and mutation live in `core` (the Storage and Ledger ports) and in `internal/triagecap` (the throughput window). The cycle state machine stays in `core`, because its transition rules depend on router and config.
- **Single-source projections beside the vocabulary.** `ErrorMessages` and `ErrorCodes` are the only projections from diagnostics to a FAIL's reasons and codes. Core's failed record, floor fail reasons, chokepoint log line, seal backfill, judgment lessons and `cyclehealth` all call them, so no reader derives the rule differently. `RefusalDisposition` is the only table saying whose fault a coded triage refusal is, so a new code decides its own fate where it is declared. See [phase-timing-and-diagnostics.md](../phase-timing-and-diagnostics.md) and [the triage refusal incident](../../incidents/2026-09-14-triage-refusal-poison-loop.md).
- **`PhaseDebugger` is off the spine.** The advisor may insert it when a phase (usually ship) returns a structured error. It diagnoses the cause and emits a `RESHIP`, `RERUN_PHASE` or `BLOCK` decision that the orchestrator executes.

## Invariants

- **Wire strings are a byte-identity boundary.** Ledger and state JSON and the EGPS gate match the phase, verdict, outcome, termination, classification and diagnostic-code strings verbatim. Pinned by `TestPhaseConstants`, `TestVerdictConstants`, `TestCycleOutcomeConstants`, `TestCycleTerminationTriageNoWork`, `TestClassificationMidExecutionFail_IsTheLegacyDefaultSpelling` and `TestDiagCodes_TriageRefusalVocabulary`. `IsVerdict` and `Phase.IsValid` are exact-match, so a typo is rejected rather than normalized (`TestIsVerdict_Rejects`, `TestPhaseIsValid_Unknown`).
- **The JSON shapes are stable.** The ledger SHA chain and the resume path depend on stable bytes, and resume trusts `cycle-state.json` wholesale. Fields added after release are `omitempty`, so older files decode and re-encode unchanged. Pinned by `TestState_RoundTrip`, `TestCycleState_RoundTrip`, `TestStateOmitempty`, `TestCycleState_ShippedRoundTripsAndIsOmittedWhenFalse`, `TestSpineFailOpen_JSONShapeIsTheOperatorSurface`, `TestDiagnostic_CodeIsOptionalOnTheWire` and the `*_Wire` tests in `result_test.go`.
- **`State` is a subset view.** The orchestrator's `WriteState` drops every key it does not model, so writers of foreign keys (the setup marker) use a lossless raw merge instead. Pinned by `TestApply_LosslessMerge_PreservesForeignKeys` (`internal/setup`) and `TestUpdateState_PreservesUnmodeledKeys` (`internal/adapters/storage`).
- **`StateRevision` counts serialized writes.** Every `Storage.UpdateState` read-modify-write increments it once under the lock, so a gap or a repeat exposes a writer that bypassed the lock. Pinned by `TestUpdateState_InProcessConcurrentMutators_ZeroLostUpdates`, `TestUpdateState_TwoProcessStress` and `TestUpdateState_RevisionOmittedAtZero` (`internal/adapters/storage`).
- **The allocation lease never rolls back.** `LastAllocatedCycleNumber` is the highest number ever minted and `LastCycleNumber` the highest completed. The lease is bumped through `UpdateState` before a run starts, so concurrent allocators get distinct numbers and a crashed run burns its number. Pinned by `TestAllocateCycleNumber_ConcurrentAllocatorsDistinct`, `TestAllocateCycleNumber_CrashBurnsNumber` and `TestPersistCycleEndState_NeverRollsBackLease` (`internal/core`).
- **The ship latch is the cycle's own.** `CycleState.Shipped` is set only when this cycle's ship phase PASSes review, and `SHIPPED_VIA_BUILD` reads only the latch. Main HEAD movement is never evidence, because a sibling lane moves it too. Pinned by `TestRunCycle_EmptyTriageCommitmentSurvivesSiblingLanding`, `TestRunCycle_ShipPassPersistsTheShipLatch` and `TestCompleteCycle_ForwardsTheShipLatchToTheOutcomeLabel` (`internal/core`). `PreCycleHEAD` keeps the closeout baseline across a pause after ship for the same reason.
- **Audit dispatches are counted before the checkpoint write.** `AuditDispatches` counts dispatches, not completions. It is incremented before the pre-phase `cycle-state.json` write, so a round interrupted after the auditor pre-wrote `acs-verdict.json` is already on disk, and a resume retires that dead attempt's verdict. A completion-derived count backstops checkpoints that predate the field. Pinned by `TestSupersedePreviousAuditRound_AdvancesThePersistedDispatchCounter` and `TestResumedCrashedAudit_RetiresTheDeadAttemptsVerdict` (`internal/core`).
- **Retry bounds live in cycle state, not orchestrator memory.** `AuditRepairAttempts` and `BookkeepingRegradeAttempted` survive a crash-resume. An in-memory counter would reset and hand a failing cycle unlimited retries or a second regrade (`TestDecideAfterRetro_RegradeOncePerCycle`). `AuditRepairActive` is separate from the monotonic counter because gating the repair brief on the counter leaked a stale rejection into later `Ship→Build` and `Debugger→TDD` re-entries. Each field keeps a one-line why in code.
- **Fail-reason carriers are orchestrator-owned.** `AuditFailReasons`, `ShipFailReasons` and `BookkeepingRegradeAttempted` are written in-process from the runner's own gates, never read from an agent-writable workspace file. That is the trust boundary the ADR-0072 coherence floor needs to tell a diagnosed task FAIL from a forged verdict. They are persisted so a crash between the verdict record and finalization resumes without a false halt. Each field keeps a one-line why in code.
- **`ShipRecoveryCode` and `AuditDeclineReason` are persisted** so the live loop and a crash-resume seed the standing-audit-findings brief identically. The in-process context snapshot does not survive a resume. Pinned by `TestSeedAuditRepairContext_ShipRecoveryRebuildCarriesStandingFindings` and `TestSeedAuditRepairContext_RetroRoutedReentryCarriesStandingFindings` (`internal/core`).
- **Skipped and not-adopted are distinct.** `SkippedPhases` holds phases that did not run. A phase that ran and returned non-PASS after the floor-derived `FinalVerdict` goes in `VerdictsNotAdopted` and may not overwrite that verdict. Pinned by `TestVerdictNotAdopted_Wire`.
- **Spine fail-opens accumulate.** Repeats are never collapsed, because the count is the signal. Pinned by `TestCycleResult_AccumulatesSpineFailOpens`.
- **Refusal dispositions.** A code that names an item charges that item's `failure_count`. `TRIAGE_PROTECTED_SURFACE` also routes its subject to the operator on the first hit. `TRIAGE_COMMITMENT_INVALID` is stamped on I/O faults reading the triage decision, so it never charges the queue. An unknown or empty code charges nobody. Pinned by `TestRefusalDisposition_TableBesideTheVocabulary`.
- **`ClassificationMidExecutionFail` stays outside failurelog's taxonomy.** `NormalizeLegacy` maps it to the unknown class, so records carrying it age out on the one-day `LegacyEffectiveTTL`. That was an operator decision ([03b](../decomposition/03b-failure-learning-engine.md)). Pinned by `TestClassificationMidExecutionFail_IsOutsideTheTaxonomy` (`internal/failurelog`) and `TestRecurrence_DenylistNamesTheEnginesDefaultClass` (`internal/recurrence`).
- **`CarryoverTodo.CyclesUnpicked` is dead.** It is written as 0 and never incremented. Per-task failure memory is the inbox item's `failure_count`. It stays for wire compatibility, and no new reads should be added ([queue audit](../../operations/queue-audit-2026-08-27.md)).

## Findings

- **cycle-1022**: an audit's floor-override reason was recorded on disk (`audit-fail-reason.json`) while every operator-facing surface stayed silent. That added `CycleResult.FailReasons`, which carries the untruncated reasons into the cycle summary and dossier.
- **cycle-802**: a retro FAIL under quota or timeout pressure overwrote an audit PASS and zeroed the wave. That added the floor guard and `VerdictsNotAdopted` ([internal-dossier.md](internal-dossier.md)).
- **dossier-retro-skipped-mislabel**: FAIL dossiers claimed retro was skipped while the run directory held retro's report, because ran-but-declined verdicts were written into `SkippedPhases`. That split the two records ([retry-hooks-and-spine-telemetry.md](../retry-hooks-and-spine-telemetry.md)).
- **cycle-1166**: a width-3 batch emitted 76 spine fail-opens to stderr only. That added `SpineFailOpens` and the per-cause `MissingArtifact` and `Reason` fields ([retry-hooks-and-spine-telemetry.md](../retry-hooks-and-spine-telemetry.md)).
- **cycle-1603**: a crashed audit's pre-written verdict was honored on resume, because a completion-derived round index could not see the dead attempt. That added `AuditDispatches` ([incident](../../incidents/2026-09-02-repair-round-stale-acs-verdict.md)).
- **cycle-1630**: an empty-commitment cycle was labeled `SHIPPED_VIA_BUILD` because a sibling lane moved main HEAD. That replaced the HEAD delta with the `Shipped` latch ([incident](../../incidents/2026-09-12-shipped-via-build-sibling-landing.md)).
- **cycle-1329**: a green audit and green ACS cycle that failed at ship was misread as a forged verdict. That added `ShipFailReasons` ([ADR-0072](../adr/0072-system-failure-policy-and-halt.md)).
- **cycles 1634/1636**: a reasoned FAIL (triage's protected-surface rejection) sealed as "phase-infra class". The seal, the chokepoint log line and `cyclehealth` now all read a phase's diagnostics through the one projection `ErrorMessages`, kept beside the severity vocabulary ([phase-timing-and-diagnostics.md](../phase-timing-and-diagnostics.md)).
- **cycle-156**: builders commit in the worktree, so crash-resume needs the persisted `WorktreeBaseSHA` to run the build-commit normalize ([incident](../../incidents/cycle-156-builder-commit-vs-audit-pending-diff.md)).
