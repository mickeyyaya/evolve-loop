## Purpose

`internal/fleet` plans and runs concurrent evolve cycles ("lanes"). It partitions a backlog into file-disjoint lane specs (`Partition`, `PlanCycles`, `PlanWaves`, `PartitionGraph`, `PlanFromTriage`), launches them (`Supervisor`, `RunPool`), gates them at dispatch (`FreshenSpecs`, `PreflightControlPlane`, `QuotaAwareCount`), watches realized width (`StarvationTracker`), and composes PASS lanes for landing (`PrefixQueue`).

## Design

- **Fleet mode is an env contract.** Every launch path forces `EVOLVE_FLEET=1` (`ipcenv.FleetKey`) on a copy of the spec env and advertises the effective width in `ipcenv.FleetWidthKey`, which `core.shipRecoveryBudget` uses to scale contention-class ship retries. Under fleet mode the orchestrator skips the whole-cycle project lock. Per-resource flocks (`state.json`, the ledger chain, `.evolve/ship.lock`) serialize the shared writes, and each cycle's own worktree, `run.json` reads and run-scoped audit binding keep it isolated (ADR-0049 S2–S6).
- **Scope travels twice.** A spec carries its todo ids in `Scope` and as a comma-joined list in `ipcenv.FleetScopeKey`. The launcher (`cmd/evolve` `execCycleLaunch`) passes `Env` verbatim and `core.materializeLaneScope` pins `lane-scope.json` from that list, so code that edits `Scope` must rebuild the list too.
- **`OutputContract` is the lane's goal prose.** It reaches the launched cycle as `--goal`, so the scout does the planned work instead of choosing its own task. `combinedContract` keeps a single todo's contract verbatim and labels each contract `[id] text` when file-sharing todos merge into one cycle. A todo with no contract stays in scope but adds no line; an all-empty group yields `""`, and the cycle keeps the generic goal-hash goal.
- **Three partitioners, one ownership rule.** A normalized file (`filepath.Clean`) belongs to at most one concurrent lane.
  - `Partition` (the flat `evolve fleet --plan` path and the wave seed) is a greedy pass. A todo whose files are all free goes to the least-loaded bucket; one that overlaps exactly one bucket joins it; one whose files span two or more buckets is deferred to a later wave. `place` claims every file of the todo, free ones included, so no other bucket can claim them later.
  - `PlanWaves` (campaigns) levels the `depends_on` DAG through `dag.Levels`, then union-finds the todos of each level that share a file, transitively, into one cycle. Inside a wave it merges instead of deferring. Groups are ordered by their earliest member, and a group is `Optional` only when every todo in it is.
  - `PartitionGraph` (rung 1 of the merge ladder) runs `Partition`'s rule over transitive module-internal package sets from `go list -deps`, called once per containing directory. Only module-internal imports count, so a shared stdlib import never conflicts. A todo that touches a global-zone file (`go.mod`, `go.sum`, `.evolve/policy.json`) conflicts with every bucket already holding work, and every later todo conflicts with the global-zone bucket.
- **`PlanFromTriage` source precedence.** `committed_floors`, else the caller's card packages, else `top_n[].id`. The sources are never merged. Only `top_n` cards can declare `files[]`; floors and packages are bare strings whose id is their footprint, so they stay one-todo islands. A repeated id collapses to one todo. `TodosFromTriage` is exported so the pool path (`cmd_loop_pool.go`) rolls the same backlog the wave path partitions.
- **Plan-time routing gate.** `RoutedFn` is the ADR-0074 authority. A console-routed id is refused and returned as `id: reason`, never planned into a lane. The gate sits here because `top_n` is the selection-to-dispatch handoff that both schedulers and the wave-seed fallback read; prompts only advise. Composition roots pass `inboxbatch.RoutedResolver`; `nil` means no routing context.
- **Wave barrier and rolling pool.** `Supervisor.Run` launches a batch under a semaphore and waits for every lane, so realized width is the minimum over time whenever lane durations are skewed. `RunPool` backfills the moment any lane exits, choosing the highest-`Priority` pending todo whose files are disjoint from every running lane (lowest backlog index breaks ties). It runs fewer lanes when nothing is disjoint, never zero while work remains. `poolSpec` mirrors `PlanCycles`' single-todo spec and forces fleet mode, so a pool dispatch is the same isolated seam as a wave dispatch. `Concurrency` can only lower the pool's width below `Target`.
- **I/O-free telemetry.** `PoolTransition` is data. The caller formats the `lanes live: N/target` line, the same idiom as `policy.FleetConfig.Warnings`.
- **Dispatch freshness gate.** `FreshenSpecs` re-probes every scope id right before launch. A stale id is dropped with one WARN line. A spec that loses its whole scope frees its slot, and `RefillFn` fills it from the pending backlog; refill candidates are probed too. The exclude set holds every id the wave owns (kept and skipped) plus each candidate tried, so a refill never duplicates a lane, never resurrects a skipped id, and the loop is bounded. An empty backlog leaves the slot empty: a shorter wave, never a doomed lane. `ClassifyEmptyScopeBuild` turns an honest "no in-scope work" build after the gate into `SKIPPED`, never `FAIL` and never `PASS`.
- **Control-plane preflight.** `PreflightControlPlane` runs `git status --porcelain --untracked-files=all` in the main checkout and refuses the wave when any path, including both sides of a rename, is `guards.IsProtectedSurface`. `--untracked-files=all` names a new protected file inside a new directory individually. The helper lives here rather than in `internal/guards` because `guards` is itself protected surface: a cycle editing it would trip its own integrity gate.
- **Quota shrink.** `QuotaAwareCount` takes the caller's intersection of the `clihealth` benches with the families the wave needs, and does no probing of its own. Each benched family costs one lane, down to the min-lanes floor clamped to `[1, count]`. Every benched family gets one WARN, sorted for determinism: either the shrink or "capacity held" at the floor.
- **Starvation observer.** `WaveObservation.Starved` means fewer lanes realized than desired without a quota shrink. The caller holds one `StarvationTracker` outside the per-wave loop so the streak spans waves, and calls `Observe` only on the wave-ran path. The k-th consecutive starved wave fires and resets the streak. `BuildStarvationItem` builds one weighted inbox todo whose id (`fleet-work-supply-starvation`) is independent of the cycle, so a re-fire overwrites the single open todo.
- **Prefix-queue composer.** ADR-0078 holds the model. In code, `groups()` splits the FIFO so that a `TierIffy` lane, or a lane sharing a file with the current group, starts a new group; `ComposePrefixes` emits cumulative prefixes per group; `ResolveCulprit` extends a known-good set one lane at a time (one verify per lane), then re-verifies the whole landed set and trims from the tail until it is green. `ParseLandingMode` rejects an unknown value; `internal/policy` owns the fail-safe fallback to `per-lane`.

## Invariants

- **Cross-lane file disjointness.** Two concurrent lanes never own the same normalized file, because they would collide on the shared tree at ship time. It holds per wave only: a file may reappear in a later, dependency-ordered wave. Pinned by `TestPartition_CrossBucketFileDisjoint`, `TestPlanWaves_WaveLevelFileDisjoint` and `TestRunPool_CollidingFilesNeverCoRunButAllEventuallyDispatch`.
- **Package-graph neighbours are never split.** Todos whose transitive package sets meet, or where either touches a global-zone file, land in one bucket or are deferred (`TestPartitionGraph_PackageGraphConnectedTodos_NeverSplitAcrossBuckets`, `TestPartitionGraph_GlobalZoneFile_ConflictsWithEveryBucket`). Unrelated packages still spread, since conflicting everything would defeat the fleet (`TestPartitionGraph_UnrelatedPackages_StillSpreadAcrossBuckets`).
- **Deterministic placement.** The partitioners keep input order and break ties to the lowest index, so the same backlog always yields the same lanes.
- **No idle lanes.** Empty buckets yield no spec, so a backlog that cannot fill `count` lanes launches fewer. `n < 1` and a non-positive count clamp to one bucket.
- **The caller's env is never mutated.** `Supervisor` and `filterScope` copy the map before writing (`TestSupervisor_DoesNotMutateCallerEnv`, `TestFreshenSpecs_PrunedSpecRewritesFleetScopeEnv`).
- **A pruned spec's scope list and contract follow its `Scope`.** `filterScope` rebuilds the `FleetScopeKey` list and drops the pruned todo's labeled contract lines. Unlabeled continuation lines inherit the fate of the label above them (`TestFreshenSpecs_PrunedSpecDropsStaleContractLine`, `TestFreshenSpecs_MultiLineStaleContractFullyDropped`). A single-todo contract carries no label, but pruning its only id frees the whole lane, so that shape never launches.
- **Fail loud, never a silent no-op.** A nil `LaunchFn` gives every result `errNoLaunch` without spawning a goroutine. Malformed or wrong-typed triage JSON returns an error and no specs, so the caller falls back to the sequential path instead of launching an unscoped lane. An unverifiable tree fails the preflight. A file that does not exist fails `TransitivePackageSet`. `only()` panics on an empty set.
- **Per-cycle deadline.** A positive `CycleTimeout` gives each launch its own deadline, so a wedged child (a tmux REPL that never boots) is reaped instead of hanging the wave (`TestSupervisor_PerCycleTimeoutReapsHungLaunch`).
- **Pool admission does not depend on callback order.** `RunPool` claims a lane's files and counts it running before it starts the lane's goroutine. The `started` rendezvous and `runtime.Gosched` are scheduling hints only; launch callbacks stay concurrent and unordered.
- **`PrefixQueue` locking.** Every exported method takes `mu`. `groups()` does not lock and is only called with `mu` held, so there is no re-entrant lock. The composer is the single writer to main, but enqueues and AIMD reports arrive from several goroutines (`TestPrefixQueue_ConcurrentEnqueue_NoLostWork`; `go/acs/cycle982` also greps `prefixqueue.go` for the mutex).
- **`verify(landed)` always holds after `ResolveCulprit`.** Per-group NNFI proves each group green alone, but the union of green groups can still be red, since cross-group interactions are never speculated on. The tail trim ejects the newest landed lane, which may be innocent: blame is positional, not causal. Precise blame would need cross-group bisection, which the design gives up for a linear verify budget (`go/acs/cycle982` C982_005).
- **Starvation weight floor 0.9, enforced twice.** `policy.FleetConfig` and `BuildStarvationItem`/`Validate` both clamp or reject, so neither a bad config nor a bad caller can under-weight the todo. A quota-shrunk wave is never starvation (`TestStarvation_QuotaShrunkWaveNeverStarves`).
- **The min-lanes floor holds capacity through a bench**, and a floor above `count` clamps down to `count` (`TestQuotaAwareCount_MinLanesFloorHoldsCapacity`, `TestQuotaAwareCount_MinLanesClampedToCount`).
- **Routing gate coverage.** `committed_floors` ids pass through the same gate as cards, so the precedence source is not a bypass (`TestTodosFromTriage_RefusesRoutedCommittedFloor`). Unknown ids are dispatchable by the resolver's contract, because scout-originated work has no inbox item.

## Findings

- **Fleet trial #1** (cycle 467 scout H1): a dirty `.evolve/policy.json` in the main checkout killed an audit-PASSED lane at ship time. `PreflightControlPlane` moved the check to wave start.
- **D1 empty-plan livelock** (cycles 464–466): real triage decisions often carry only `top_n[].id` and no `committed_floors`, as the cycle-464 artifact did, so every wave planned zero specs and the empty-plan guard fired on every wave. The `top_n` fallback fixed it.
- **Cycle 523** (inbox `wave-seed-partitions-on-id-not-real-files`): `PlanFromTriage` used a card's id as its only file, so cards sharing a real file looked disjoint and ran as colliding lanes. Cards now carry `files[]`.
- **Batch bh1rt946t**: one early lane exit left the wave barrier one lane wide for the rest of the wave. Cycle 550 added `RunPool`.
- **Pool backfill test flake** (2026-09-09 here, 2026-09-11 in `cmd/evolve`): the tests inferred admission order from the order launch callbacks arrived, which Go does not guarantee. The fixtures now hold both initial lanes until both callbacks are seen. See [the report](../../reports/2026-09-11-pool-backfill-test-flake.md).
- **Width-3 batch of 2026-07-13** (cycle 767): about 3 of 8 failed lane slots were doomed at dispatch. One task had already shipped, one consumed task was re-picked because consumption raced dispatch, and one task with an unmet dependency was dispatched three times. The honest empty build of the shipped task was then failed by review. That produced the freshness gate and `ClassifyEmptyScopeBuild`. Lane menus (multi-id specs) later exposed the stale scope list and the stale contract line (diff-review HIGH-2, re-review MEDIUM-A).
- **Cycles 542–544**: the starvation observer was first built as a new `internal/fleethealth` package, which the ship gate failed because the package was missing from `go/.apicover-enforce`. It was re-landed inside this already-enforced package. `go/acs/cycle544` and `cycle548` pin that no `internal/fleethealth` exists and that `starvation.go` lives here.
- **Cycle 871** (merge rung 1): file disjointness misses merge skew, such as a rename in one package and a call-site edit in an importer. That produced `PartitionGraph` and the global-zone list.
- **Cycles 975, 981 and 982**: the prefix composer. Cycle 982 added the mutex after concurrent enqueues could lose a lane (the lost-work class of cycles 948/949), and added the whole-set re-verify after two solo-green iffy lanes whose union was red both landed (F2).
- **ADR-0069**: the acs-tagged cycle 975/981 predicates do not run under `go test ./internal/...`, so repo-wide apicover saw every `prefixqueue.go` export as uncovered and turned main red. `prefixqueue_apicover_test.go` gives each export default-tag coverage.
- **`fleet.min_lanes`** (2026-07-03): without the floor, one benched family collapsed a two-lane wave to one lane even when a healthy family could carry both.
- **Unbounded cycle wait**: the [large-scale readiness audit](../../research/loop-largescale-readiness-audit-2026-06-21.md) listed a wave that waits forever on a wedged child as a blocker. `CycleTimeout` closed it.
- **Dropped contract**: the `OutputContract` was once lost between `Todo` and `CycleSpec`, which left the scout free to pick work that did not advance the campaign. `PlanWaves` and `PlanCycles` both thread it now (`TestPlanWaves_ThreadsOutputContract`, `TestPlanCycles_ThreadsOutputContract`).
