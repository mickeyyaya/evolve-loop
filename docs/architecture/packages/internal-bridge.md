## Purpose

`internal/bridge` launches and drives the LLM CLIs a phase runs on (claude, codex, agy, ollama), headless or inside a tmux REPL. It realizes a phase's launch intent into per-CLI flags from embedded manifests, answers or escalates the interactive prompts a REPL raises, detects walls and wedges, and records each launch attempt's telemetry.

## Design

*File group 1: `attempt_telemetry.go`, `autorespond.go`, `billing.go`, `bootsmoke.go`, `budget_scale.go`, `capture_models.go`, `catalog_overlay.go`, `clicontrol_adapter.go`, `codex_model_clamp.go`, `codex_pretrust.go` and their tests.*

### Auto-responder (`autorespond.go`)

The auto-responder is the fallback prompt engine for interactive REPLs, a port of `lib/auto-respond.sh`. `--dangerously-skip-permissions` is the default permission strategy; the responder is the safety net for the prompts that escape it: auth rechecks, rate limits, model deprecation, trust dialogs, plan mode and the like. It has two layers:

- `decideAutoRespond` is pure: pane, manifest `interactive_prompts`, and per-rule match counts in; an action and an rc out.
- `autoResponder.tick` / `tickPane` is effectful: capture the pane (or take the wait loop's capture), decide, then send keys or write `escalation-report.json`.

The action and rc contract `runTmuxREPL` consumes:

| Action | rc | Meaning |
|---|---|---|
| `noop` | 0 | nothing matched |
| `suppress_once:<name>` | 0 | only a handled fire-once prompt still matches; the caller warns once |
| `send:<csv>` | 1 | keys were sent (the caller sees `""`, 1) |
| `extend:<secs>` | 2 | push the artifact-wait deadline |
| `transient_dwell` | 3 | a transient upstream error held for the dwell (enforce stage only) |
| `escalate:<name>` / `escalate:exhausted` | 85 | escalate policy, missing or invalid keys, or a confirmed quota wall |
| `loop_guard:<name>` | 86 | one rule matched more than 5 times in the launch |

The loop guard counts every match of the same rule across the launch, not consecutive sends; [full-tmux-control.md §2a](../full-tmux-control.md) describes it as "5 consecutive sends without pane progression", which is looser than the code.

Rule selection:

- The first manifest rule whose regex matches wins, so manifest order is part of the contract. A rule with `tail_lines` matches only the tail of the capture, where a live modal sits.
- An `escalate` match on a busy pane is skipped: a CLI cannot be blocked on a prompt while it is generating, so the match is the agent quoting a banner ([ADR-0047](../adr/0047-surface-classification-and-channel-separation.md)). Only `escalate` is gated; approvals and menus render beside their own "esc to cancel".
- A `once: true` rule fires one time. Its dismissed text lingers in the re-captured scrollback, so later matches are skipped without counting toward the loop guard, and the scan continues so a new prompt still fires.

Pane treatments, applied before matching:

- `decideAutoRespond` strips agent diff lines: a numbered editor diff line or a bare `+`/`-` line. `+++`/`---` headers pass. CLI chrome is never diff-prefixed.
- `tickPane` strips prompt-echo lines, a line whose trimmed text is a substring of the injected prompt, before both the prompt match and the exhaustion scan. An empty prompt strips nothing.
- `strippedForExhaustionScan` (echo strip, then diff strip) is the one treatment both exhaustion scans use: the tick fast path and the stop-review checkpoint in `driver_tmux_repl.go`.
- `strippedForFatalPaneScan` delegates to `recovery.StripAgentContent`; see [internal-recovery.md](internal-recovery.md) for why it differs.
- The raw pane is kept for pending-send resolution, shadow rules, the busy probe and the escalation report.

The busy read goes through `LivenessCenter.BusyOf`, which is nil-safe and stateless, so the tick never disturbs the stop-review checkpoint's `Observe` baseline and the Center stays the only liveness facade ([ADR-0068](../adr/0068-bridge-signal-center-concurrency.md)).

Each tick also runs three detectors on the stripped pane:

- **Quota wall.** The manifest's `exhausted_regex` is checked through `LivenessCenter.ExhaustedOf`, ungated by busy, and overrides a lesser verdict because the artifact will never come. A wall must persist for consecutive observations (`exhaustion_persistence.go`), then one live probe corroborates it (`wallcorroborate.go`; the production corroborator is wired in [internal-adapters-bridge.md](internal-adapters-bridge.md)). A healthy answer disables the scan for the phase; a confirmed wall escalates `escalate:exhausted`.
- **Transient upstream dwell.** The manifest's `transient_regex` on a non-busy frame for 30 consecutive wait-loop observations (60s at the 2s cadence) records `would_fast_fail` in shadow and returns rc 3 in enforce (the recovery stage, `Deps.RecoveryStage`). Only the artifact wait loop enables it.
- **Shadow rules.** Promoted rules at shadow stage match observe-only and record `rule_shadow_fire` / `would_fire` once per rule per launch, the evidence the batch-end auto-enforce sweep reads.

Interaction telemetry ([ADR-0045](../adr/0045-corrective-interaction-protocol.md) I1): every send opens a pending outcome that the next capture resolves. The pattern clearing records `prompt_cleared`; the loop guard tripping on the same rule, or a new send while one is pending, records `no_effect`; a lingering fire-once prompt records `suppressed_lingering`; the run ending records `run_ended`. The recipe adapter's capability runs carry no recorder.

The AskBroker rung ([ADR-0045](../adr/0045-corrective-interaction-protocol.md) I3) runs before any rc 85: it extracts the blocking question through `panetrust` (typed extraction; the privileged path never branches on raw pane text) and asks the `KernelAnswerer`. In enforce it injects the answer once per launch and returns rc 1; in shadow it records `would_act` on every tick that reaches it; off, a nil broker, no typed question or a miss escalate as before.

Keys: `sendKeySequence` sends each comma-separated token as its own keystroke with a 500 ms pause through `Deps.Sleep`; an `Enter` token is a bare Enter. Human mode adds a reading pause and human-cadence typing.

The decision-matrix fixtures in `autorespond_decision_test.go` are verbatim panes from claude v2.1.150, codex v0.133.0 and agy 1.0.2, recorded in [tmux-repl-cli-behavior-2026-05-26.md](../../research/tmux-repl-cli-behavior-2026-05-26.md).

### Attempt telemetry (`attempt_telemetry.go`)

`recordModelAttempt` writes the one `llm-calls` ledger row per launch attempt (`llmcalls` owns the filename and I/O). It derives the attempt number (at least 1) and the call id once and returns the `attemptLogContext`, so every later signal of the same launch carries the row's identity. Usage status follows the resolver's source: transcript or events result is `measured`, scrollback peak is `partial`, anything else is `unavailable`, and a resolver error is `resolver_error`. Negative counters and a NaN or infinite fill are discarded with a warning. `launchWarn` is the only `bridge.warning` producer; `tripwire` emits `bridge.tripwire` when a successful non-claude launch runs past `tripwireSuccessThreshold` with no usage source. The ledger's cause code comes from `launchoutcome.CauseCode` ([decomposition unit 10](../decomposition/10-bridgeengine.md), [ADR-0101](../adr/0101-signal-center.md)).

### Codex launch preparation (`codex_pretrust.go`, `codex_model_clamp.go`)

- **Pretrust.** codex-tmux's `Preflight` runs `pretrustCodexProjects` and `dismissCodexUpdateNag` at the engine's `CLIPreflight` chokepoint, strictly before the driver's `Launch`, for the exact worktree of every launch: fresh, reused or resumed. A provisioning-time hook was rejected: it would duplicate the same write through a new core→bridge seam (core cannot import bridge) for no behavioural gain. The recipe path (`newRecipeDriver`) bypasses `CLIPreflight`, so it pretrusts codex-family CLIs itself.
- The pretrust appends `[projects."<path>"] trust_level = "trusted"` for the worktree and workspace, plus `[notice] hide_rate_limit_model_nudge = true`, to `~/.codex/config.toml`. The merge is append-only and idempotent. The directory is created 0700 and the file written 0600 through a unique temp file and rename. `dismissCodexUpdateNag` sets `dismissed_version` in `~/.codex/version.json` so the update menu never shows.
- **Model clamp.** A ChatGPT-subscription codex account rejects models outside its plan. `clampCodexModelForAuth` rewrites the effective model selector (split or inline `-m`/`--model`, or a `-c model=` override; a dedicated flag beats an override) to the manifest's `chatgpt_default_model` when the model is not in `chatgpt_safe_models`. Auth is `api-key` only when `OPENAI_API_KEY` is set and `BRIDGE_ALLOW_OPENAI_API_KEY=1`; the credential-isolation guard already demands that opt-in, so the env alone decides.

### Other surfaces

- **Boot smoke** (`bootsmoke.go`). `BootSmokeTest` runs a `*-tmux` driver's real `Launch` with `BootOnly` and bypass-equivalent posture, and exits without a prompt, so the boot is the one a phase launch performs. It returns `ExitOK`, `ExitREPLBootTimeout`, `ExitMissingBinary`, or `ExitBadFlags` for an unknown or non-tmux driver, plus the final scrollback. It self-provisions and removes a scratch workspace and boots in a scratch cwd. `evolve doctor boot` and the loop readiness gate both show its `ScrollbackTail`.
- **Boot handshake** (pinned in `boot_handshake_test.go`). Boot is ready only when the prompt marker is visible and the pane's foreground process is not a shell. The shell set is closed while CLI binary names vary (claude runs under node), so the check rejects a known shell rather than requiring a known binary, and a controller without `PaneCommander` degrades safely. After the paste, the first wait-loop pane showing shell-spill signatures with a shell process fails fast with `ExitREPLBootTimeout`; spill-lookalike text under the CLI process is ignored. The real driver constructors arm `guardDeadShell`; the RealTmux integration fixtures, whose REPL is a shell script, run with it unset. Mid-run process death is the observer's job.
- **Idle-artifact nudge** (pinned in `bridge_dialog_autorespond_test.go`). When a review checkpoint finds the agent idle with the artifact missing, the driver sends exactly one in-pane nudge naming the artifact path before the timeout path proceeds: the agent has often finished and not written the file.
- **Artifact budget scale** (`budget_scale.go`, [ADR-0076](../adr/0076-convergence-architecture.md) A). The orchestrator sets `BridgeRequest.BudgetScale > 1` for the build phase of a medium or large cycle; it stretches the artifact-wait budget. An unlisted agent scales from the driver's builtin `tmuxArtifactTimeoutS`, so the flag is exactly the default, stretched.
- **Model picker capture** (`capture_models.go`). `CaptureModelPicker` feeds modelquery's `RecipeLister`: send `/model` and Enter, poll up to six one-second ticks for a picker marker, send one extra Enter only while the picker is closed (codex's slash autocomplete swallows the first), and always finish with Esc. An ephemeral session is killed on a detached context. The live refresh passes a scratch `cfg.Workspace`, so escalation reports and ledger rows land outside the repo and are salvaged to `.evolve/models-probe`; `cfg.Worktree`, the session cwd, is deliberately left unset.
- **Catalog overlay** (`catalog_overlay.go`). `modelCatalogDirFn` resolves the catalog directory from policy's `bridge.catalog_dir`, else `.evolve`; `cmd/evolve` replaces it through `SetModelCatalogDirFn` rather than the environment. The parsed catalog is memoized per (dir, mtime) under a mutex.
- **CLI control adapter** (`clicontrol_adapter.go`). `cliController` is the production `clicontrol.Controller` and the one place the abstract `clicontrol.Event` becomes a concrete command: `Manifest.Control` maps the event, and `captureControl` boots or attaches the family's `*-tmux` REPL, sends the command and polls for the prompt marker. Each `Do` derives the family's config from a family-agnostic template (workspace, project root, bypass posture) through `RealizeFor`, so flags never bleed across CLIs. An unmapped event returns `ErrUnsupported` without booting.
- **Billing snapshot** (`billing.go`). Operator tooling off the cycle path: snapshot the credential-resolution state (a hash of the credentials file's token prefix, `ANTHROPIC_API_KEY` presence, `ANTHROPIC_BASE_URL`) before and after a call and compare for an unintended auth path. File and env signals only ([ADR-0021](../adr/0021-agent-bridge-go-port.md)).
- **agy model tiers.** agy takes `--model "<display name>"`; `launchCmdLine` shell-quotes the display names ([cli-capability-matrix.md](../cli-capability-matrix.md)).

## Invariants

*File group 1.*

- **Agent content never drives prompt matching.** Diff lines and prompt echoes are stripped and an escalate match on a busy pane is skipped, because an agent writing or quoting a banner is not the CLI showing it. Pinned by `TestDecideAutoRespond_AgentDiffContentNotChrome`, `TestDecideAutoRespond_BareDiffLineNotChrome`, `TestDecideAutoRespond_IndentedBareDiffLineNotChrome`, `TestDecideAutoRespond_IdleGatesEscalateWhileBusy`, `TestAutoResponderTick_BusyGateViaCenter_SuppressesEscalate`, `TestC654_004_EchoedExhaustionStrippedGenuineSurvives` and `TestC672_003_TickEchoedExhaustionDoesNotEscalate`.
- **The busy read goes through the liveness facade.** `TestAutoResponderTick_NoDirectChromeParse` reads `autorespond.go` between two code anchors (`prevCounts := make(...)` and the `decideAutoRespond(scanPane, ...)` call) and fails if that region calls `panestream.PaneBusy(` directly. The anchors must stay unique.
- **A fire-once rule never reaches the loop guard.** A lingering dialog would otherwise abandon the run it was added to protect. Pinned by `TestAutoRespond_TrustPromptFiresOnce`, `TestAutoRespond_FeedbackRatingFiresOnce` and `TestAutoRespond_ClaudeTrustDialog_v2252`. codex's plan picker is the exception: it asks several questions, so it stays multi-fire (`TestAutoRespond_PlanModeAnswersEveryLiveQuestion`).
- **Rules must not fire on this repository's own files.** The trust and plan-mode rules are bottom-anchored because this repo quotes those dialogs verbatim in tracked files an agent reads. `TestAutoRespond_TrustRulesDoNotMatchThisRepositorysOwnFiles` and `TestAutoRespond_PlanModeDoesNotMatchThisRepositorysOwnFiles` read `autorespond_decision_test.go`, `autorespond_planmode_test.go`, the manifests and the incident docs.
- **A quota wall needs persistence and exactly one corroboration.** Both probe answers latch, because tick callers that discard rc (the boot loop, the recipe adapter) would otherwise re-fire a quota-consuming probe every tick. Pinned by `TestExhaustion_TransientWallTextDoesNotFastFail`, `TestTick_RealWallProbesExactlyOnceAcrossTicks`, `TestTick_ContentWallSuppressedWhenCorroboratorSaysHealthy` and `TestTick_CorroboratedWallStillEscalates`.
- **A failed capture is no observation.** It can neither reset nor advance the transient dwell, and a busy pane is never preempted. Pinned by `TestRunTmuxREPL_TransientDwell_CaptureErrorsDoNotResetTheDwell`, `TestRunTmuxREPL_TransientDwell_BusyPaneIsNeverPreempted` and `TestRunTmuxREPL_TransientDwell_DoesNotFireBeforeSixtySeconds`. `transientDwellObservations` and `exhaustionPersistObservations` change together.
- **The AskBroker rung never suppresses rc 85 on a miss and injects at most once per launch.** Pinned by the `TestPre85Rung_*` tests.
- **Outcomes are never fabricated.** A pending send with no pattern waits for `flushPending`, and the run's end records `run_ended`.
- **The transient classifier reads the pane, never stderr, and its field is driver-authored** ([ADR-0090](../adr/0090-transient-disclosure-as-cause-data.md)): provider prose on the recorded cause would be a prompt-injection path. Pinned by `TestRunTmuxREPL_ArtifactTimeout_MarkerFlagsTransientOnLivePane`, `TestEveryTmuxFamilyDeclaresTransientRecognition` and `TestRunTmuxREPL_ArtifactTimeout_EchoedPromptIsNotTransient`.
- **One attempt-ledger writer, one cause-code site.** `TestRecordModelAttempt_ReturnsTheAttemptContext`; `TestLaunchOutcome_OneClassificationSite` requires `launchoutcome.CauseCode(` to appear in `attempt_telemetry.go` and no other non-test file.
- **The codex config read-merge-write runs under `flock.WithPathLock`.** Concurrent fleet cycles pretrust distinct paths into the one host-global file, and a lost update re-arms the trust modal for the losing cycle ([ADR-0049](../adr/0049-concurrent-multi-cycle-execution.md) N10). The lock prevents lost updates; the temp-file rename keeps lock-free readers tear-free. Pinned by `TestPretrustCodexProjects_ConcurrentTwoGoroutines`, `TestPretrustCodexProjects_ConcurrentCalls_AllEntriesSurvive` and the `codex_pretrust_amplify_test.go` tests. Preflight precedes `Launch` (`TestLaunchDispatchesPreflightBeforeDriverLaunch`), and the recipe path pretrusts itself (`TestRecipeDriverPretrustsCodexWorktree`).
- **A pretrust failure never blocks a launch.** Callers log the error and continue; the auto-responder stays the downstream defense.
- **The clamp never mutates its input, and the deep model must be in the safe set,** or the clamp would rewrite every deep launch to its default. Pinned by `TestClampCodexModelForAuth` and `TestCodexManifest_DeepTopTiers_ValuePin`.
- **The model picker is never confirmed.** The last keystroke is always Esc. Pinned by `TestCaptureModelPicker_OpensImmediately` and `TestCaptureModelPicker_NeverOpensErrors`.
- **A boot smoke never runs in the live checkout.** An empty worktree would fall back to `os.Getwd()`; `BootSmokeTest` applies a scratch cwd.
- **Only live catalog entries override dispatch.** A detect entry or an empty catalog leaves the manifest byte-identical. Pinned by `TestApplyCatalogTierMap_DetectDoesNotOverride` and `TestApplyCatalogTierMap_NoEntryIsByteIdentical`.
- **agy tier models carry an effort parenthetical in agy's word order.** agy accepts a bad name without error and serves another model. Pinned by `TestAgyManifestTierModelsAreNamesAgyAccepts` and `TestAgyTierModelsPinnedToVerifiedNames`.
- **Session names are unique under concurrent launches.** The atomic per-process nonce separates lanes that share a second-granularity timestamp ([ADR-0049](../adr/0049-concurrent-multi-cycle-execution.md) N15), and names carry a run-scope token. Pinned by `TestResolveSession_AgyConcurrent_UniqueUnderRace` and `TestResolveSession_AgyConcurrent_MixedRunsAndCycles`.
- **Source readers.** `go/acs/cycle17` requires `catalog_overlay.go` to contain `modelCatalogDirFn` and no `os.Getenv("EVOLVE_MODEL_CATALOG_DIR")`. `go/acs/cycle45` forbids `"EVOLVE_CODEX_VERSION_PATH"` in `codex_pretrust.go`. `go/acs/cycle50` forbids the quoted `"EVOLVE_CODEX_CONFIG_PATH"` in `codex_pretrust.go`, the four `codex_pretrust*_test.go` files and `preflight_test.go`. `go/acs/cycle1` requires `codex_pretrust_concurrent_test.go` to contain `EVOLVE_CODEX_CONFIG_PATH` unquoted and a `TestPretrustCodexProjects_Concurrent*` test, which is why that file's comment names the retired env seam.

## Findings

*File group 1.*

- **Agent content benched a CLI** (cycle 314, soak 4). A codex agent editing the clihealth parser typed "You've hit your usage limit" into a test fixture; the numbered diff line matched the escalate rule and benched codex for 30 minutes. That produced the diff-line strip and the busy gate. The residual, a bare `+`/`-` line lingering in idle scrollback, needed the bare-diff strip.
- **Prompt echoes benched passing phases** (cycles 641 and 642). An echoed Deliverable-Contract line and a reviewer checklist were read as a wall. The prompt-echo strip followed (helper in cycle 654, wired in cycle 672).
- **An underscore token is not a banner** (cycle 113). The old `rate.?limit` regex matched an agent grepping `rate_limit` detection code and killed the cycle mid-research.
- **Banner word order** (cycle 144). codex's ChatGPT banner "You've hit your usage limit. Upgrade to Plus…" failed a `(usage|rate)[ -]limit (reached|exceeded|hit)` regex because "hit" comes first, so codex sat until the artifact deadline. A bare "Upgrade to Plus to continue" is deliberately not matched: it is pricing text an agent may echo.
- **Lingering dialogs trip the loop guard** (2026-06-03). A dismissed codex trust dialog re-matched from a 200-line boot scrollback every poll until the guard abandoned the run with exit 86. That produced `once: true`, later applied to the CLI feedback-rating prompt.
- **Keystroke pacing** (2026-05-26). claude's multi-select (`Enter,Right,Enter`) intermittently failed to submit as a zero-gap burst and submitted every time with a 500 ms gap. The earlier CSV parser collapsed every Enter into one trailing Enter, which would submit a multi-select with nothing selected.
- **Probe re-fire** (the false-wall class, [incident 2026-08-15](../../incidents/2026-08-15-false-walls-and-repick-class.md)). Review found that without the latch, rc-discarding tick callers re-probed a confirmed wall every tick.
- **Capture errors held the dwell at zero.** Adversarial review reproduced a tmux server erroring every other tick: the empty pane read as a non-match, reset the streak, and the run burned the silence budget the dwell exists to cut short.
- **A marker over a dead shell read as ready** (cycles 274 and 277). codex's update menu exited to zsh and the pasted prompt spilled into `quote>` / `bquote>` continuations; the marker substring in scrollback declared the REPL ready and the phase wedged for 25+ minutes. That produced the boot handshake. Arming the guard unconditionally broke the Ubuntu CI RealTmux fixtures, whose REPL is a shell script, so only the real driver constructors arm it.
- **codex's permission modal** (cycle 122, [incident](../../incidents/cycle-122-codex-permission-modal-and-wsg-fallback-gap.md)) produced the pretrust. Its review found that a newline in a path would corrupt `config.toml` and stop codex from starting, hence the TOML escaper.
- **Subscription model rejection** (cycle 142). A codex auditor resolved to a model outside the ChatGPT plan; the 400 raised a "Switch to <fallback>?" modal the auto-responder does not dismiss, and the phase hung for the full artifact wait. That produced the clamp and the `[notice]` nudge suppression. A later rejection of the deep-tier model sat idle 20 minutes before exit 81 ([incident 2026-09-14](../../incidents/2026-09-14-codex-deep-tier-model-rejected.md)); the `model_unsupported` rule now escalates at once.
- **agy silently substitutes a model** (2026-08-28). The manifest said "Gemini Flash 3.7 (Low)" (transposed) and the live catalog said "Gemini 3.7 Flash" (no effort suffix). agy rejects both with one warning line and serves Gemini 3.5 Flash (Medium) for the whole session, exiting zero. Because the catalog overlays the manifest, router and memo ran that model at every tier for two weeks while every flag-shape assertion stayed green. agy's picker shows the family alone and puts effort on a separate slider, so a name captured from the picker is incomplete. The pinned names were each verified live on agy 1.1.22.
- **The exit-81 cause was a filename.** Before the marker line, the cause came from `firstDiagnosticLine`, which for a tmux driver (notes prefixed `[<cli>-tmux]`, not `[bridge]`) fell through to the last stderr line, a workspace file listing; with a sandbox WARN ahead of the wait, the WARN became the cause. The one marker line now carries the cause ([full-tmux-control.md §7a](../full-tmux-control.md)).
- **Channel e2e flakes** (macOS CI, 2026-08-03). A bare sleep lost the race with the driver's inbox seek to EOF, so the ask was never delivered and the package hit its 10-minute timeout; a frozen supervisor clock also made the 10s Ask timeout unfireable. The test now waits for `build-pane.live`, which the driver creates after the seek, and advances its fake clock.
- Plan-mode dialogs and codex's plan-mode effort downgrade: [incident 2026-08-27](../../incidents/2026-08-27-plan-mode-dialog-blind-spot.md). claude 2.1.252's trust default flip: [incident 2026-09-01](../../incidents/2026-09-01-claude-2252-trust-default-flip.md). A transient 529 inside the artifact wait: [incident 2026-08-18](../../incidents/2026-08-18-transient-529-inside-artifact-timeout.md).
