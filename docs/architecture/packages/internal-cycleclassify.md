# internal/cycleclassify

> Related records: [ADR-0020](../adr/0020-unified-phase-event-stream.md) (the events stream this package filters, and its parity gate), [ADR-0039](../adr/0039-failure-floor-and-failure-signal-contract.md) §7 (the sentinel pass), the [triage refusal poison loop](../../incidents/2026-09-14-triage-refusal-poison-loop.md) (the record pass), the [cycle-61 post-mortem](../../incidents/cycle-61.md), and [deliverable-contract.md](../deliverable-contract.md) (why artifact names go through `phasecontract.ArtifactFilename`). The retention and retry semantics of each class belong to `internal/failurelog`. This page keeps the package-level detail those records do not.

## Purpose

`internal/cycleclassify` reads a finished or aborted cycle workspace (`.evolve/runs/cycle-<N>/`) and returns one canonical classification with the marker and file that triggered it. The loop uses the result to decide between retry and stop. It records failed approaches under that class, quota-pauses on `MarkerQuotaLikelyEmptyOutput` (`cmd_loop_sequential_verify.go`), and stops on `integrity-breach`. The package is the Go port of the legacy bash `classify_cycle_failure` (`archive/legacy/scripts/dispatch/evolve-loop-dispatch.sh`).

## Design

- **Wire-compatible classes.** The `Classification` strings match the bash classifier, so `state.json:failedApproaches[].classification` did not change at the Go cutover. The sentinel pass returns `failurelog` canonical strings (`code-build-fail` and so on) cast to `Classification`. `failurelog.Record` normalizes idempotently, so those strings are wire-safe too.
- **Pass order.** `Classify` runs the passes below in order, and the first hit wins. Structured passes come before prose.
  1. *Record read.* `classifyFromRecord` reads the C1 record (`phase-timing.json`) first, so the sentinel pass can compare phases.
  2. *Sentinel pass* (pass 0, ADR-0039 §7). A phase report (`*-report.md`, sorted by name) with a FAIL verdict sentinel and a failure block states why that phase failed. Its class is trusted only when `failurelog.NormalizeLegacy` maps it into the canonical taxonomy. An out-of-taxonomy class falls through to the regex passes: never `UnknownClassification`, and never blind trust of an agent string. `orchestrator-report.md` is skipped because it is prose for the regex passes. `retrospective-report.md` is skipped because it is about a failure, not the failure itself.
  3. *Record pass* (pass 0b). The last outcome in the record is a FAIL with an error-severity diagnostic that carries a code (`cyclestate.ErrorCodes`). That is a `phase-refusal`: the phase's own deterministic gate stopped the cycle, the refusal repeats on every retry of the same item, and so it is task-attributable. `Marker` is the first code. `Detail` and `Subject` come from the first error diagnostic with that code, and `Phase` is the refusing phase.
  4. *Infrastructure in `orchestrator-report.md`* (pass 1).
  5. *Infrastructure in the events stream* (pass 2, ADR-0020). The normalizer owns the infra-marker vocabulary and emits `kind==infra_failure` for markers on stdout or stderr. This package filters that kind across the sorted `*-events.ndjson` files and never re-scans raw `*-stdout.log`/`*-stderr.log`. A transient stream-json `rate_limit_event` normalizes to `kind==rate_limit`, a non-fatal backoff, so a recovered rate limit does not force an infrastructure verdict.
  6. *Ship gate* (pass 3), *audit verdict* (pass 4) and *build never GREEN* (pass 5), all over the orchestrator report.
  7. *Hang reclassifier* (opt-in). `detectHangShipped` needs two factors: the first non-empty line after `## Verdict` contains "shipped", and `git log --grep="cycle N" --format=%H main` in the process working directory finds a commit. The cycle number comes from the workspace's `cycle-N` suffix. A matching cycle succeeded and only its parent process hung, so it becomes `exit-transport-hang` (1 h retention) instead of a 7-day `integrity-breach`. `SetHangClassifier` wires the toggle from `policy.ClassifyConfig().HangClassifier` at loop start (`cmd_loop.go`).
  8. *Empty-output session* (pass 6). This pass is described below.
  9. Otherwise the result is `integrity-breach` with an empty `Marker` and `Source`.
- **Regexes are ports of `grep -qiE`.** Each is case-insensitive, and Go's `.` does not cross a newline, so a marker must sit on one line, just as the line-by-line grep required. The split-line `## Verdict\n**FAIL**` form belongs to audit reports, not the orchestrator report.
- **Empty-output session (quota wall).** A phase whose `<agent>-stdout.log` exists but is empty or whitespace, and whose paired `<agent>-events.ndjson` holds no `assistant_text` envelope, is the subscription-quota-wall signature: `claude -p` exits empty when the quota is exhausted. The result is `infrastructure` with `MarkerQuotaLikelyEmptyOutput`, and the loop quota-pauses (rc=5, auto-resume) instead of burning the next cycle into the same wall. The `assistant_text` match also accepts the pretty-printed `"kind": "assistant_text"` form, in case a re-serializer inserts a space.
- **Prompt-echo veto.** `firstInfraMarker` skips an `infra_failure` event that `isPromptEchoSelfReport` identifies as the phase quoting its own prompt. All three conditions must hold: the trimmed excerpt is a verbatim substring of `<phase>-prompt.txt`, the phase's deliverable (`phasecontract.ArtifactFilename(phase)`) carries a PASS verdict sentinel, and `driverExitedZero` finds the phase's last `llm-calls.ndjson` record with exit code 0. Deliverable PASS plus a clean exit are the source of truth, and a bare keyword echo cannot override them.
- **Test seams.** `hangClassifierFn`, `gitLogFn`, `globFn` and `maxScannerBufBytes` are package variables so tests can drive the toggle, the git lookup, the glob error branch (a literal pattern cannot make `filepath.Glob` fail) and the scanner-overflow branch. `gitLogMatchesCycle` takes a `gitexec.Git`, so the exact git invocation is unit-tested with a fake exec (`classify_git_test.go`).

## Invariants

- **Infrastructure beats ship-gate-config, which beats audit-fail, which beats build-fail.** A ship-gate-deny report can mention the audit verdict in passing, and the narrower, lower-severity `ship-gate-config` label is the right one. Pinned by `TestClassify_InfraBeatsEverything` and `TestClassify_ShipGateBeatsAuditFail`. The code keeps a one-line why at the ship-gate pass.
- **The sentinel pass is FAIL-only.** A phase's FAIL is the cycle's failure, but a WARN is not necessarily why the cycle stopped, so a later infra crash must keep winning. Pinned by `TestClassify_Pass0_WarnDoesNotSuppressInfra`; one-line why in the code.
- **The sentinel pass is recency-aware.** A classed FAIL sentinel wins only when no record exists or when it comes from the record's last phase, the phase the cycle stopped on. A sentinel from an earlier phase (a scout that wedged, retried and passed) is stale once a later gate refused with a code. Pinned by `TestClassify_SentinelClassStillOutranksTheRefusal` and `TestClassify_StaleEarlierSentinelDoesNotOutrankTheRefusal`; one-line why in the code.
- **A coded refusal precedes the infra passes.** An infra marker before the refusal did not stop the cycle, because the phase still ran and refused. None can come after it, because the cycle ended there. The refusal must be the last outcome: a refusal the cycle recovered from does not count. Pinned by `TestClassify_CodedRefusalOutranksTheRegexPasses` and `TestClassify_RefusalMustBeTheLastOutcome`. An absent or corrupt record, a PASS tail, or an uncoded FAIL falls through (`TestClassify_UnreadableRecord_FallsThrough`, `TestClassify_UncodedFailOnTheRecord_IsNotARefusal`).
- **A missing orchestrator report is not an immediate breach.** A mid-cycle quota abort never writes one, and the empty-output pass recovers that case from per-phase artifacts. Every pattern pass misses harmlessly on empty data. Pinned by `TestClassify_NoReportButEmptyOutput_QuotaLikely`.
- **The empty-output pass runs last,** so it can never mask a classifiable failure (`TestClassify_EmptyOutputNeverBeatsClassifiableMarker`).
- **The stdout log must exist.** A missing log means the phase never ran, which is a true silent skip and must stay `integrity-breach` (`TestClassify_NoStdoutLog_StaysBreach`). An empty log whose events stream still captured assistant output was merely truncated and is not a quota wall (`TestClassify_EmptyStdoutButAssistantEvents_StaysBreach`).
- **Scan errors are biased toward the safe verdict.** In `hasAssistantEvents` a scan error (a line longer than `maxScannerBufBytes`) counts as output present, so a large-output truncation never triggers a false quota pause (`TestClassify_EmptyStdoutButEventsTruncated_StaysBreach`). In `firstInfraMarker` a scan error yields no infra signal rather than a partial one, as `cyclecost.parseEventsLog` does (`TestClassify_EventsLineTooLong`). The effective line cap is the larger of the 1024-byte initial buffer and `maxScannerBufBytes`, so an overflow fixture must exceed 1024 bytes.
- **The prompt-echo veto fails closed.** A missing or unreadable prompt, report or call record, a non-PASS sentinel, a non-zero exit, or an empty phase or excerpt means no veto, so a genuine runtime infra signal still classifies as infrastructure. Pinned by `TestC654_001_PassDeliverableExit0EchoNotInfraVeto` and `TestC654_002_GenuineInfraStillVetoes`, and run by `go/acs/cycle654`.
- **The last call record owns the exit.** `driverExitedZero` takes the phase's last `llm-calls.ndjson` record with an exit code, because a retry's final attempt is authoritative. An earlier exit 0 never vetoes a later failure (`TestDriverExitedZero_LatestUnavailableUsageAttemptStillOwnsExit`).
- **Deterministic `Source`.** Every glob is sorted, so when several files match, the alphabetically first one names the source (`TestClassify_SortedEventsScan`).
- **The hang reclassifier is opt-in,** so a misconfigured git log can never mask a real integrity breach ([internal-policy.md](internal-policy.md)). Its two factors are pinned by `TestClassify_HangClassifier_*` and `TestShippedAfterVerdict`.
- **Source-reading predicates constrain `classify.go`.** `go/acs/cycle1147` requires a `phasecontract.ArtifactFilename(` call and no hand-concatenated `-report.md` name. `go/acs/cycle5` requires that the quoted env-var name of the retired hang-classifier flag never appear in the file.

## Findings

- **cycle-61**: a memo-phase API 529 landed in `memo-stdout.log`, not the orchestrator report, so the bash classifier fell through to `integrity-breach` on a recoverable infra error. That motivated scanning phase output for infra markers, later symmetric stdout and stderr detection in the normalizer ([ADR-0020](../adr/0020-unified-phase-event-stream.md) task 4). `TestClassify_InfraInEventsStdout` keeps a stdout-borne case.
- **ADR-0020 cutover**: the raw-log scan was deleted with no runtime fallback. `TestClassify_ParityInfraRawVsEvents` (raw lines through the real `phasestream.Classifier`) and `TestClassify_ParityViaProduce` (raw logs through `phasestream.Produce`, as the runner calls it) are the parity gate.
- **cycles 119/120** ([incident](../../incidents/cycle-119-artifact-timeout-and-cross-cli-trust.md), workstream D2): an empty-output session after an opus-heavy run was the quota-wall signature but fell through to a generic error. A mid-cycle quota abort wrote no orchestrator report at all. That produced the empty-output pass, and removed the missing-report short-circuit to breach.
- **cycles 641/642 → 654**: an adversarial reviewer's own exploit checklist ("…missing rate limits.") was echoed by the tmux driver, keyword-matched as `rate_limit`, and turned a passing, exit-0 phase into an infrastructure discard. The same failure recurred byte for byte in 642. Cycle 654 landed the prompt-echo veto: deliverable PASS plus a clean exit are the source of truth. The normalizer-side echo gate lives in `phasestream` (`TestClassifier_SetInjectedPrompt`).
- **2026-09-14 triage refusal poison loop** ([incident](../../incidents/2026-09-14-triage-refusal-poison-loop.md)): triage's protected-surface refusal carried only a prose diagnostic, no class fit it, and the item was recovered untouched for nine waves. That added `phase-refusal` and the record pass. The architecture review's MEDIUM-2 found that a stale earlier-phase sentinel could disarm the fix, which made the sentinel pass recency-aware.
- **Flag reduction**: the hang classifier moved from an environment flag to `policy.ClassifyConfig().HangClassifier`. A test that kept `t.Setenv` broke at the migration ([flag-parameter-conversion-standard.md](../../research/flag-parameter-conversion-standard.md), step 7).
