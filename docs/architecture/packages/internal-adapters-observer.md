## Purpose

`internal/adapters/observer` is the live per-phase stall detector. `CoreAdapter` implements `core.Observer`, and `evolve loop` starts one per phase. Each run watches the phase's stdout log and workspace for progress and writes its own lowercase NDJSON envelope to `<phase>-observer-events.ndjson`. It only observes: a `stall_no_output` incident kills nothing. The standalone `evolve phase-observer` (`internal/phaseobserver` over `internal/observerengine`) is a separate observer.

## Design

- **Two progress signals.** Progress is stdout-log growth, or a newer file mtime anywhere under the workspace. A tmux driver writes to its scrollback and reaches the stdout log only at exit, so for a working tmux agent the workspace signal is the only filesystem sign of life.
- **Probe before incident.** At the stall threshold, and only there, `Watch` consults `Config.LivenessProbe`. True resets the clock and emits `stall_probe_active` (info) instead of `stall_no_output` (incident). The probe runs at most once per `StallS` window, so its subprocesses cost nothing on the healthy path.
- **Two probes, OR-ed.** `anyProbe` combines the tmux pane probe and the process CPU probe, and either proves life. It calls every probe on each call, with no short-circuit, so each stateful probe keeps its last sample current.
  - *Tmux pane probe* (`newTmuxPaneProbe`). It lists sessions on the bridge's isolated socket, picks the first `evolve-bridge-*` session whose name contains `-c<cycle>-<phase>-` (names are `evolve-bridge-<cli>-c<cycle>-<phase>-pid<pid>-<ts>`), hashes `capture-pane -p`, and reports alive when the hash changed. With a known run id it also requires the `sessionrecord.RunScopeToken` infix. A non-tmux phase finds no session and makes no claim.
  - *Process CPU probe* (`newProcessCPUProbe`). It covers headless drivers, which have no pane. It reads the agent PID from `core.BridgePIDFile(<phase>-stdout.log)`, which is `<phase>.bridge-pid`. The bridge's `execRunner` writes that file when the headless driver sets the pidfile env. The probe compares `ps -o time=` output between calls.
  - Both probes grant one window on first sighting, and both return false (no claim) on any error.
- **The CPU probe is a proxy.** It beats stdout flatness but has blind spots: an agent blocked on a slow API response accrues little CPU (a false negative), and a wedged busy loop reads alive (a false positive). It fails safe, since false leaves the stall logic unchanged. The real fix is a wall-clock heartbeat from the bridge, independent of agent output ([proxy-failure research](../../research/verdict-and-gate-proxy-failure-class-2026-06-03.md), item 3).
- **Bounded workspace scan.** `newestActivity` walks the workspace on every poll. It skips unreadable entries and the observer's own events file, and stops after 500 files. The per-phase workspace is small and the cycle's git worktree lives outside it, so the cap is only a backstop against a pathological tree.
- **In-process subscription.** `Config.OnEvent` receives every typed event synchronously, after the sink write and outside the sink lock. Production leaves it nil. Tests use it to wait on events instead of sleeping for fixed windows.
- **Live channel producer.** When `RecoveryStage` resolves to `enforce` (`channel.ResolveStage`, empty means `shadow`), `Start` also runs a `channel.Producer`. `channelSourcePaths` points it at `<phase>-pane.live` and `<phase>-breadcrumbs.live` for a tmux driver, and leaves a headless driver on the producer's stdout/stderr log defaults. `phaseCLI` guesses the driver from the request env only (`EVOLVE_<PHASE>_CLI`, then `EVOLVE_CLI`, default `claude-tmux`). It loads no profiles, so a wrong guess degrades only that phase's live feed.
- **Cancel.** `Start` returns `finishFn`'s idempotent cancel. It stops the watcher and the producer, waits up to `watcherExitTimeout` (10 s), then closes the sink through `closeSinkAfterWait`. The watcher notices cancellation only once per `PollS` (5 s by default), and a 2 s wait proved too short.
- **Faults are signals.** The adapter's two faults, `OBSERVER_EVENTS_SINK_OPEN_FAILED` and `OBSERVER_WATCHER_LEAKED`, reach the Signal Center through `observerengine.Reporter` with origin `CoreAdapter.Start`. Its detection events stay in its own events file.
- **No nudges yet.** The auto-spawn path sends no soft-stall nudges. The nudge logic lives in `internal/observerengine`, and folding the engine into this adapter is follow-up F8 of unit 12. `DefaultNudgeS` (300 s, [ADR-0023](../adr/0023-live-injection-and-launch-rules.md)) waits for that fold.
- **Agent equals phase.** The runner names the agent after the phase, so `Config.Agent` is the phase name.

## Invariants

- **Observer failure never blocks the phase** (ADR-0030). An events sink that cannot be opened is signaled, and `Start` returns a no-op cancel; the phase runs unobserved. Pinned by `TestCoreAdapter_Start_DegradesToNoopWhenEventsFileUnopenable` and `TestCoreAdapter_SinkOpenFailureIsASignalAndTheAdapterIsWired`.
- **The sink is never closed on the timeout arm.** A watcher still running past the bound may still write, so closing its sink would be a use-after-close race. The goroutine and its fd leak on purpose (the OS reclaims them at exit), and the leak is signaled. Pinned by `TestCoreAdapter_NoSinkCloseRaceOnTimeout`, `TestCoreAdapter_SinkClosedOnNormalDone`, `TestCoreAdapter_WatcherLeakIsASignal`, and the `go/acs/cycle669` predicates, which run the first two by name.
- **The observer's own events file is not progress.** Its writes would otherwise reset the clock and mask every stall. It is excluded before the file cap is charged. The suffix comes from `observerengine.EventsSuffix`, the engine's one layout. Pinned by `TestWatch_ObserverEventsFileDoesNotMaskStall`, `TestNewestActivity_ReportsNewestFileMtime` and `TestCoreAdapter_UsesTheLayoutProjection`.
- **A probe suppresses a stall only on positive liveness.** False never masks one. Pinned by `TestWatch_LivenessProbeFalseStillStalls`.
- **Run ownership fails closed.** A probe that knows its run id never claims liveness from another run's session, because that would keep a dead agent's stall clock fresh indefinitely. An empty run id (single-driver dispatch) matches on the cycle/phase infix alone. Pinned by `TestProbeRefusesForeignRunSession`, `TestProbeMatchesOwnRunSession` and `TestProbeLegacyNoRunIDMatchesAny`.
- **The pane probe queries the bridge's socket.** A default-socket query never sees the agent panes and would report every agent dead. Pinned by `TestSocketTmuxRunner_PrependsIsolatedSocket`.
- **Probes are single-goroutine.** Each closure holds its last sample, and only the `Watch` loop calls it.
- **A late pidfile still earns the first-sighting grant**, because `observed` is set only after a successful read. The code keeps a one-line why for this.
- **The two `-stdout.log` spellings agree.** `Start` passes `PathsFor(ws, phase).Stdout` to `core.BridgePIDFile`, which keeps a private copy of the suffix. If the two drift, the CPU probe finds no pidfile and silently reports dead. Pinned by `TestCoreAdapter_StdoutLayoutAgreesWithTheBridgePIDFileConvention`.
- **No stderr lines and no env reads in production sources.** Faults are signals, and settings come from policy. Pinned by `TestCoreAdapter_HasNoStderrLinesAndNoEnvReads`, a text scan for `os.Stderr`, `os.Getenv` and `EnvLookup`. The scan reads comments too, so a non-test comment naming those identifiers fails it.
- **The origin has one home.** `originAdapterStart` is the only production spelling of the quoted `CoreAdapter.` origin, so the planned split of `Start` (unit 12, F1) renames one constant. Pinned by `TestCoreAdapter_OriginHasOneHome`, which counts the quoted prefix in non-test sources, comments included.
- **The event envelope is byte-stable.** Lowercase types and severities (`info`, `incident`) and the `Event` field set are pinned by `TestObserver_EventsFileMatchesGolden` against `testdata/adapter-events.golden.ndjson`. `soakreport` counts only `INCIDENT` envelopes, so uppercasing these severities would start counting the adapter's stalls there.
- **`DefaultNudgeS` equals policy's compiled `NudgeS`.** Pinned by `TestDefaultNudgeS_MatchesPolicyCompiledDefault`.

## Findings

- **cycle-122** ([ADR-0030](../adr/0030-phase-observer-autospawn-in-evolve-loop.md)): the Go port had silently dropped the bash dispatcher's per-phase observer. `CoreAdapter` restored it for `evolve loop`.
- **cycle-141**: a working tmux build agent was reported stalled because its output never reached the stdout log. That added the workspace-activity signal.
- **cycle-190**: a tmux agent thinking for more than ten minutes in one "Incubating" turn left both filesystem signals flat and drew a false incident. That added `LivenessProbe` and the pane probe.
- **Headless follow-up**: the same false stall recurs for headless `claude -p` phases, which have no pane. The proxy-failure review named child-process CPU as a stronger signal, which added the CPU probe and `anyProbe`.
- **Concurrency campaign, CB.6**: with concurrent runs, the cycle/phase infix alone could match another run's session, the cross-run form of the false-liveness class from cycles 254/255. The probe now asserts the run token.
- **observer-sink-close-race** ([2026-07 code audit](../../research/code-audit-2026-07/README.md), weight 0.92): the cancel closed the sink unconditionally after the 10 s wait, racing a wedged watcher's writes. Commit 22a90595 extracted `closeSinkAfterWait`, which closes only on the done arm; `go/acs/cycle669` pins it.
- **cycle-124**: the operator asked for soft-stall nudges. They reached only the standalone observer, and the auto-spawn gap remains (unit 12, F8).
- **ADR-0103 unit 12**: the adapter's two `[observer] WARN` stderr lines became Signal Center codes, its dead env readers were deleted, and its paths now project from `observerengine.PathsFor`. The events golden was captured before that edit, to prove the detection stream unchanged.
- **Test timing**: fixed wall-clock windows made these tests flaky under `-race` on macOS. The tests now wait on events (`OnEvent` with `awaitEvent`) or drive a virtual clock (`nowFunc`), and keep only generous safety bounds.
