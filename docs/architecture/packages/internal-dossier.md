ADR-0055's neutral notes (`Write`'s `commit` is reserved; `Build` synthesizes a `cycle-recorded` phase) no longer hold; this page describes the current code.

## Purpose

`internal/dossier` owns the committed per-cycle record, `knowledge-base/cycles/cycle-N.{json,md}`. It holds the `Dossier` type and its `Validate` trust boundary, `Build` (a projection of the cycle's evidence), the JSON and markdown renderers, `Write` (an atomic write plus a scoped git commit), `SweepOrphans` (recovery of uncommitted pairs), and the corpus readers `ReadCommitted`, `PhaseSkipEvidence` and `RollupSpineFailOpens`.

## Design

- **The Go struct and `Validate` are the single source.** `schemas/cycle-dossier.schema.json` is the cross-tool reference, and the module takes no JSON-Schema validator dependency. `TestSchema_NoDrift` keeps the two in step:
  - Names are checked in both directions (change-log §17 gives the reason).
  - Shape is checked on three axes: `$ref` target, JSON type, and `required`. A name-only inventory stays green while the schema is unusable. Swapping the `items.$ref` of `skipped_phases` and `phases_run_verdict_not_adopted` keeps every name identical, yet the two definitions carry disjoint required keys, so every real dossier would be rejected.
  - `required` is checked one way only: every schema-required field must be a Go field without `omitempty`. A non-omitempty field missing from `required` is merely permissive, while a required field the writer may omit rejects valid documents.
  - Every schema definition must be registered in `schemaObjects` and reachable from `Dossier`. A definition nothing points at is dead schema, and dead schema is what rots.
- **A projection of evidence, never a synthesis.** `Build` reads each fact from the artifact its owning phase writes, returns not-ok when the artifact is absent or unusable, and then leaves the field empty. Ingestion is best-effort per artifact: a missing or malformed file shrinks the record and never fails `Build`.

  | Field | Source |
  |---|---|
  | `Phases`, `Timing` | `BuildOpts.PhaseTimings`, else the workspace `phase-timing.json` |
  | `CommitSHA`, `TreeSHA` | `ship-binding.json` (`ShipBinding`) |
  | `Tasks` | `internal/committedset`: the lane pin, else triage's `top_n`, minus deferrals |
  | `CIWatch` | `ci-watch-verdict.json` |
  | `Failure` (FAIL only) | `failure-digest.json` and `audit-fail-reason.json` |
- **Live timings come first.** `core` passes the timing set it composed and flushed once (`cycleRun.flushPhaseTimings`). `phase-timing.json` is written by a deferred call in `RunCycle`, so on the normal path it lands after the dossier is built. The fallback to the workspace log stays live for a caller that never threads live timings.
- **Absence is loud.** With neither source, `Phases` holds one `evidence-unavailable` phase at WARN. WARN stays inside `Validate`'s vocabulary and states the degradation without claiming a verdict no phase produced. `FinalVerdict` is untouched.
- **FAIL synthesis.** A FAIL gets a minimal `audit-fail` defect and an `address-audit-findings` carryover that point at the audit artifacts, so `Validate` passes without invented specifics. The audit report filename comes from the `phasecontract` registry.
- **Shared wire types.** `ShipBinding` and `CIWatchRecord` are declared here, and their writers (`phases/ship`, `internal/ciwatch`) marshal them. Those packages already import `dossier` and the reverse edge does not exist, so writer and readers share one definition and a field rename is a compile error.
- **Failure artifacts are read locally.** Their writers live in `internal/core`, which imports this package, so the read cannot be shared without an import cycle.
- **`Tasks` has three states.** `nil` means no decision was read and the field is omitted; `&[]string{}` is an explicit empty commitment and serializes as `[]`; otherwise it holds the ids. A plain `[]string` cannot express this: without `omitempty` a nil marshals to `null`, which the schema's `"type": "array"` rejects, and with `omitempty` an explicit empty commitment vanishes. `HasCommitment` and `CommitmentLine` render the empty commitment as a stated fact in the markdown half, the half people read. Production reaches both only through `text/template` reflection.
- **Schema version.** `Build` is the only construction boundary (`core.writeCycleDossier` delegates to it), so it stamps `CurrentSchemaVersion` on every new record. The value is 2 because 1 is the implicit, never-written version of the pre-discriminator corpus. Zero (field absent) is the legacy signal. The schema declares the field as an integer and does not require it.
- **`PhaseSkipEvidence` is the sanctioned read of `skipped_phases`.** It returns `none` (no entry for the phase), `trusted` (any nonzero version, so a future bump cannot reclassify version 2 as legacy), `contradicted` (a legacy record with a surviving execution receipt) or `unverified` (a legacy record without one: unknown, not a skip). There are two receipt sources, because the historical run dirs are gone: for retro, its report in `.evolve/runs/cycle-N/` (`retrospective-report.md`, or the pre-rename `retro-report.md`); for any phase, the ledger's `{cycle, role, kind: agent_subprocess}` entry.
- **`ReadCommitted` is the fleet channel.** Fleet lane cycles run as separate `evolve cycle run` subprocesses whose results never return to the parent loop, so the committed dossier is the only way a batch-level surface (the loop summary's spine fail-open roll-up) sees what its lanes recorded. It windows by filename before opening any file, and it is best-effort because its callers are reporting surfaces.
- **Write and commit.** `Write` renders both halves (each renderer calls `Validate`) and writes each through `atomicwrite`. With `commit`, `commitPairGit` stages and commits exactly the pair by pathspec. `commitPair` is the production wrapper; `commitPairGit` takes an injected `gitexec.Git` so the retry tests run without racing real locks.
- **`SweepOrphans`** finds dirty `cycle-N.{json,md}` paths through `gitexec.DirtyPaths`, pairs them by cycle number, recommits each complete pair through `commitPairGit`, and skips half pairs, since a lone file is a partial write from a killed writer. A per-pair failure is logged to `logw` with the cycle number and git's error, recorded in `Failed`, and the sweep moves on.
- **`CyclesDir` is the one spelling of the corpus path** for the producer, the chronicle seed, `ReadCommitted`, `evolve dossier verify` and the dashboard's ship-rate history. `internal/contextfillcorrelate` still joins the path inline, because it is a leaf package that does not import `dossier`; carry it along on any move.
- **`SpineFailOpenRollup` uses snake_case JSON tags** to match the loop summary's `spine_fail_opens` block and the dossier's own fields.

## Invariants

- **A FAIL records why and the fix.** `Validate` requires at least one defect and one carryover on a FAIL, so no failure's experience is lost. Pinned by `TestValidate_FailMustCarryExperience`.
- **Nothing is fabricated.** An absent artifact means an absent field. Pinned by `TestBuild_AbsentEvidenceIsLoudNeverASynthesizedPass`, `TestBuild_FailWithoutArtifacts_NilFailure` and `TestBuild_IngestsCIWatchVerdict`.
- **`ShipBinding.CommitSHA` has no `omitempty`.** Its emptiness is the "did not deliver" signal `shippedCommit` keys on; the asymmetry with the other fields is deliberate. The code keeps a one-line why. `ship-binding.json` is also the file `core.detectLostLanding` keys on, so the two agree on what "landed" means.
- **A failure digest is adopted only when its `cycle` field matches.** A digest from another cycle is a stale leftover, and a false forensic identity is worse than none. This is the same distrust `core.EvaluateBlockerBreaker` applies. Pinned by `TestFailureRecord_StaleDigestCycleIsRejected`.
- **Reasons are bounded.** Whitespace collapses first, because reasons come from test output and a newline would put a fake `## ` heading into the markdown record that retro reads; collapsing also makes the byte bound meaningful. At most 5 reasons, each at most 200 bytes (bytes, not runes), cut head-first on a valid UTF-8 boundary. Pinned by `TestBuild_FailureReasonsTruncatedAndCapped`, `TestFailureReasons_MultilineReasonCollapses` and `TestFailureReasons_MultibyteTruncationStaysValidUTF8`.
- **The schema version is forward-only.** A re-rendered legacy record stays unstamped, because a backfilled record would look post-fix while still carrying the mislabel. Pinned by `TestSchemaVersion_LegacyRecordStaysUnstamped`.
- **The commit is scoped.** Only the pair is added and committed, by pathspec. An identical rewrite (`git diff --cached --quiet` exits 0) returns before committing, so it never makes an empty commit. Pinned by `TestWrite_Commit` and `go/acs/cycle539`.
- **The retry is bounded.** Four attempts (one plus three retries) with a linear 25 ms × attempt backoff, so a stuck lock errors within a second instead of hanging finalization. Only `index.lock` contention is transient; any other error fails fast. Pinned by the `TestCommitPairGit_*` tests in `write_retry_test.go`.
- **A failed commit always unstages the pair**, on a permanent error and after exhausted retries alike, so no phantom staged change reaches the next tree-diff guard. The invariant is the staged set, not the porcelain: new files legitimately stay untracked after the unstage. Pinned by `TestCommitPairGit_RollsBackStagedOnPermanentFailure`.
- **Spine escalation keys on a cycle's own count**, never the batch total, or escalation would stop identifying anything. A threshold of zero or less disables it, since every cycle would qualify. Nil dossiers are skipped and `ByPhase` is always allocated, because a reporting surface that panics on a partial batch reports nothing. Pinned by `TestLoopSummary_RollsUpSpineFailOpensPerBatch`, `TestRollupSpineFailOpens_CleanBatchIsSilent` and `TestSpineFailOpenRollup_ZeroValueIsSafeToRead`.
- **`ReadCommitted(root, minCycle <= 0)` reads the whole corpus.** A caller that cannot bound its window must choose that deliberately. Pinned by `TestReadCommitted_WindowedAscendingAndFaultTolerant`.
- **`build.go` must name `phasecontract` and must not re-type the audit report filename.** `go/acs/cycle1141` reads the source file to check both.
- **Known limit.** `failure-digest.json` is written only when the dispatch loop routes into retro, so a FAIL reclassified at finalize without a retro dispatch carries reasons only.

## Findings

- **ADR-0055 correction** (2026-06-23): the recorder was first shipped with no production caller, and the `dossier-closeout` floor was silently ignored. See the correction note in ADR-0055.
- **cycle-539**: `Write`'s `commit` parameter was reserved and always false, so every closeout pair stayed untracked and a later phase's tree-diff guard aborted cycles on it. The parameter was implemented as a scoped commit; `go/acs/cycle539` pins it.
- **cycle-564**: `commitPair` was best-effort and un-retried. Concurrent fleet lanes sharing one repo contend on `.git/index.lock`; a failed commit left the pair untracked, and the tree-diff guard hard-aborted the next phase. It accounted for nine recorded cycle failures and 35 orphaned pairs, and it produced the bounded retry and `SweepOrphans`.
- **cycle-573**: a permanent commit failure left the pair staged. The fix unstages it before returning the error.
- **Retro-skip mislabel** (cycle-802 guard, PR #389; change-log §16): a declined post-verdict phase was recorded in `skipped_phases`, so FAIL dossiers claimed retro was skipped while its report sat on disk. 134 legacy records (cycles 823–1217) carry it. cycle-1666 chose the version discriminator and the read-only `evolve dossier retro-mislabel` audit over a backfill, since the two remedies were exclusive; the audit found all 134 contradicted by receipts.
- **Schema drift** (change-log §17): the drift test ADR-0055 promised did not exist, and eleven fields rotted until it did.
- **cycle-1141**: a synthesized defect that names a stale audit filename sends the next cycle looking for a file that is no longer written, which is why the name is derived from the registry.
- **cycle-1166**: one width-3 batch took 76 spine fail-opens and nothing summed them. See retry-hooks-and-spine-telemetry.md §3.
- **Failure identity**: FAIL dossiers once recorded only "see the audit report", so convergence briefs and cross-batch forensics had to dig through gitignored workspaces. By dossier time `core` has already written both failure artifacts, so `Build` projects them.
- **cycle-1623** (CHANGELOG, 2026-09-11): a cycle that ran twelve phases and shipped recorded one synthetic PASS phase and no commit, because the dossier read `phase-timing.json` before the deferred write landed. The healthier the cycle, the emptier its record. The same change set `CommitSHA` for the first time (so historical dossiers lack it and the ship-rate series has a discontinuity), moved the ship binding to the shared `ShipBinding` type after a reader keyed on `commit` instead of `commit_sha` and passed its own tests because they re-typed the same key, and routed `Tasks` through `committedset` after runtime cycle-1621 showed a lane pin naming two tasks where `top_n` named one.
