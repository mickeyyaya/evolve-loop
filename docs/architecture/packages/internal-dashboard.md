# internal/dashboard

> Decision: [ADR-0095](../adr/0095-pipeline-dashboard.md) (read-only, stdlib-only, beliefs imported, ship rate from the dossiers, the failure panel's triage order, hostile-text handling, one SSE stream, read failures never silent). Design spec: [2026-09-02-ship-rate-harness-and-pipeline-dashboard-design.md](../../superpowers/specs/2026-09-02-ship-rate-harness-and-pipeline-dashboard-design.md). Operator guide: [pipeline-dashboard.md](../../guides/pipeline-dashboard.md). This page keeps the package-level detail those do not.

## Purpose

`internal/dashboard` is the read-only observability surface behind `evolve dashboard`: a stdlib-only local web UI that renders the loop's on-disk state (`.evolve/cycle-state.json`, the run workspaces under `.evolve/runs/`, the committed dossiers under `knowledge-base/cycles/`, and the inbox) as one live page. It answers whether the loop is alive, what is queued, what each cycle did, what went wrong, and how the ship rate is trending.

## Design

### Reading rules

- **Every read is best-effort, and absent is not corrupt.** An absent artifact is the ordinary sparse-workspace shape and stays silent; a present but unreadable or unparsable one zero-values its field and becomes a line in `Snapshot.Warnings`, never a page failure. `Warnings` exists so a reader can tell "absent" from "hidden": a half-written `failure-decision.json` must never read as "no failure recorded yet", and an unreadable `knowledge-base/cycles` must never read as a 0 % ship rate over 0 cycles. `readJSON` returns `(false, nil)` for absent and `(false, err)` for present-but-broken; `dossierCache.loadCycle` makes the same split. Pinned by `TestReadFailure_TornArtifactIsWarnedNotSilent`, `TestReadHistory_MalformedDossierIsWarnedNotFatal`, `TestReadHistory_MissingDirIsEmptyNotError`, `TestReadCycle_TornTimingIsWarnedNotFatal`, `TestReadQueue_MalformedItemIsWarnedNotFatal`, `TestReadLoop_MalformedCycleStateWarns` and `TestCollect_EmptyRootIsQuiet`.
- **The package never takes the loop's flock sidecars and never writes.** It relies on the writers' atomic-rename discipline: a reader sees the old file or the new one, never a torn one.
- **An unlistable `.evolve/runs` is a warning, not an empty list.** A silent nil would empty the board and freeze the change fingerprint (`workspaceCycles`).
- **Beliefs owned elsewhere are imported.** Workspace paths (`core.RunWorkspacePath`), the cycle-state path (`core.ResolveCycleStatePath`), liveness (`runlease.Fresh`), inbox items (`inboxbatch.LoadDir`, the same loader triage consumes) and their order (`rankinputs.Load` plus `Inputs.Order`, the inbox rank every lane consumer reads, [ADR-0121](../adr/0121-inbox-priority-is-a-computed-rank.md)), dossiers (`dossier.ParseJSON`), phase timing (`phasetiming.Read`), the report names and round archives (`phasecontract.ArtifactFilename`, `RoundArchiveFilename`, `ParseRoundArchive`, the functions the writer `core/audit_round_artifacts.go` uses), the finding grammar (`reportdoc`), and the halted level (`policy.LevelSystem`). Phase order is the observed timing log, not another copy of the canonical list. `triage-decision.json` is a literal here; `cycleoutcome`, `triagecap` and `inboxmover` read the same name, written beside `triage-report.md` per `agents/evolve-triage.md`.
- **The failure panel names its writers so the join can be audited:** `failure-decision.json` (retro-authored, validated by `core/failure_decision.go`), `disposition.json` (retro-authored, gated by `core/disposition_gate.go`, cross-checked against the digest), `audit-fail-reason.json` (the coherence floor, `core/system_failure.go`), `failure-digest.json` (`core/failure_digest.go`).

### The model (`Snapshot`)

- **`Snapshot` is immutable.** It is rebuilt on every detected change and swapped by pointer; nothing mutates it. `--snapshot` prints the same model.
- **State vocabulary** (`State*`, the state type drives colour and sorting and `StateName` rides beside it): `running` when the cycle holds a fresh run lease; `halted` when its `failure-decision.json` declares the SYSTEM level; `pass`, `warn`, `fail` from the committed dossier's final verdict; `incomplete` with no dossier and no fresh lease (paused, crashed, or checkpointed mid-cycle), named `paused (brake)` when `.evolve/loop-stop` exists. `assignState` runs after `readCycle` because it depends on the live loop status. Pinned by `TestAssignState_ClosedVocabulary` and `TestCollect_BrakeReachesStatelessRows`.
- **Liveness is the lease, never a PID.** `LoopStatus.Running` is `runlease.Fresh` on the current cycle's lease, and only when the lease's run id matches the state's. A torn lease is a warning, never "idle"; a lease whose identity does not match the state is a warning and not running. Pinned by `TestReadLoop_FreshLeaseIsRunning` and `TestReadLoop_StaleLeaseAndBrake`.
- **A cleanly stopped loop removes `cycle-state.json`.** `readLoop` then shows the newest run workspace's `run.json` with `Checkpointed` set: where the loop was when it stopped, not what it is doing. A missing cycle-state is the quiet idle case. Pinned by `TestReadLoop_StoppedLoopFallsBackToNewestRunJSON` and `TestReadLoop_NoCycleStateIsQuiet`.
- **Each fleet lane has its own state and lease identity.** `readRunStatuses` reads each workspace's own cycle-state; the plane's singleton is a compatibility source only for a lane with no state of its own, and a workspace's `run.json` is a durable breadcrumb, never a stand-in for the primary lane's live state. A lane state that is torn or declares another cycle is a warning and never running. The loop card shows the primary lane's own state when it has one, else the newest running lane. Pinned by `TestCollect_OwnLaneStateIsTheLoop`, `TestCollect_NewestRunningLaneIsTheLoop` and `TestCollect_FleetStateIdentityAndCorruptionWarn`.
- **Dispatch metadata (`CLI`, `Model`) comes from `llm-calls.ndjson`**, and only the representative lane is enriched. `lastCallForPhase` takes the newest call for the current phase, else the newest call overall, which is the dispatch on the pane. For schema-v2 records `Model` is the verified dispatched selector; for legacy rows it is the requested label. Pinned by `TestCollect_FleetLoopIsEnriched`.
- **The cycle list is capped (`Options.MaxCycles`, default 40).** Run-workspace cycles come first and dossier-only history fills the remainder, newest first. A running lane is always rendered, even past the cap. `workspaceDir` matches only `cycle-<N>`: a quarantined `cycle-<N>.polluted-<stamp>` duplicate and `archive/` are excluded. Pinned by `TestCollect_WholePicture`, `TestCollect_CapKeepsNewestDossiersAndEveryWorkspace` and `TestCollect_FleetLivenessSurvivesHistoryCap`.
- **`PhaseRun` joins timing to routing by window.** Timing entries are sorted by start; `Round` is the 1-based occurrence of the phase name in the cycle; each run takes the final attempt whose terminal timestamp falls inside its own window, and an attempt is used at most once, so a retry in round one never shifts a later round's model attribution. A second-precision end covers its whole second. A timestamped ledger with no call inside the window leaves the routing blank instead of borrowing another round's; two rounds of one phase that started in the same instant withhold their calls; a legacy call with no start time inside the previous round's whole-second overlap, or at or after the next round's start, is withheld from both. Pinned by `TestReadCycle_PhasesInRunOrderWithRoundsAndRouting`, the five `TestPhaseRuns_*` tests and the four `TestCallForPhaseWindow_*` tests.
- **The failure panel** (`readFailure`) assembles from the workspace and falls back to the committed dossier's failure record when the workspace is gone; it is nil for a PASS or when nothing is recorded. `Findings` are the final round's issues, highest severity first (`reportdoc.SeverityRank`, unknown severities after the known ones so nothing is dropped, then by id). Pinned by `TestReadFailure_AllPanelsAndRoundHistory`, `TestReadFailure_DossierFallbackWhenWorkspaceGone`, `TestReadFailure_NothingToReportIsNil` and `TestReadFailure_SingleRoundReportOnly`.
- **Round history** (`readAuditRounds`) sorts the archives by their parsed index, appends the live report as the round after the highest archived index, and diffs each round against the previous one that exists: indices are not contiguous, because a dispatch that died before writing its report archives nothing while the counter still advances. A round's verdict follows the audit gate's order: the machine-readable sentinel first, the shared prose grammar as the fallback for older templates. Pinned by `TestReadAuditRounds_UsesRegistryArchiveNames` and `TestReadAuditRounds_NonContiguousArchiveIndices`.
- **`diffRounds` counts resolved, new and carried findings.** A current finding is carried when its lead clause (`reportdoc.FindingKey`) or its id plus severity appears in the previous round, because auditors keep an id while rewording the title and sometimes renumber while keeping the wording. Both lookups resolve to the same prior index and a prior finding is consumed at most once, so a new defect that reuses an old id is new. The id match applies only to findings that have ids: the reference template's TSV rows carry none, and a severity-only key would call any HIGH the same defect. Pinned by `TestDiffRounds_MatchesByIDOrLeadClause`, `TestDiffRounds_PriorFindingConsumedOnce` and `TestDiffRounds_IDLessFindingsMatchByLeadClauseOnly`.
- **`Finding` is an alias of `reportdoc.Finding`**, so the panel and the repair-brief seed in core can never disagree about what a finding is.

### History and trend

- **Shipped is PASS, or WARN that recorded a commit.** FAIL never ships. The same predicate feeds the trend and the round histogram.
- **`Trend`**: `Points` are the closed cycles oldest first, capped at the last 120 for the verdict strip; `Closed` and `Shipped` are all-time counts; ship rates cover the last 20, the last 50 and all closed cycles. `RoundHistogram` counts closed cycles that still have a workspace by audit rounds, because dossiers do not record rounds. `ShipStreak` counts shipped cycles back from the newest until the first non-ship and `LastZeroShipRun` names the most recent run of consecutive non-ships (`first_cycle`, `last_cycle`, `length`); both are computed over the full history before the 120-point cap, so `evolve status` reads a streak longer than the strip. Pinned by `TestComputeTrend_ShipStreakCountsBackFromTheNewestCycleOverTheFullHistory`.
- **`FingerprintStat`** groups FAIL dossiers by `failure.fingerprint`, most recently seen first. `Regressed` is set when the fingerprint recurs after a shipped cycle later than its previous occurrence; `Reason` is the first reason recorded with the latest occurrence. Pinned by `TestReadHistory_ShipRateAndFingerprints`.
- **`dossierCache` memoises parsed dossiers by name, mtime and size**, so a rebuild re-parses only changed files instead of about 1,800 dossiers per tick. A parse error is returned every time until the file changes and is never cached as a dossier. Pinned by `TestDossierCache_ReusesUnchangedFile`.

### Phase plan

- **The mandatory set is the registry's, read through `internal/config`**: `config.mandatory_phases` in order, the conditional-mandatory phases (the reader cannot evaluate their rule, so one that ran counts as required), and the spine order the walk follows. The operator's environment (`Options.Env`: `EVOLVE_MANDATORY_PHASES`, `EVOLVE_USE_PHASE_REGISTRY`, …) is injected by the command, never read from the process, so the board prints the set the loop's floor enforces. `Collect` injects none; `Server.Snapshot` carries the server's. A missing registry is the compiled baseline, silently; an unreadable or malformed one, or a weak spine, is a warning (`config.IsRegistryFault`). Pinned by `TestServer_SnapshotReflectsTheInjectedEnvironment`.
- **What ran has one precedence rule** (`phaseHistory`): a running cycle reads its Signal Center stream (`signalcenter.KindPhaseOutcome`), because `phase-timing.json` is flushed only at closeout; a sealed cycle reads `phase-timing.json`, the durable record joined with the model attribution; either falls back to the other when its own record is empty. Pinned by `TestPhasePlan_PhaseHistoryPrecedenceIsStateDriven`.
- **Gate marks are evidence, never inferred.** A step is `GateVerified` only when the stream holds `gatesignal.CodeVerified` for it. A missing stream yields nothing, a torn line is skipped, and a read that stops early is a warning. `streamReader` re-reads a stream only when its mtime or size changed, because a sealed cycle's stream never changes and the board re-collects every tick. Pinned by `TestStreamReader_CachesByModTimeAndSize`.
- **Step statuses**: `pass`, `warn`, `fail` (the last run's verdict), `incomplete` (a run with no recognised verdict, drawn but never counted as passed), `ongoing` (the running cycle's current phase), `pending` (a mandatory phase the running cycle has not reached), `unreached` (a mandatory phase a sealed cycle never ran), `skipped` (a mandatory phase the cycle went past without running). A phase outside the walk order (an optional insertion, or a mandatory phase outside `spine_order`) has position -1: it never moves the frontier and is never skipped. A registry without `spine_order` walks the mandatory list. Pinned by `TestPhasePlan_PlanStep_WireShape`, `TestPlanStep_UnknownVerdictIsIncomplete`, `TestPhasePlan_WarnSkippedAndRepeatedOngoing`, `TestPlanStep_SealedCycleMarksUnreachedAndRounds` and `TestReadPlan_UnorderedMandatoryPhaseIsUnreachedNotSkipped`.
- **Counts**: `Required` is the mandatory steps plus the conditional-mandatory ones that ran, `PassedRequired` how many of those passed; `Total` and `Passed` count every step. Pinned by `TestPhasePlan_LiveLaneCountsRequiredPassedOngoingAndRemaining`.
- **The advisor's proposal** is the newest of `phase-replan.json`, else `phase-plan.json` (a `router.PhasePlanEntry` array), sorted against the sequence: proposed to run and not held (not run, not ongoing, not scheduled by the floor), proposed to skip and not run, and proposed to skip but run anyway (the floor overrode it). A newer file that is torn is a warning and yields nothing, never the older file labelled as current. Pinned by `TestPhasePlan_TornSourcesAreSaidNotSubstituted`.
- **A dossier-only cycle has no plan**, and plan warnings carry the `cycle <N>` prefix (`TestReadPlan_PlanWarningsCarryCyclePrefix`). The detail endpoint carries the same plan as the board (`TestCollect_CyclesCarryTheirPlan`, `TestServer_CycleDetailCarriesThePlan`).

### Serving

- **Every handler is GET and none writes under the root.** Routes: `/`, `/static/`, `/api/snapshot`, `/api/cycle/{id}`, `/api/artifact/{id}/{name}`, `/events`.
- **Loopback is not a read boundary on its own.** `DefaultAddr` is `127.0.0.1:8090` because the page renders LLM-authored text and there is no authentication. `hostGuard` answers `421 Misdirected Request` to any `Host` that is neither a loopback name (`127.0.0.1`, `localhost`, `::1`) nor the host the server bound: a DNS-rebinding page cannot forge a loopback `Host`, and an operator who binds a LAN address has opted in to that name. `normaliseHost` (host part, IPv6 brackets stripped, lower-cased) is shared by the check and the registration. Pinned by `TestServer_HostGuardRejectsRebinding`.
- **Hostile text stays text.** The shell carries a CSP (same-origin scripts, styles and fetches; no framing, no base-URI or form-action rewriting), JSON is HTML-escaped, and artifacts are always `text/plain` with `nosniff`. Pinned by `TestServer_IndexAndStaticAreServedWithCSP` and `TestServer_ArtifactEndpointIsPlainTextAndGuarded`.
- **Artifact reads are allowlisted, symlink-safe and capped.** A name is a plain file name with a known extension (`md`, `json`, `txt`, `ndjson`, `log`, `yaml`, `yml`): no separators, no dot-segments, no hidden files, so lock sidecars and `.lease` are never listed or served. `ReadArtifact` requires a regular file by `Lstat`, opens it with `reportdoc.OpenRegularNoFollow`, and checks the opened file is the one it stat'ed. A file over `ArtifactMaxBytes` (2 MiB; audit reports are budgeted at 32 KiB, while logs and ledgers can run to megabytes) is refused with `ErrArtifactTooLarge` (HTTP 413), never streamed unbounded. Pinned by the `TestReadArtifact_*` tests and `TestListArtifacts_SortedAllowlistedRegularOnly`.
- **The cycle detail** (`/api/cycle/{id}`) reads the cycle fresh from its workspace and joins the dossier of the snapshot's epoch, so it needs no second scan of the corpus; a cycle the cap excluded falls back to a single-file dossier read, and a torn one answers with the warning, not a bare 404. The board's per-lane state, ongoing phase and plan override the fresh read when the cycle is on the board. `PrimaryReport` is the audit report for a failed cycle and the build report otherwise, registry-derived so the client never spells a name. Pinned by `TestServer_CycleDetailServesCapExcludedDossier` and `TestServer_CycleDetailWarnsOnTornCapExcludedDossier`.
- **`Options` zero values select the defaults**: poll 2 s, 40 cycles, SSE keep-alive 15 s, `time.Now`.

### Change detection and the event stream

- **The fingerprint reads no content.** It stamps the mtime and size of the brake file, the cycle-state file, the dossier directory, the inbox and its lifecycle directories, `.evolve/runs`, and, per workspace, the directory, its cycle-state, `run.json`, phase timing, `llm-calls.ndjson`, lease and audit report. Directory mtimes move on every create or rename (every atomic write); file stamps catch in-place appends and same-size rewrites. Pinned by `TestServer_FleetPhaseUpdateRefreshesSnapshot` (a same-length phase-name rewrite) and `TestServer_SSEPushesOnChangeAndKeepsAlive`.
- **`refresh` publishes once per fingerprint.** `refreshMu` serialises it, so racing callers (`Run`'s startup poll and on-demand readers) see each other's publish and never bump the sequence twice for one fingerprint. Pinned by `TestServer_UnchangedRootDoesNotBumpSeq` and `TestServer_ConcurrentOnDemandReadersPublishOnce`. `Handler` without `Run` builds the snapshot on demand (`TestServer_HandlerWithoutRunBuildsOnDemand`).
- **`publish` never blocks.** A subscriber whose buffer is full misses an intermediate notice and re-fetches the newest snapshot on the next one.
- **One SSE stream per page.** Frames are `event: snapshot` / `id: <seq>` / `data: {"seq":<seq>}`, plus `: ping` comments every keep-alive so proxies and ssh tunnels keep the connection open; the client re-fetches `/api/snapshot` on each notice. `handleEvents` subscribes before it reads `current()`: `current()` may build the first snapshot and publish it to the channel just subscribed, and `seq <= last` drops that echo, so the client sees each sequence number once (a repeated id reads as a phantom change). The code keeps a one-line why for this ordering, since no test pins it deterministically.
- **Shutdown never leaves a stream behind.** `Serve` installs its context as every request's `BaseContext`, so cancelling it ends open streams and `Shutdown` completes instead of timing out behind them (`TestServer_ServeCancelClosesOpenSSEStream`, `TestServer_ServeStopsOnContextCancel`). `WriteTimeout` stays zero on purpose, because a server-wide write deadline would kill the stream; the code keeps a one-line why for it, since no test pins it.

### The inbox queue

- **The queue is the inbox rank.** `readQueue(root, now)` ranks every pending item against the whole queue with the evolve dir's own rank inputs (`rankinputs.Load(…, now)`, the collector's clock) and lists them in that order; `QueueItem` carries `score` beside `weight`, and the inbox table shows the score. A loader problem (an unreadable recurrence ledger, a malformed policy) is an `inbox rank: …` line in `Snapshot.Warnings`, never a page failure. Until P2 of the [inbox prioritization plan](../../plans/inbox-prioritization-2026-10.md) (2026-10-06) the queue sorted by weight, then id. Pinned by `TestReadQueue_PendingFollowsTheInboxRankAndCarriesEachScore` and `TestReadQueue_AnUnreadableLedgerIsAWarning`.

## Invariants

- **Read-only.** No handler writes, and no read takes a flock sidecar.
- **A live lane is never hidden by the history cap** (`TestCollect_FleetLivenessSurvivesHistoryCap`).
- **Liveness is a fresh lease whose identity matches the state**, never a PID (`TestReadLoop_FreshLeaseIsRunning`, `TestCollect_FleetStateIdentityAndCorruptionWarn`).
- **A torn source is said, never substituted** (`TestPhasePlan_TornSourcesAreSaidNotSubstituted`, `TestReadFailure_TornArtifactIsWarnedNotSilent`).
- **Only loopback names or the bound host are served** (`TestServer_HostGuardRejectsRebinding`).

## Findings

- Auditors re-cite a defect under its old id with a reworded title, and occasionally renumber a finding while keeping its wording; matching by lead clause or by id plus severity covers both.
- When the run workspaces alone outnumber `MaxCycles`, `selectCycles` keeps only the newest of them, so an older non-running workspace cycle drops off the board; only running lanes are exempt from the cap.
