## Purpose

`internal/phasecontract` is the single source of truth for what each phase must deliver: the report headings the classifiers require (`Report`, `Section`), the per-protocol deliverable contract (`Contract`: location, kind, well-formedness rules), its rendering into the dispatch prompt, the machine-readable verdict sentinel, and the file-naming rules for artifacts, round archives, prompts and the challenge token.

## Design

- **Two halves.** `Report` holds the heading strings the six built-in classifiers test and the producer agents must declare. `Contract` adds where the deliverable lands, its kind and its rules. Built-in contracts take their `Sections` from the `Report` vars through `alwaysOn`, so a heading is typed once.
- **Only the strings live here.** Match semantics that `phasespec.ClassifyRules` cannot express stay in each phase's classifier: build's OR of headings, scout's and triage's heading plus at least one item, tdd's OR within AND, audit's verdict-token extraction. That logic is stable; the strings are what drift against the templates.
- **`Section.Accepted`** lists the canonical heading first, then tolerated legacy variants, so a report written against an older template still classifies PASS. A section is satisfied when any variant is present.
- **Verdicts only for audit.** Audit is the only built-in whose classifier extracts a verdict token. The other built-ins classify on section presence and leave `Verdicts` nil, so the contract gate stays additive: it requires what the classifiers already require, plus location.
- **Router: one persona, three protocols.** `router`, `router-replan` and `router-proposal` share `AgentName: "router"` but have distinct contracts and artifacts, so a replan or proposal self-check never validates a stale whole-cycle plan. `routing-plan.json` is a bare JSON array, so it has no required keys.
- **Location-only registrations.** `retro` and `build-planner` are registered with nil `Sections` and `Verdicts`: the gate gains location and well-formedness checks without inventing section requirements those phases never emitted.
- **`ship` is `NoArtifact`.** Its deliverable is the pushed commit, enforced by the ship-gate and the commit-gate attestation. The explicit contract makes the gate pass it instead of failing open on an unknown phase. `ArtifactName` returns `""` for it; `ArtifactFilename` falls back to the convention.
- **Staged sections.** `HandoffSummary` is declared on the build, scout and audit reports, and producers must declare it (`TestProducersDeclareCanonical`), but its presence and size are judged by the report-size gate (`deliverable.VerifyWithReportSize`, shadow by default). `stagedSections` keeps it out of the always-on set (`alwaysOn`, `Report.Complete`), so it cannot block a report before that gate is promoted, and stays decoupled from the challenge-token, failure-context and breaker checks.
- **Conditional sections.** `ExplanationSections` are owed only while `Roots.ExplanationDocumentationVersion` is non-zero. Every verifier reads the version from `Roots`, so the self-check and the gate agree.
- **`Roots` carries the verifier's context.** `DispatchedArtifact` is the exact path the runner dispatched and overrides the contract path: intent in delta mode writes `intent-delta.md` while the registry names `intent.md`. Only the runner sets it. `Cycle` locates per-cycle effect state; 0 means unknown.
- **Failure-context flags.** `RequireFailureContext` (audit, and user phases that emit verdicts and opt in through `classify.require_failure_context`) makes a FAIL/WARN sentinel without a failure block a violation. Prose-only verdicts stay legal. `RequireFailureContextPhaseIO` (build, scout, triage) applies the same check only at `EVOLVE_PHASE_IO>=enforce`; it is a separate field so audit's enforcement is untouched.
- **`RequireChallengeToken`** is set on build only. The runner injects the token block at dispatch and the gate checks the echo, so the correction loop re-dispatches with the fix before audit. It fails open when no token was minted. Scout mints the token, so scout must never set it.
- **Spec-derived contracts.** `FromSpec` derives well-formedness only: location, kind, sections. Verdicts attach only to an evaluate phase that declares `classify.verdict_on_pass`. `kindFromArtifact` reads the artifact extension; it is unrelated to `PhaseSpec.Kind`, which describes the runner. `sectionsFromClassify` accepts both the `## `-prefixed heading and the bare token, and does not re-prefix an author's `#` heading.
- **`SynthesizesContract`** is the single home of "does this spec get a derived contract": an `llm` phase, or one that declares `outputs.files`. `CatalogResolver.Resolve` and any projection (inventory, lint) must consult it before `FromSpec`.
- **Prompt rendering has three parts.** `RenderContractBlock` is the invariant instruction block in the cacheable prefix. `RenderContractFooter` is the volatile path line. `RenderContractTail` restates the machine half as XML at the generation point. `RenderContractBlockStage(c, false)` is byte-identical to `RenderContractBlock`; the dispatch path sets `includePhaseIO` at `EVOLVE_PHASE_IO>=advisory`, which gives build, scout and triage a self-report-failure channel without forcing a verdict on a successful run.
- **One exemplar, one command.** `failureExemplar` and `selfCheckCommand` are shared by the block and the tail so the two copies cannot drift. Where a FAIL/WARN without a failure block is a violation, the tail's exemplar carries the block, because the tail is the copy the agent follows. The self-check placeholder stays literal, not XML-escaped, because an agent pastes it into a shell. `exemplarClass` draws the exemplar's class from the `failurelog` vocabulary (`code-audit-fail` for audit, `code-build-fail` otherwise), because the gate refuses a class outside it.
- **The failure block.** `Prescription` carries a WARN's named remediation for a foreseen risk. It is kept apart from `Defects` so consumers can tell a fix-to-apply from a thing that is wrong.
- **`ReadFailureBlock`** is the one reader for router signal lifting, orchestrator faillearn and the classifier. It tries the registered markdown artifact, then `<phase>-report.md`. A readable report without a block does not end the scan, because a user phase may write its registered artifact clean and carry the block in the conventional file.
- **`ChallengeToken`** is the reader the phase runner's prompt preparation and the verdict engine's ACS floor share. Four readers outside the runner still spell the read inline; consolidating them is follow-up F1b in [decomposition/11-phaserunner.md](../decomposition/11-phaserunner.md).
- **`PromptArtifactFilename`** has three readers: the bridge writes `<agent>-prompt.txt`, the audit's probe quarantine anchors on it, and the repair-round archiver retires it through `RoundArchiveFilename`.

## Invariants

- **Every canonical heading is declared by its producers.** A template rename would otherwise false-FAIL valid reports at cycle time. Pinned by `TestProducersDeclareCanonical` and `TestExplanationDocumentation_TitleAndProducerDeclaration`. To fix a failure, change the template and `contract.go` together.
- **Built-in sections derive from the `Report` vars, minus staged sections.** Pinned by `TestBuiltinReportVars_WiredIntoRegistry`; the HandoffSummary scope by `TestBuildScoutAudit_RequireHandoffSummary` and `TestTDDIntentTriage_NotExpanded`.
- **No verdict requirement on a section-classified phase.** A verdict the phase never emits would false-block at enforce. The one-line why stays on the registry; the tail side is pinned by `TestRenderContractTail_SentinelOnlyForVerdictPhases`.
- **Built-ins are authoritative.** A clashing user spec never overrides a built-in contract. Pinned by `TestCatalogResolver` and `TestResolveBuiltinStaysAuthoritative`. Both resolvers return identical contracts for every built-in: `TestProperty_BuiltinAndCatalogResolversAgreeOnBuiltins`.
- **Owed files and effects come from the registry only.** `overlayDeclared` is a pure projection, so a built-in that set them would be silently clobbered. Pinned by `TestBuiltins_DeclareNoOwedFilesOrEffects`; the overlay by `TestCatalogResolver_OverlaysDeclaredFieldsOntoBuiltins`.
- **The agent is shown every enforced requirement.** Pinned by `TestProperty_RenderBlockListsEveryEnforcedRequirement`.
- **The prefix block is deterministic and path-free**, for prompt-cache safety. Pinned by `TestRenderContractBlock_Deterministic` and `TestRenderContractBlock_Markdown_NoPath`. `RenderContractBlockStage(c, false)` equals `RenderContractBlock(c)`: `TestRenderContractBlockStage_BuildFailureInstructionGated`.
- **The printed exemplar never reads as a real verdict.** The failure-bearing exemplar carries placeholder tokens, so the parser must reject it. Pinned by `TestRenderContractTail_ProjectsPathSectionsAndSentinel`.
- **Artifact names agree across their homes.** `ArtifactName` equals the profile's `output_artifact` basename (`TestArtifactNameMatchesProfileOutput`) and the registry's `outputs.files[0]` (`TestRealRegistry_BuiltinArtifactNameMatchesDeclaredPrimary`). Every built-in with an artifact reaches its registry entry through `RegistryKey` (`TestRealRegistry_EveryBuiltinWithArtifactResolvesARegistryEntry`).
- **`ArtifactFilename` is never empty**, because a caller would join the workspace directory itself. Pinned by `TestArtifactFilenameNeverEmpty`.
- **`RequiredRoles` and `RequiredArtifacts` derive from the registry and return fresh slices.** Three packages keep them in package-level vars, so an aliased slice would let one caller's write corrupt another's. Pinned by `required_ssot_test.go`.
- **A native executor with no declared output gets no derived contract.** Nothing would write an invented `<name>-report.md`. Pinned by `TestResolveNativeExecutorWithoutOutputsHasNoContract` and `TestSynthesizesContract_Branches`.
- **Scout never sets `RequireChallengeToken`**, since echoing its own token is circular. Not pinned by a test; the one-line why stays on the field.
- **Placeholder echoes are rejected.** An entry that is wholly one `<…>` token, in any of `Defects`, `EvidencePaths` or `Prescription`, disqualifies the sentinel, even beside real entries. Pinned by `sentinel_amplify_test.go` and `TestParseVerdictSentinelFull_RejectsPlaceholderEcho`.
- **v1 sentinels stay legal forever.** A nil failure block renders the v1 line byte for byte. Pinned by `TestRenderVerdictSentinelWithFailure_NilIsV1` and `TestParseVerdictSentinelFull_V1Compat`.
- **Trailing-byte tolerance widens only the candidate set.** The guards are unchanged; a comment whose payload used to be rejected for trailing bytes can now win tail-anchored selection. That is acceptable because the artifact's author controls the verdict outright.
- **`OwedPath` takes the basename**, so a declared separator never steers a read outside the workspace. Pinned by `TestOwedPath_IsTheOneJoinTheGateReads`.
- **Round indices are canonical integers.** `ParseRoundArchive` rejects padded and non-numeric indices. Pinned by `TestParseRoundArchive`.

## Findings

- **cycle-192** ([ADR-0033](../adr/0033-structured-verdict-single-source-of-truth.md)): classifiers grepped for headings the templates no longer emitted; a build false-FAIL tripped the auditor's cross-check and nothing shipped. The earlier `64b2d95` fix widened the regexes but left the strings duplicated in six files with no alarm. This package and `TestProducersDeclareCanonical` are the fix.
- **cycle-148**: verdict drift between `## Verdict` and `**Verdict:**` motivated the machine-readable sentinel ([ADR-0034](../adr/0034-unified-deliverable-contract.md), Layer 5).
- **cycle-269**: proof-of-read was enforced only at audit, where it could not be recovered, and the Go migration had dropped the prompt-side injection. `RequireChallengeToken` moved the check to the contract gate.
- **cycle-281**: the spec-derived fallback invented `ship-report.md` for the native ship phase, so every shipping cycle hit three enforce blocks and survived only through the breaker's demotion. That produced `SynthesizesContract`, and later the explicit `ship` `NoArtifact` contract.
- **router bare array**: the router contract once required a `plan` key while `PhaseAdvisor` writes a bare array, so `evolve phase verify router` failed every cycle.
- **intent delta path skew**: intent in delta mode dispatched `intent-delta.md` while the gate judged `intent.md`, a file the phase was never asked to write. `Roots.DispatchedArtifact` makes the dispatched and verified names one source.
- **cycle-565** (slice S1 of report-size contracts): `HandoffSummary` arrived as a staged section, observed through the report-size gate before any enforcement.
- **cycle-603**: a captured scrollback carried the contract's own printed FAIL example and won verdict classification. The placeholder-echo guard followed ([ADR-0039](../adr/0039-failure-floor-and-failure-signal-contract.md)).
- **cycle-1140**: `retro` and `build-planner` filenames lived only in `backfill.phaseHeaders` and `core.backfillArtifactPath`, and cyclehealth, redteamcheck and ledgerverify each typed their own required-role list. Registering the phases and deriving `RequiredRoles`/`RequiredArtifacts` from the registry fixed both (the campaign retrospective of cycles 215-231 named such replicated vocabularies one disease).
- **cycles 1145 and 1147**: `ArtifactName` and `ArtifactFilename`; see [deliverable-contract.md](../deliverable-contract.md#reading-the-registry-from-go-cycle-1145).
- **cycles 1298 and 1478**: tail-anchored selection and trailing-byte tolerance; see [deliverable-contract.md](../deliverable-contract.md#verdict-sentinel-strangler-fig).
- **cycle-1327** (F3 in [batch-integrity-review-2026-08-04.md](../../operations/batch-integrity-review-2026-08-04.md)): a WARN audit's prose remediation left no machine-readable trace, so the fix silently vanished. `FailureBlock.Prescription` is the wire half.
- **cycle 1684**: the audit declared a failure class outside the vocabulary and the retry envelope declined the repair round silently. The contract block now lists the vocabulary and `exemplarClass` draws from it; see [verification-wave-findings-2026-09-14.md](../../research/verification-wave-findings-2026-09-14.md).
