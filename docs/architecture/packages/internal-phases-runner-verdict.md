## Purpose

`verdict` is the judge of every subagent-dispatching phase. `Engine.Judge` takes one `Dispatch` (what the request named, what preparation snapshotted, what the bridge did) and returns the `core.PhaseResponse` core routes on. It reconciles a bridge teardown against the contracted deliverable, then classifies the chosen bytes with the phase's own hook, applies the ship guard and reports its WARN decisions to the Signal Center.

## Design

- **Two steps.** `reconcile` (`reconcile.go`) interprets the bridge outcome and returns an early response only when the phase cannot go on to classification. `classify` (`classify.go`) selects the verdict bytes, writes the clean-stdout companion, runs `Classify`, applies the ship guard and appends the reconcile trail. `settle.go` holds the one settle ladder both steps call, and `artifact.go` the on-disk helpers.
- **Strategies, not ownership.** `Verify` is the host's resolved probe (`Options.VerifyFn` or the catalog-aware default). `Classify` is the phase's verdict hook, bound by the host per call over its request and bridge response. The engine judges bytes it never reads for itself and applies a verdict rule it never owns, and it never sees `core.PhaseRequest` or the host's `Hooks`.
- **Construction.** The probe is positional and required; a nil probe panics at first use, with no guard (`TestNew_PanicsAtFirstUseWithoutVerify`). Every other seam is a functional option with the host's default: `WithSleep` (default `time.Sleep`; the host passes its sleep seam so its tests count intervals), `WithStdoutFilter` (nil writes no companion), `WithOptional`, and `WithSignals`, an accessor read at every use so a Center wired after construction still receives events.
- **`Identity` is the engine's own type.** It names the dispatch to the verifier, so a salvage the verifier performs is reported under the cycle and run it belongs to. The leaf does not import the gate reporter; the host adapts the type.
- **A leaf with one voice.** Non-test sources import the standard library plus `coherence`, `core`, `deliverable`, `paths`, `phasecontract` and `signalcenter`, never the host, `internal/log` or the bridge (`TestImportGraph_LeafImportsOnlyTheDeclaredPackages`). The check covers direct imports only; `coherence` reaching `policy` transitively is fine. The leaf writes nothing to the process streams and reads no environment; the Signal Center is its only voice (`TestNoStderrNoEnv_InTheLeaf`, a source scan because a stray stream write is invisible to every other test).
- **One producer.** `warn` emits a `runner.warning` WARN under module `runner`, stamped with the dispatch's cycle, phase and run id and the emitting method as origin. Empty field values are dropped so every code stays under the Center's field cap; `TestForensicFail_EmitsOneEventWithTheGoldenFields` asserts the largest event keeps one slot of slack. The five codes and their field vocabularies are registered in `verdict.go`'s `init`.
- **The settle bounds are exported** (`SettleRetries`, `SettleInterval`) so the host projects them for the settle tests it keeps. They are a liveness ceiling of about three seconds for a deliverable still flushing, never the verdict-correctness mechanism; that is the verdict-source rule.
- **`Snapshot` shares the bridge's key.** The (size, mtime) identity is the key the bridge's completion stability window uses (`internal/bridge/completion.go`), so the runner's and the bridge's notion of "unchanged" cannot drift. Only `StatSnapshot` mints one: the host takes it before dispatch and the engine judges it after.
- **`rootsFor` is the one translation** from a dispatch to `phasecontract.Roots`, shared by the clean-exit probe and the teardown probe so they can never resolve different paths or a different cycle for one phase. `EvolveDir` is set only with a project root, through `paths.EvolveDirOf`; it completes the orchestrator-target and declared-effect roots and locates the merged catalog for the catalog-aware default. `Cycle` names the `processing/cycle-N/` a declared effect is judged under ([ADR-0100](../adr/0100-declared-deliverables-gate.md)). Pinned by `TestRootsFor_CarriesCycleAndEvolveDirOnlyWithAProjectRoot`, which also scans the sources for an inline `.evolve` spelling, since a value comparison cannot tell `EvolveDirOf` from an inline join.
- **The ACS floor reuses `coherence.ReadCycleVerdicts`,** so "audit and ACS both PASS" has one definition, the same condition the coherence floor flags as incoherent, and the sentinel parse keeps its placeholder-echo guard. The challenge token is read only through `phasecontract.ChallengeToken` (`TestChallengeToken_ReadThroughPhasecontract`).
- **The clean-stdout companion's filename is the writer's belief** (`logfilter`). The engine passes workspace and phase and never spells the path.
- **Testing.** The package is in `go/.apicover-enforce` and `go/.cover-strict` at 100%. Both count package-local tests only, so every export is named and exercised here (`TestAPICover_EveryExportIsNamedAndExercised`). Every test injects `WithSleep`, so none sleeps. `TestJudge_ReplaysTheHostGoldens` replays the host's response and probe goldens (`testdata/`, captured through `runner.New` and `Run` before extraction) through `Judge` with equivalent fakes; `replayScenarios` mirrors the host's `verdictScenarios` table row for row. `TestLimits_FunctionsFilesAndNestingStayWithinTheBar` enforces functions under 50 lines (comments inside a function count), nesting of at most 4 and files under 800 lines.

## Invariants

- **The teardown arm order is stale refusal → well-formed → optional degrade → ACS floor → forensic FAIL.** Each arm is reached by its own row in `TestReconcileTeardown_ArmOrderIsStaleOKOptionalACSFloorForensic`. The optional-before-floor order is unobservable, because audit is never optional; it is kept structurally.
- **Staleness is read before the probe.** The verifier may salvage and rewrite a leftover, and a leftover the probe repairs must still be refused as a prior attempt's report. The code keeps a one-line why; pinned by `TestReconcileTeardown_LeftoverRepairedByTheProbeIsStillRefused`.
- **A stale leftover closes both reconcile doors.** A deliverable unchanged since the pre-dispatch snapshot carries this cycle's token and may be well-formed, so neither the well-formed fall-through nor the ACS floor may accept it. The refusal fires only on an OK probe; a stale, malformed leftover stays `cause=malformed`. Pinned by the stale rows of the arm-order test.
- **Snapshot comparison fails open.** `unchangedSince` reads any error or non-regular file as changed, so a doubt never refuses a reconcile. `StatSnapshot` uses `Lstat` and snapshots only a non-empty regular file. Pinned by `TestUnchangedSince_FailsOpenOnErrorAndNonRegular` and `TestStatSnapshot_RequiresNonEmptyRegularFile`.
- **A substantive bridge error hard-fails without the deliverable.** Launch, boot, safety and cost failures make on-disk output untrustworthy, so the phase FAILs whether optional or not, without probing, without `Classify` and without an event, because core's phase-outcome chokepoint codes the same returned error. Pinned by `TestJudge_SubstantiveBridgeError_FailsWithoutTheDeliverableOrTheStream`.
- **A FAIL arm wraps the bridge error.** `fmt.Errorf("%s: bridge: %w", ...)` keeps the infra sentinel reachable through `errors.Is` for core's `IsInfraTeardownError` and `bridgeExitCode`. Pinned by `TestJudge_TeardownErrorChainSurvivesTheWrap`.
- **Only a not-OK probe retries.** A probe error means no contract or an IO fault, which waiting cannot fix, so it returns at once and an uncontracted phase pays zero retries. A missing file is `missing_artifact` with a nil error and does retry. `attempts` counts re-probes, not the first probe. Pinned by `TestSettle_BoundedAt1PlusRetries_StopsOnOKOrError_CountsReprobes`.
- **The ladder checks ctx before and after each sleep.** The injected sleep cannot be interrupted, so the cost after a cancel is at most one interval and no further probe. The first probe always runs, so a deliverable already on disk is still caught. Pinned by `TestSettle_HonoursCancellationBeforeAndAfterTheSleep`; the teardown ladder's immunity by `TestJudge_TeardownLadderIsCancellationImmune_CleanExitLadderIsNot`.
- **The classified bytes come from at most one read.** `classifiedArtifact` uses the verified bytes only when they describe the dispatched file and are non-empty, because an infra read fault returns an empty result and a deliverable that lands after the last probe verifies absent. It then reads the dispatched file once. An absent file that failed verification classifies as `""`, a coherent FAIL rather than a pane-scraped verdict; the pane survives only for a path-less result (a NoArtifact contract). Pinned by `TestClassifiedArtifact_VerifiedBytesThenOneReadThenPaneOrEmpty`.
- **The ACS floor rescues only an authenticated audit.** It needs the audit phase, audit and acssuite both PASS, and the verified report echoing this cycle's trimmed, non-empty challenge token. The acssuite verdict is a non-LLM signal a session stall cannot corrupt; the token stops a stale, forged or cross-cycle report from being laundered to PASS. With no probed bytes the floor reads the file once and adopts path and bytes, so the rescue and `Classify` judge the same bytes. Pinned by `TestRescueViaACSFloor_RescuesOnlyAudit_PassPass_TokenEchoed_LateReadOnce`.
- **A floor rescue is never a silent bypass.** The response lists the violations the floor overrode, so a hygiene flag such as `stray_in_worktree` stays visible. Pinned by `TestReconcileTrail_EmitsOneReconciledEventViaVerifyOrACSFloor`.
- **A reconciled phase completed.** The agent's own verdict stands with a nil error, so a reconciled FAIL routes as a real FAIL, not an infra retry. One `RUNNER_RECONCILED` event per reconcile, emitted by `classify` once the verdict is known; a failing stdout filter's WARN precedes it (`TestWriteCleanStdout_NilFilterSkips_ErrorIsACodeNeverAnError`).
- **An optional phase degrades to WARN** on a teardown with no trustworthy deliverable, because its successor runs regardless of its verdict. Pinned by `TestDegradeOptional_WarnResponseAndOneEvent`.
- **The ship guard downgrades only a clean-ship claim.** PASS and any non-canonical verdict become FAIL when the deliverable failed its contract; FAIL, WARN and SKIPPED pass through, and `NextPhase` is untouched. Pinned by `TestApplyShipGuard_DowngradesOnlyUnverifiedCleanShipVerdicts`.
- **`RUNNER_DELIVERABLE_UNVERIFIED` is fault-only.** It fires only when an unverified deliverable ends in FAIL; a WARN or SKIPPED pass-through emits nothing, though its violations still reach the diagnostics. Pinned by `TestClassify_UnverifiedDeliverable_SignalsOnlyWhenTheFinalVerdictIsFail`.
- **The stdout companion never blocks.** A failing filter is one `RUNNER_STDOUT_FILTER_FAILED` event and the verdict stands, because the raw log stays the forensic source. Pinned by `TestWriteCleanStdout_NilFilterSkips_ErrorIsACodeNeverAnError`.
- **`forensicSnapshot` discards the read error.** A directory renders `size=N tail=""`, and the rendered bytes are pinned by a golden (`TestForensicSnapshot_AbsentSizeTailAndDirectory`). The code keeps a one-line why.
- **`Dispatch` is built positionally in the leaf's test,** so a new field breaks that literal at compile time and the host's `dispatchOf` projection is revisited instead of silently zeroing (`TestDispatch_HasExactlyTheDeclaredFields`).
- **Signals are a Null Object.** A nil accessor, or one returning nil, never changes a verdict (`TestWithSignals_NilIsTheNullObject`, `TestWithSignals_ReadsTheCenterLive`).

## Findings

- **cycle 603, recurring through cycles 877 to 921** ([ADR-0072](../adr/0072-system-failure-policy-and-halt.md) verdict incoherence): the terminal pane lost the real sentinel to a TUI write collapse and carried the contract's prompt-echoed example sentinels, so classifying it fabricated a verdict the agent never emitted. That produced the verdict-source rule: a contracted phase is judged only on its deliverable.
- **cycle 921**: a clean-exit agent returned control before its report write landed. The settle ladder is the liveness answer; see the runner notes for the widened window.
- **cycle 3 retrospective**: a teardown false-FAIL recorded no reasoning. The forensic event now carries the roots the probe judged, the violation codes, the report and ACS on-disk state and the cause, and the FAIL message names the first violation or the stale refusal.
- **F22** (cycle 1685, [verification-wave findings](../../research/verification-wave-findings-2026-09-14.md)): once the verifier could salvage and persist a repaired artifact, a probe could rewrite a prior attempt's leftover before the stale check saw it, defeating the cycle-1550 guard. Staleness is now read before the probe.
- The extraction folded four hand-written stderr lines into coded events and merged the two INFO lines of a reconcile (ACS floor, reconciled) into one `RUNNER_RECONCILED`; `RUNNER_OPTIONAL_PHASE_DEGRADED` was new, since that arm had been a response diagnostic only ([decomposition unit 11](../decomposition/11-phaserunner.md)).
