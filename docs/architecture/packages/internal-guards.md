## Purpose

`internal/guards` is the in-process trust kernel. It holds the five `core.Guard` implementations that `evolve guard <name>` runs as Claude Code PreToolUse hooks, and `ProtectedSurfaceManifest`, the single list of the pipeline control plane that no autonomous cycle may modify. Other packages (the ship tripwire, the build floor and the fleet preflight) inject `IsProtectedSurface` rather than keeping their own list. The inbox routing roots and triage's breaker judge with `lanerouting.Forbidden`, which composes `IsProtectedScope` with the build profile's sandbox deny list ([internal-lanerouting](internal-lanerouting.md)).

## Design

- **One decision per process.** `internal/cli/guardcmd` builds one guard (`buildGuard`), reads the PreToolUse JSON from stdin, calls `Decide` once, appends to `.evolve/guards.log`, writes an `Alarm` decision to `.evolve/integrity-alarm.jsonl`, and exits 2 on deny. `.claude/settings.json` wires `ship`, `phase`, `role` and `docdelete`. `chain` is run by hand (`evolve guard chain`, the same check as `evolve ledger verify`).
- **The guards.**

| Guard | Tool | Rule | Off switch |
|---|---|---|---|
| `chain` | any | allow only while the ledger's hash chain verifies | none |
| `phase` | `Agent` | deny during an active cycle, so phase agents go through the native bridge | `--bypass` |
| `role` | `Edit`, `Write` | per-phase write allowlist plus the control-plane boundary | `--bypass` (still alarms on a protected path) |
| `ship` | `Bash` | deny `git commit`, `git push` and `gh release create/edit` unless that simple command itself runs `evolve ship`; each command on the line is judged on its own | `--bypass` |
| `docdelete` | `Bash` | deny an `rm` whose line names `docs/` or `knowledge-base/` anywhere (case-folded, bare or as a directory; a command substitution can feed the `rm` a path another command names), an `rm` or `mv` run inside one (`cd`, `pushd`, `git -C`, or the shell's own directory), and an `mv` of doc content outside `docs/`; allow only an `rm`/`git rm` of exactly the active cycle's never-committed explanation document | `workflow.allow_doc_delete` |

- **The role guard's order.** A tool other than Edit/Write, or an empty `file_path`, is allowed. The path is cleaned once, so every later rule judges the file the write lands on. Then: `--bypass` allows (with an alarm on a protected path). An always-safe path (`/tmp/`, `<home>/.claude/`) is allowed unless it is protected. Missing storage or a cycle-state read error denies. Outside a cycle (`CycleID == 0`) everything is allowed. Inside a cycle a protected path is denied with an alarm; then retro may write the lesson corpus `.evolve/instincts/lessons/`; then any phase may write under its workspace; then a worktree phase (`core.WorktreePhase`: tdd and build) may write under the active worktree. Everything else is denied.
- **Run-scoped state.** A lane's guard reads `<worktree>/.evolve/cycle-state.json`, which `core.linkGuardDeps` links to the run's own `run.json` (the mirror `WriteCycleState` writes, [ADR-0049](../adr/0049-concurrent-multi-cycle-execution.md) CB.4). The host-global `cycle-state.json` can hold a different concurrent run's phase.
- **The manifest.** Each `ProtectedSurfaceEntry` is a lower-case, slash-normalized fragment and a rationale. A fragment matches anywhere in the normalized path, so the boundary holds in a cycle worktree, the branch root or main. A directory entry is used when every file in it is control plane; packages that are otherwise ordinary cycle territory (`core`, `phases/ship`, `phases/audit`) get file entries. The fragments are deliberately narrow: `go/acs/regression/` but not `go/acs/`, `registry_table.go` but not all of `flagregistry`, so a cycle still writes its own `go/acs/cycleN/` predicates and ordinary source.
- **Two projections of one manifest.** `IsProtectedSurface` is membership. `normalizeSurfacePath` makes the path slash-separated, cleans it (keeping a directory's trailing slash) so `..` cannot step around a fragment, adds a leading slash so a repo-relative path matches, and case-folds it. Appending one slash lets a slashless directory name (a package or import path) match its directory fragment. `IsProtectedScope` also answers "does this directory contain protected surface", which is the question a declared fix surface such as `"files": ["go/internal/core/"]` asks. Only a directory spelling widens it: a trailing slash, or a last segment with no dot after its first character. The inbox routing roots use scope; the role guard, the ship tripwire, the fleet preflight and triage's breaker keep membership.
- **Two tripwires, on different lanes.** `go/acs/regression/protectedsurface` walks the repo by name: every `*_gate.go` or `*guard*` file must be covered. `TestProtectedSurface_CoversEveryExplanationLifecycleCallSite` walks `go/internal` by call site.
- **The call-site scanner.** `explanationLifecycleVocabulary` derives the explanation-lifecycle API names from beliefs that already exist rather than a hand list: the callee and value columns of `explanationLifecycleCallPins` and `explanationLifecycleAssignPins`, the gate entry points of the activation belt, the two single-sourced callees, the free functions `core/build_explanation_handoff.go` declares, and the exported functions of `explanationdocs`. `explanationCallSiteFiles` reports each non-test file under `go/internal` that calls a vocabulary name or assigns one as a struct-literal value; the assignment is where the wiring decision lives. It resolves names with the pin tables' `expressionName`, and it skips `vendor/`, `testdata/`, `_test.go` files (a fixture is not a dispatch site) and files that fail to parse (a build concern). `go/cmd` and `go/acs` are not walked; no call site into the vocabulary lives there.
  - `DocumentPath` is excluded: it only formats a prompt-hint path, and including it would force a manifest row for all of `phases/build`.
  - Methods are excluded, because a method is never called by its bare name.
  - Two data references share vocabulary names (`explanationdocs.CurrentContractVersion` in `orchestrator.go`, `o.explanationContractVersion` in `cyclerun.go`). Both files are protected for their own reasons.
  - Known limit: a call through an interface or a func-valued field (`a.hooks.explanationCheck(a.req)`) resolves to the field path, not a vocabulary name. The scanner catches the wiring site instead.
- **Explanation single-sourcing pins.** `TestBuildExplanationLifecycleWiring` pins which function calls or assigns each lifecycle step. The activation cross-check lives only in `explanationdocs.CrossCheckActivation`, which both the ship and audit gates call. The explanation-review contract (status enum, build-status match, required or not-applicable switch, evidence references) lives only in `explanationdocs.ValidateReviewedHandoff`, read through `reportdoc.ReasonedReview`. Per-phase policy (heading, missing-handoff verdict, NEEDS_CORRECTION disposition) stays in each gate. The pin tables are package-level so the scanner reads the same lists.
- **The ship guard judges simple commands.** `splitShellCommands` (`shell_commands.go`) is a small quote-aware scanner. It splits a Bash tool command at `;`, `&`, `|`, newlines and parentheses into the commands the shell would run, and yields each command's text for verb matching and its unquoted words for naming the executable.
  - A command substitution, `$( )` or backticks, is a command of its own even inside double quotes, because the shell runs it before the command around it.
  - Comments and heredoc bodies are dropped. A heredoc opens only at an unquoted `<<` (not `<<<`) outside a comment and outside parentheses, where `<<` may be an arithmetic shift. The delimiter is the whole shell word after quote removal, as bash reads it (`EOF-MARKER`, `'END.'`, `"a\b"`, a line-continued word, a trailing CR), never an identifier prefix of it. A body closes at a line holding the delimiter after leading blanks, or the delimiter then `)`, and runs to the end of the input when unterminated.
  - Where the scanner and the shell could disagree, it errs toward showing the guard more text: an early close reveals lines, it never hides them.
  - A command is ship-class when its text matches the verb pattern or its words reach `commit` or `push` through git's global options (`git -C dir push`). It is allowed only when its own words, after any `VAR=value` assignments, are `<…/>evolve ship`.
- **What the ship guard cannot see.** It is a PreToolUse screen, not a shell. A verb assembled at run time (`P=push; git $P`, ANSI-C quoting such as `$'\x67it' push`, an alias, a function, `eval` of computed text) and a binary an agent names `evolve` are outside its reach. The ship tripwire, the commit gate and `evolve ship`'s self-SHA pin are the backstops ([ADR-0064](../adr/0064-pipeline-integrity-boundary.md)).
- **`helpers.go`.** `cmdString` and `strField` read a string from `tool_input` and return "" when it is absent or not a string. The unexported alias `core_GuardInput` lets `helpers.go` take the core type without importing `core`.

## Invariants

- **Every guard fails closed on missing state.** Missing storage or a cycle-state read error denies in `phase` and `role`; a nil ledger or any `Verify` error denies in `chain`. A guard that cannot see the cycle must not guess that none is running. Pinned by `TestPhase_NilStorageDenies`, `TestPhase_ReadCycleStateErrorDenies`, `TestRole_NilStorageDenies`, `TestRole_ReadCycleStateErrorDenies`, `TestChain_NilLedgerDenies`, `TestChain_DeniesOnAnyVerifyError` and `TestChain_DeniesBroken`.
- **The control-plane check precedes every allowance and applies to every phase.** A build phase may write source into its worktree but never the gate that grades it. The deny carries an alarm, so it lands in a dedicated channel rather than as a silent exit 2. Pinned by `TestRole_DeniesControlPlaneEditInBuildPhase` and `TestRole_DeniesRelocatedExplanationCallSitesInBuildPhase`.
- **An always-safe directory does not shield a protected file.** The global `~/.claude/settings.json` wires the hooks themselves; a cycle that rewrote it could disable every guard. Pinned by `TestRole_DeniesGlobalSettingsInCycle` and `TestRole_C1_DeniesGlobalSettingsUnsetHome`.
- **An emergency bypass of a protected path is allowed but alarmed; any other bypass is silent.** Pinned by `TestRole_BypassProtectedPathAlarms`.
- **Outside a cycle the operator may edit anything.** Control-plane changes ship through human-gated `evolve ship --class manual`, never an autonomous `--class cycle`. Pinned by `TestRole_OutsideCycleAllowsControlPlane` and `TestRole_AllowsGlobalSettingsOutsideCycle`.
- **The retro lessons allowance sits after the boundary** and is phase-scoped, so no protected path can ride it. It is fragment-anchored because the guard knows no project root. Pinned by `TestRole_LessonsAllowanceNeverCoversProtectedSurface`, `TestRole_RetroMayWriteLessonsCorpus` and `TestRole_NonRetroDeniedLessonsCorpus`.
- **Only worktree phases write into the worktree.** Scout, audit and the rest keep to their workspace. Pinned by `TestRole_TDDWritesTestsInWorktree`, `TestRole_NonWorktreePhaseDeniedWorktreeWrite` and `TestRole_BuildPhaseNoWorktree_DeniesNonWorkspace`.
- **The operator home is read once, and an empty home disables its rule.** `NewRole` reads `$HOME` once so one process makes one reproducible decision; `isAlwaysSafe` reads no environment. With no home, `filepath.Join("", ".claude")` would bless every relative `.claude/` path, and a `/tmp` fallback would silently turn the home rule into the `/tmp` rule. Pinned by `TestNewRole_ResolvesHomeFromEnv`, `TestIsAlwaysSafe_UnsetHomeNeverMatchesClaude` and `TestIsAlwaysSafe_DecidesAgainstTheGivenHome`.
- **An always-safe write never alarms.** A flood of false alarms is how a real violation hides. Pinned by `TestRole_AlwaysSafeDirs`.
- **The manifest is compiled, not config**, so a cycle cannot write a `.evolve/policy.json` knob that disarms it. The manifest protects itself through its `/go/internal/guards/` entry. The why stays in code; `TestProtectedSurfaceManifest_KeepsEveryPreRefactorFragment` pins the self-entry.
- **Every fragment is well formed.** It is lower-case (the path is case-folded, never the fragment), has no backslash, starts with a slash (so `go/acs` cannot match `lego/acs`) and carries a rationale. Pinned by `TestProtectedSurfaceManifest_EveryEntryDenies`, which also checks each entry denies in worktree-absolute and repo-relative form.
- **The original perimeter stays byte-for-byte.** Pinned by `TestProtectedSurfaceManifest_KeepsEveryPreRefactorFragment`.
- **The boundary stays narrow.** Neighbors of protected files remain writable. Pinned by `TestProtectedSurfaceManifest_NonProtectedPathsStillAllow`, `TestIsProtectedSurface` and `TestRole_AllowsLegitWorktreeWritesUnderProtection`.
- **Membership is not widened to scope, and membership implies scope.** The breaker must never be stricter than the seed that screens for it. The appended slash can only complete a fragment ending in a slash, so it changes no file match. Pinned by `TestIsProtectedSurface_MembershipStaysMembership`, `TestIsProtectedScope_ImpliedByMembership` and `TestIsProtectedScope_DirectorySpellingCoversTheSurfaceInside` (which also pins that the bare root `/` matches nothing).
- **Every compiled-default overlay skill is protected**, read from policy's own export so the next one cannot skip the manifest. Pinned by `TestProtectedSurface_CompiledDefaultOverlaySkills`.
- **Every explanation-lifecycle call site is protected.** Pinned by `TestProtectedSurface_CoversEveryExplanationLifecycleCallSite`. Its supports:
  - `TestExplanationCallSiteScanner_SeesEveryPinnedFile` is the anti-vacuity check: the scanner must find every file a pin table names.
  - `TestExplanationHandoffVocabulary_IncludesKnownLifecycleFunctions` and `TestExplanationDocsVocabulary_IncludesKnownVerificationFunctions` put a floor on the two derivation sources, so splitting either file fails directly.
  - `TestExplanationLifecycleImportAliases_NoneExist` enforces the scanner's precondition that nothing aliases or dot-imports `explanationdocs`. Any hit is a blind spot, so the bound is exactly zero.
  - `TestExplanationDocsExportedNames_ExcludedDocumentPathStillExists` fails a stale exclusion.
- **The ship guard ignores verbs inside heredoc bodies**, because a commit message may describe `git push`. `devolve ship` is not `evolve ship`. Pinned by `TestSplitShellCommands_DropsHeredocBodies`, `TestShip_Decide_VerbInHeredocBody` and `TestShip_Decide_WordBoundary_Devolve`.
- **An `evolve ship` allows only itself.** A ship verb elsewhere on the line, in a command substitution inside the ship's arguments, or after a quoted, commented or arithmetic `<<` is denied. Pinned by `TestShip_ANativeShipElsewhereInTheCommandAllowsNothingElse`, `TestShip_ACommandSubstitutionInsideANativeShipStillRuns`, `TestShip_OnlyAnUnquotedHeredocOpenerHidesTheLinesAfterIt`, `TestShip_AHeredocMarkerIsTheWholeShellWord` and `TestShip_GitGlobalOptionsDoNotHideTheSubcommand`; `TestShip_ANativeShipMayMentionShipVerbs` keeps real ship commands allowed.
- **Every decision judges the clean path.** `..` cannot reach a protected file past its fragment, nor leave `/tmp` or `<home>/.claude` while keeping their always-safe standing. Pinned by `TestRole_DeniesADotDotPathIntoTheControlPlane`, `TestRole_ADotDotOutOfAnAlwaysSafeDirIsNotAlwaysSafe` and `TestIsProtectedSurface_JudgesTheCleanPath`.
- **A doc move is a deletion unless it lands under `docs/`.** `knowledge-base/` is not a destination: its `research/` subtree is retired and `cycles/` is runtime state. Pinned by `TestDocDelete_DeniesMvToLegacyArchiveHome`, `TestDocDelete_DeniesMvOutOfDocs` and `TestDocDelete_AllowsConsolidationIntoDocs`.
- **A guard decides on its own run's state.** Pinned by `TestRoleAndPhaseGuards_ReadOwnRunState`, which also checks the global view would have denied.
- **The suite is hermetic because the guards read no environment.** A guard's decision comes from its constructor arguments and cycle state; the one read is `$HOME`, taken once by `NewRole`. No shell the suite runs from can turn a deny into an allow. Pinned by `TestGuards_ReadNoEnvironmentButHome`, an AST scan of the package's non-test files. Role fixtures use non-`/tmp` paths such as `/work/wt/cycle-20`, because on Linux `t.TempDir()` sits under `/tmp`, where the always-safe rule decides before cycle state is read. A fixture whose workspace must not exist on disk serves its cycle state from the `cycleStateOnly` stub, since `WriteCycleState` mirrors run state into the workspace.

## Findings

- **Cycle 20, flag-campaign-10** ([ADR-0064](../adr/0064-pipeline-integrity-boundary.md)): a build agent edited `go/acs/regression/flagreaders/readers_test.go` and the registry SSOT to bless its own split-const dodge, and the audit approved the self-edit. The role guard then let build write anything under the worktree. That produced the manifest and the in-cycle deny with alarm. The same change closed four review findings: C1 (the global `settings.json` sat under the always-safe home rule; the id survives in `TestRole_C1_DeniesGlobalSettingsUnsetHome`), H2 (a bypass of a protected path must alarm), M1 (case-insensitive filesystems) and M2 (`.evolve/policy.json` overrides gate defaults, so it is protected).
- **The L4 architecture review (2026-07-16)** turned the fragment literal into the exported manifest, grew the perimeter to the gate-shaped surfaces the first list missed, and added the by-name tripwire under `go/acs/regression/protectedsurface`.
- **The disposition gate** was enrolled by the operator during the cycle-1034 salvage ([ADR-0074](../adr/0074-typed-signal-contracts-routing-authority.md) S2): it grades the retro that grades failed cycles, so a cycle able to edit it could route its own failure classification.
- **PR #549**, a decomposition slice, moved five explanation-lifecycle call sites out of protected files into unprotected ones: `cyclerun_postreview.go`, `resume_execution.go`, `resume_bootstrap.go`, `phases/audit/classification.go` and `phases/runner/dispatch.go`. The manifest and the four pin tables had drifted apart. The fix added the rows and the call-site scanner, which derives its vocabulary so no fifth hand list can drift. Two architecture-review rounds on 2026-09-12 added gate entry points to the vocabulary (`verifyExplanationDocumentation`, wired by struct-literal value in `audit.go`, was invisible), struct-literal values, the method exclusion, the enforced alias precondition, the derivation-source floors and the `DocumentPath` exclusion.
- **The architecture review of 2026-09-01** found `CycleBinding.ContractVersion == 0` meant both "legacy cycle" and "a caller dropped the field". Only the host activation marker tells them apart. Ship checked it inline, audit not at all, so version 0 silently disabled audit's explanation gate. Both now call `explanationdocs.CrossCheckActivation`. The same review found the explanation-review contract stated once per phase gate with nothing binding the copies, which became `ValidateReviewedHandoff`.
- **Cycles 1036, 1041 and 1042**: `role.go`'s header documented a retro lessons allowance that `Decide` never implemented, so retros could not persist lesson YAMLs and learning durability broke silently. The ACS suites `go/acs/cycle1036`, `go/acs/cycle1041` and `go/acs/cycle1042` carry the behavioral contract under `-tags acs`; `role_lessons_test.go` keeps the crux in the default run. `go/acs/cycle1036` reads `role.go` and requires the text `.evolve/instincts/lessons`.
- **PR #351**: a lessons test built on `t.TempDir()` passed on macOS and failed the Ubuntu job, because on Linux the path rode the `/tmp` rule. Role fixtures use fixed non-`/tmp` paths since.
- **The tdd worktree allowance**: only `build` once got the worktree allowance, so tdd's RED tests were denied and the phase exited 81. The allowance now follows `core.WorktreePhase`.
- **`guards-role-hermetic-home`** ([change log 2026-07-30](../../operations/change-log-2026-07-30.md)): the filed escape did not exist, but `isAlwaysSafe` read `$HOME` raw and the test helper fell back to `/tmp`, so every `$HOME/.claude` assertion exercised the `/tmp` rule. Home is now injected at the composition root.
- **The Local Hero `TestMain`** ([testing-strategy.md](../testing-strategy.md)): an operator shell exporting `EVOLVE_BYPASS_SHIP_GATE=1` made every deny test fail open locally while CI stayed green. The guards have since moved to constructor bypass (`go/acs/cycle31`, `go/acs/cycle32`) and read none of these variables.
- **CB.4** ([ADR-0049](../adr/0049-concurrent-multi-cycle-execution.md)): under concurrent runs the host-global cycle state can hold another run's phase, so a guard reading it would deny a build write in the lane's own worktree. The worktree symlink to `run.json` closed that.
- **F29** ([verification wave findings](../../research/verification-wave-findings-2026-09-14.md)): with membership alone, an item declaring `go/internal/core/` and `go/internal/phases/runner/` reached a lane four times (cycles 1646, 1651, 1654 and 1656), and triage's breaker refused its card each time. That produced `IsProtectedScope` and the slashless-directory membership fix.
- **F37** ([incident](../../incidents/2026-09-26-lane-edited-the-control-plane-through-a-shell-tool.md)): a builder rewrote the protected `core/cyclerun.go` through a shell tool. The role guard sees only Edit and Write, so the boundary's question is now also asked by the build floor, which injects `IsProtectedSurface`.
- **ADR-0075**: `evolve guard phase` was wired only under the `Bash` matcher, so its one real branch never fired. It is now wired to `Agent|Task`.
- **v11.7.5 to v11.8.3** ([phase5-audit.md](../phase5-audit.md)): the Go port of the ship gate lacked the bash heredoc strip, so commit bodies that described `git push` were denied.
- **The 2026-08-05 doc-root consolidation** moved the archive home to `docs/private/research/archived-YYYY-MM-DD/` and retired `knowledge-base/research/` as a destination.
- **Cycle 1705** ([incident](../../incidents/2026-09-26-the-doc-guard-sent-a-draft-where-the-predicate-gate-refuses-it.md)):
  - A Build retracting its own never-committed explanation draft was denied both `rm` and a move out of `docs/`. The deny message prescribed a plain `mv` into the archive home, which left the draft untracked in the worktree.
  - The host predicate gate then refused the untracked file and forced FAIL over the auditor's PASS.
  - `docdelete` now allows exactly one removal: the active cycle's own never-committed explanation document, named by the host. It advises `git mv` for committed content. A general "never committed" allowance was reviewed and dropped: an untracked symlinked directory and `git rm ':(top)…'` both reached committed files through it.
- **`guards-path-traversal-and-ship-bypass`** (P1, found 2026-09-26 by reading the code during comment-reduction batch 19):
  - Neither the surface normalizer nor the always-safe check cleaned its path. `<worktree>/go/internal/core/../guards/role.go` missed the `/go/internal/guards/` fragment, and `isUnderDir` (which does clean) placed it in the worktree, so a build or tdd Write reached a guard. `/tmp/../x` counted as always-safe.
  - The ship guard allowed a whole line whenever `evolve ship` or `ship.sh` appeared anywhere in it, so `git push origin main; echo evolve ship` passed. A quoted `'<<EOF'`, a here-string `<<<` and an arithmetic `$((x<<y))` each opened a false heredoc that hid the next line from the verb check, and `git -C . push` never matched the verb pattern.
  - The fix cleans at both boundaries and replaces the line-based heredoc stripper with the per-command scanner. It also drops the `ship.sh` allowance: `scripts/lifecycle/ship.sh` no longer exists, and an allowance keyed to a path an agent can write is itself a bypass.
  - Review of the fix found one more way past, older than it: the heredoc marker was read with an identifier regex, so `<<EOF-MARKER` waited for a line `EOF` that never came and hid everything after the real close, a `git push` included. The old line-based stripper had the same regex. The marker is now the whole shell word after quote removal (`TestShip_AHeredocMarkerIsTheWholeShellWord`).
  - Three tests had passed for the wrong reason and were rewritten: `TestRole_BuilderWritesInWorktree` and `TestRole_AuditPhaseRestricted` sat under `/tmp`, and `TestShip_Decide_VerbInHeredocBody` ran `evolve ship`, whose substring allowance decided it. Each rule was mutation-checked: removing it turns its named test red.
- **The quota guard never denied, and is removed** (2026-09-26, part of `guards-path-traversal-and-ship-bypass`).
  - `evolve guard quota` built a fresh `Quota` for each hook call, so its in-memory counters never outlived one call. It keyed them on an `agent` field that no Claude Code tool input carries.
  - Its hook matched `WebSearch|WebFetch|Bash`, so it started a process and read `policy.json` on every Bash call for nothing.
  - The guard, its hook entry, its `guards.log` tag and `workflow.allow_deep_research` are gone. `TestHookWiring_EveryWiredGuardIsAGuardTheBinaryBuilds` (guardcmd) keeps the hook wiring and the binary in step.
  - The old `TestMain` also went: it unset three `EVOLVE_BYPASS_*` variables that nothing reads, and `testing-strategy.md` counted five.
