Model routing

How each phase picks a CLI and model — and what happens when the pick fails.

How it works today

  • One routing table decides every dispatch (ADR-0119). The cli_routing block in .evolve/policy.json has the keys clis, default, agents, tiers and floors. cliroute.Compile (go/internal/cliroute/compile.go) compiles it once at start, and every launch path asks Router.Resolve (cliroute.go). A launch with no root router refuses a declared table (RefuseLaunchRouter, router.go).
  • The table has one writer: evolve cli-routing init|set|unset|migrate. Each write compiles the merged file before an atomic write. The verb refuses inside a phase pane or while a run lease is live. While a loop lane is live, the verb queues the request in .evolve/queue/ when the policy key isolation.i15.stage is enforce, and the next wave boundary applies it (CHANGELOG, X17c). evolve cli-routing explain <agent> prints the chain of an agent. The chain it prints can differ from the checked-in order while a bench reorders the chain.
  • The checked-in table: clis and default are [agy, agy-claude, claude]. A balanced phase runs agy-tmux (Gemini 3.8 Flash High) first. tiers.deep lists the same three families and has share_pct: 50: the first family of the chain takes half of the deep seats by budget, and the next family takes the others. A deep seat on an agy chain runs Gemini 4 Argon (Medium) first. tiers.top is [agy-claude, claude]. A top seat runs agy-claude-tmux (Claude Opus 5.5 Medium in the manifest), then claude-tmux (opus). Codex is in no chain: only --bypass-policy reaches it.
  • The Claude floor is data: the key cli_routing.floors.claude in policy.json lists the agents that admit only the claude family. They are auditor, adversarial-review, tdd-engineer, spec-verifier, spec-verify and code-reviewer (Table.allowed reads the floors, cliroute/table.go). Thus these agents run on Claude Code only. No Go constant holds this list.
  • Tier vocabulary is fast | balanced | deep | top (modelcatalog.CanonicalTiers, go/internal/modelcatalog/refresh.go). Profiles speak tiers, and the model_tier_map of each CLI manifest gives the concrete model. The live model catalog overlays the manifest defaults at load.
  • The fallback chain walks on six exit codes (defaultFallbackOnExit, go/internal/llmroute/llmroute.go): {80, 81, 85, 87, 124, 127}. They mean, in order: REPL boot timeout, artifact timeout, unknown prompt or exhausted CLI, model mismatch, command timeout and absent binary (go/internal/bridge/exitcodes.go). agy-claude-tmux reads the model label of the footer after the REPL boots. It exits 87 if the label is not in the claude family, or if no label shows within label_wait_s. Exit 87 is a trigger, so the bridge then walks the chain to claude-tmux.
  • Inside one launch, the resolver order stays (llmroute.Resolve, llmroute.go): the profile and the routing table give the CLI, and the profile tier gives the model. The env name EVOLVE_CLI is still read there as a fallback. The project rule says that an operator setting lives in policy.json and a bypass is a CLI parameter; this page does not verify that EVOLVE_<AGENT>_CLI still works. With a table, evolve loop and evolve cycle run exit 3 (refused) before any dispatch if the routing table refuses the launch (CHANGELOG, X17b).
  • Benches reorder, never veto (llmroute.go): a quota or boot-timeout bench demotes a candidate in the chain. If all candidates are benched, the least recently benched candidate goes first.
  • The clamp and the advisor (go/internal/router/model_routing_clamp.go): the clamp validates every {CLI, tier} that the advisor proposes against allowed_clis, the tier envelopes and the live catalog. A tier below the floor clamps up. A profile that declares no envelope gets the universal envelope {balanced, top}. The advisor walks the chain of the table with Decision.WalkAt (cliroute.go): the first unbenched CLI that the tier permits leads.
  • Every decision is an artifact: routing-decision-N.json per decision, routing-plan.json per cycle — replayable with evolve routing.

How it got built

ADR-0022 added the manifest realization. ADR-0024 and ADR-0052 added advisory routing and the clamps. Cycle 436 added the per-phase {cli, tier} plans and the clamp, and cycle 480 added the universal envelope floor. In October 2026, ADR-0119 added the one routing table in three steps. L1a built the resolver, and L1b sent every launch path through it. L2 made the operator’s table live. Later work moved the Claude floor into cli_routing.floors, added the deep-tier share (share_pct) and moved the deep seat on agy to Gemini 4 Argon.

A permanent rule of the operator says that profiles name tiers, not models, and that any CLI must run any phase with any model. The clamp and the manifest layers apply this rule.
