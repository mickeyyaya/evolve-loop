## Design Decisions
Each helper stays in its origin file, next to its caller, so comment moves stay within one file. None of the new helpers is exported, and none has a doc comment, because the comment contract forbids adding comment lines. The simulator steps are `*Inputs` methods, like the existing artifact writers, so the defaults `Run` applies to its local copy are the ones every step sees. Each step still writes its own log lines and returns the exit code, which keeps the log strings verbatim. `aggregator` replaces the `pkgs` map and `get` closure pair because `observe` needs both. It also collects `tests`, which it would otherwise need a pointer to a slice for. The characterization tests are adapted from the TDD phase's throwaway kill probes and renamed after the behavior each one pins. They live in new files because the baseline `_test.go` files are frozen.
