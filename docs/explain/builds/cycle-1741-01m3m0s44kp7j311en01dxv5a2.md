## Design Decisions
Each helper stays in its origin file, next to its caller, so comment moves stay within one file. None of the new helpers is exported, and none has a doc comment, because the package comment contract forbids adding comment lines. `ClassifyOutcome` keeps the deferred and explained-abort scans as two separate loops, because merging them would let an earlier explained abort outrank a later quota defer. The characterization tests are the TDD phase's overlay kill probes, with the `TestKillProof_` prefix dropped so each test is named after the function it pins. They are in new files because the baseline `_test.go` files are frozen.
