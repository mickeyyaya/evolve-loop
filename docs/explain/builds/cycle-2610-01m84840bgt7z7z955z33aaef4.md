# Build Explanation — Cycle 2610

## Build Binding
- Cycle: 2610
- Base SHA: a099157d14664c4483d0db2009b6551b6ded79d6

## Summary
Docs-only pull requests and pushes now run only the Go tests that read the changed doc paths over an event-neutral commit range.
The full Go suite and plugin validation stay skipped on the docs-only route.

## Rationale
Docs-only pull requests previously skipped all Go tests, so a broken doc link or missing section failed first on main.
Selecting tests in Go avoids shell duplication and keeps selection exact to each changed path.

## Design Decisions
- `docstests.Select` combines `repocontract.DataFileReads()` with an AST scan of untagged `*_test.go` files instead of calling `repocontract.ByNameTestsFor`.
- `ci docs-tests` stays outside the protected `agentclass` table and core-verb JSON contract, matching `ci watch` and `ci telemetry`.
- `.github/workflows/required.yml` keeps the `changes` routing outputs unchanged so `mergewindow` classification stays intact.

## Verification
Unit tests, integration tests, CLI contract tests, STE lint, and all 20 cycle 2610 ACS predicates pass after the final edit.

## Compatibility
Code pull requests and unread doc changes retain their prior routing behavior, and `evolve ci` subcommands keep their existing contracts.

## Limitations
The AST selector resolves string literals, package constants, package variables, and same-package helper calls; dynamic path construction outside `DataFileReads()` is not selected.
