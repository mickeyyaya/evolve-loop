## Summary
The signal registry now holds the ten convergence codes that the decision package writes. The new verb `evolve convergence metrics` prints the rounds to land, the deferred-then-closed share and the falsification drop rate.

## Rationale
The package already wrote these codes in its reasons, but the registry did not list them, so the generated code table was incomplete. The readouts of plan component V8 need a pure function over rounds files. A pure function keeps the verb read-only and easy to cover at 100%.

## Design Decisions
Codes are registered in the signal center, as the CI and loop codes are, so that the registry test in that package can see them. A deferral counts as closed only when a later round lists the same id as FIXED. A finding counts once in the falsification rate, by its latest result. The two JSON encoders became one helper, which removes duplicated code.

## Verification

## Compatibility
The `decide` verb output and its exit codes do not change. The new codes add rows to the table and change no existing code.

## Limitations
The verb reads rounds files only; it does not scan the run history for them.
