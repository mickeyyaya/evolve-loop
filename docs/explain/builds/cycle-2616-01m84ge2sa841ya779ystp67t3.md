# Build Explanation — Cycle 2616

## Build Binding
- Cycle: 2616
- Base SHA: 2c8fc5fe94f930b3457ee2f38213adc5bc23897f

## Summary
Test tmux servers of dead test binaries now stop on the next test binary start and during `evolve gc`. The orphan socket matcher now accepts suffixed test sockets, and `tmuxtest` reaps dead-owner test servers before it starts a fresh server.

## Rationale
Test helpers such as `ownTmuxServer` create suffixed sockets (`evolve-bridge-t<pid>-<suffix>`). Previously, `ownerPidSocketRE` accepted only `-own`, so `evolve gc` skipped `-hermetic`, `-secret`, `-failstart`, `-twofp`, `-earlykill`, `-notmine`, and `-panelost`. In addition, `tmuxtest` lacked a start-time reap of dead-owner test servers, and `gc_reapers_fake_test.go` replaced the `sockets` reaper with a no-op in `cmd/evolve` tests.

## Changed Areas
- `go/internal/swarm/reap_orphans.go` — widens `ownerPidSocketRE` to match any `-<suffix>` (`-[A-Za-z0-9_-]+`) after `-p<pid>` or `-t<pid>` while keeping the owner PID in group 1.
- `go/internal/tmuxtest/tmuxtest.go` — adds `listTestSockets` and `reapDeadTestServers` with injectable `testSocketLister`, `pidAlive`, and `serverKiller` seams so `tmuxtest` reaps dead `evolve-bridge-t*` servers without touching `evolve-bridge-p*` loop sockets.
- `go/internal/tmuxtest/serve_tmux.go` — calls `reapDeadTestServers` before `StartServer` when `tmux` is on `PATH`.
- `docs/architecture/packages/internal-swarm.md` — updates the `ownerPidSocketRE` invariant to document suffixed socket reaping.
- `docs/architecture/packages/internal-tmuxtest.md` — documents the start-time `reapDeadTestServers` step and its fake-process-table tests.

## Design Decisions
We chose one shared owner-PID pattern in `ownerPidSocketRE` and reused `swarm.ReapOrphanSockets` inside `tmuxtest` rather than writing a second regex or reaper in `tmuxtest`. We filtered `listTestSockets` to `evolve-bridge-t` so a test binary never stops a loop `evolve-bridge-p<pid>` server. In `cmd/evolve` tests, we switched `gc_reapers_fake_test.go` to `swarm.ExecReapOrphanSockets` so `TestGCSockets_*` exercises the real socket reaper inside each test's isolated `TMUX_TMPDIR`.

## Verification
Cycle 2616 ACS predicates, `internal/swarm`, `internal/tmuxtest` (default and `notmux`), `cmd/evolve`, and `ste-lint --strict` verify the dry-run listing, apply cleanup, start-time reap, and fake-process-table isolation.

## Compatibility
Public CLI flags, socket naming (`DeriveTestSocket`, `DeriveRunSocket`), and `evolve gc` output format stay unchanged.

## Limitations
Start-time reap in `tmuxtest` runs only in the `!notmux` build when `tmux` is on `PATH` and targets sockets in the active `TMUX_TMPDIR`.
