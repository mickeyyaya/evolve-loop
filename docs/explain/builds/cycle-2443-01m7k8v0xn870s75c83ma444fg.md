# Build Explanation — Cycle 2443

## Build Binding
- Cycle: 2443
- Base SHA: d5f670867399c94f855855482b1094e18be8744a

## Summary
The `SIGNAL_EXPECTED_ABSENT` warning now names the open start. It gives the cycle, the phase, the run id and the start time in its reason and its fields.

## Rationale
A warning that names only a pair and a key forces the operator to search the stream for the stalled stage. The start event already holds the identity, so the warning copies it.

## Changed Areas
- `go/internal/signalcenter/expected.go` — `absentEvent` copies the cycle, phase and run id of the start into the reason, the fields and the event. A wave start has no cycle, so it omits the cycle.
- `go/internal/signalcenter/expected_test.go` — adds one test for a phase warning and one test for a wave warning.
- `docs/architecture/signal-center-design.md` — section 8.1 states which identity the warning carries.
- `docs/architecture/packages/internal-signalcenter.md` — the package note states the same identity.
- `docs/architecture/signal-codes.md` — the code entry lists the new fields.
- `.evolve/evals/expected-signal-warning-names-its-cycle-and-phase.md` — the eval of the task.

## Design Decisions
The run id comes from `Event.RunID`, and from `Fields["run_id"]` when the event field is empty. The wave pair therefore keeps its run id with no cycle. No new key or flag is added.

## Verification
The twelve ACS predicates of cycle 2443 and the `internal/signalcenter` tests pass. `gofmt`, `go vet` and `ste-lint` report nothing.

## Compatibility
Existing fields keep their names and values. The new fields and reason text are additive.

## Limitations
The warning names the start only. It does not name the last event of the stage.
