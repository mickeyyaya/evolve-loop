## Design Decisions
- `CLIFlags`, `GHIn`, and `PlaneLiveRuns` live in `go/cmd/evolve/cmdutil`. This avoids a new package and a copy in `main` and `landcmd`. One flag-parser struct serves both packages and their tests, with no import cycle.
- `Deps` uses an atomic pointer (`current`) in `landcmd/deps.go`, as `inboxcmd` does. `RefreshWorktree` falls back to `core.DerivedWorktree`. `NewSignalCenter` falls back to a nil center and a no-op close function when the seam is absent (`go/internal/cli/landcmd/deps.go:54-59`). A test that passes `Deps{}` fails only when a required host seam is absent.
- Integration tests that inspect `main` signal-center channels or run real derived-file generators stay in `main`. They drive `runPR` and `runCI` through the shims. Unit tests move to `landcmd`.

Other landing-adjacent verbs (`integration`, `ship`, `land`) remain in `go/cmd/evolve` for step 5 of the split plan.
