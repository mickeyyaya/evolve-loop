Trust kernel

Why the pipeline’s safety holds even in bypass-permissions mode: enforcement lives in OS-level hooks and the Go binary, not in prompts.

How it works today

  • Five dispatcher guards, plus the triage-floors check. evolve guard <name> reads the tool call as JSON on stdin and exits 0 (allow) or 2 (deny), logging byte-compatibly to .evolve/guards.log (go/internal/cli/guardcmd/guard.go). Guards: ship, phase, role, docdelete, chain. A separate subcommand runs triage-floors. The quota guard of the older design is gone from the dispatcher.
  • ship (go/internal/guards/ship.go): denies any Bash that runs git commit, git push or gh release create|edit unless it goes through evolve ship — heredoc bodies stripped first so payloads can’t smuggle verbs.
  • phase (go/internal/guards/phase.go): an Agent or Task call that starts a phase persona (evolve-*) is denied while a cycle runs, unless the call comes from inside a phase cell. Phase agents start through the native bridge.
  • role (go/internal/guards/role.go): Edit/Write must match the active phase’s allowlist — workspace, or the lane worktree for tdd/build. A narrow control-plane surface (integrity_surface.go) is denied to EVERY phase. It groups paths by guarantee class: guard, ship or commit gate, sandbox rule, ledger, policy parser, phase order, audit verdict, dispatch credential, kernel instruction and manifest.
  • Audit↔tree binding (go/internal/phases/ship/audit.go): a cycle ship requires the latest auditor ledger entry to match the exact tree — HEAD, sha256(git diff HEAD), artifact SHA, verdict PASS, EGPS red_count==0, ≤7 days old. Change anything after audit and ship refuses (AUDIT_BINDING_HEAD_MOVED is this working). When main moves, the orchestrator routes the cycle by the signal: an identity carry can re-bind the audit without an audit round, and otherwise the cycle returns to audit (go/internal/core/head_moved_rebind.go).
  • Hook wiring (.claude/settings.json): four PreToolUse hooks — ship and docdelete on Bash, phase on Agent|Task, role on Edit|Write — plus a PostToolUse postedit-validate and a Stop hook prune-ephemeral. Each PreToolUse hook resolves go/bin/evolve first, falling back to go/evolve.
The phase hook fires — the 2026-07 page recorded the phase hook as inert, because it sat under the Bash matcher while the guard inspected only Agent calls. Today the guard accepts Agent and Task (isSubagentTool) and .claude/settings.json wires it under Agent|Task. The hook is defence in depth: the in-process state machine (statemachine.go, SpineSatisfiedUpTo) holds the phase order for every CLI family.

How it got built

The control-plane boundary is ADR-0064, born from the cycle-20 breach where a build agent edited the gate that graded it. The bash→Go guard cutover (v11.4.0) preserved the log byte format. The guard set grew from three (v8.13.x) as research-quota (v10.16) and doc-deletion (v10.17) joined; the dispatcher today has five guards. cycle-243 taught why hooks carry a fallback binary path: deleting go/bin/evolve once silently disabled every guard — a failure mode that resurfaced 2026-07-12 (see ship & release).
