# Build Explanation — Cycle 2246

## Build Binding
- Cycle: 2246
- Base SHA: 9f4fc3396aec2e8d74bd35cace1ba96dd5583222

## Summary
A launch that exits 85 because the pane shows a quota wall now carries the signal BRIDGE_EXIT_QUOTA_WALL. Before this change it carried BRIDGE_EXIT_UNKNOWN_PROMPT, the same signal as a prompt that nobody recognised.

## Rationale
In wave 160 the cycles 2221 and 2222 met the weekly usage limit during the router dispatch. They sealed SKIPPED_UNKNOWN with the signal for an unknown prompt. The cause code already said rate_limit, but the signal hid it from the operator and from any consumer keyed on the signal. The classifier is the one place that knows both facts, so it names the quota there.

## Changed Areas
- `go/internal/bridge/launchoutcome/signal.go` — adds and registers the code BRIDGE_EXIT_QUOTA_WALL with the bridge module.
- `go/internal/bridge/launchoutcome/classify.go` — Classify sets the new signal for exit 85 with the cause rate_limit or exhausted. The exit code, the cause code and the transient flag do not change.
- `go/internal/bridge/launchoutcome/signal_test.go` — the registered-code count becomes 15 and a test pins the quota projection.
- `docs/architecture/signal-codes.md` — the generated registry table gains the new row.

## Design Decisions
The exit class table keeps one row per exit code. The new signal is a projection on the outcome, not a second row for exit 85. A second row breaks the rule that the signal name follows the row name. The quota causes are a small set in one map, so a new quota cause is one entry.

## Verification
The tests of the launchoutcome package pass, the signal-codes drift test passes, and the predicates TestC2246_001 and TestC2246_002 pass.

## Compatibility
The exit code, the cause code, the transient flag and the launch error text are unchanged. A consumer that matched BRIDGE_EXIT_UNKNOWN_PROMPT for a quota wall must now match BRIDGE_EXIT_QUOTA_WALL; the repository has no such consumer.

## Limitations
Acceptance criteria 1 and 2 (the cycle ends quota-paused, and cycle resume --all picks it up) need a change to the protected `go/internal/core/cyclerun.go`. This build does not change it; it is a console follow-up.
