# Persona ADRs

The files in this folder are the persona series. They are a different series from [the main ADRs](../architecture/adr/). The number 0005 names one decision here and another decision there.

Write "persona ADR-NNNN" to cite a file in this folder. An ADR number with no prefix means the main series ([ADR-0164](../architecture/adr/0164-all-decisions-serve-one-goal-and-one-amendment-resolves-their-conflicts.md), decision 2).
