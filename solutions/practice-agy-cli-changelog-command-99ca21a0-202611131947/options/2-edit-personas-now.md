# Option 2 — edit a persona now

All numbers cite `assumptions-and-evidence.md`.

## What changes, for whom

Change a core persona in `agents/` to use a 1.5.8 feature, such as the ACP context usage report (E1).

## Causal chain to the goal metric

A persona edit can only help if a line affects a persona rule. No line does (A3, E2). No chain to the metric exists.

## Quantified expected effect

Unknown. No measured baseline supports a gain (E3, E6).

## Cost and time to effect

One persona edit plus the D8 measure cycles (E3).

## Top two risks

1. The edit breaks the one-persona, baseline rule (E3), so a regression cannot be traced.
2. The persona serves other CLI families, and an agy-only edit can degrade them (A3).
