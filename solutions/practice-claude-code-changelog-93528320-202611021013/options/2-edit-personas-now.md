All numbers cite `assumptions-and-evidence.md`.

## What changes, for whom

Add a rule to two or more personas, for example a subagent effort rule and an `ultrathink` rule. The phases would follow the new text.

## Causal chain to the goal metric

New text would change phase behavior. The change cannot be judged, because M2 has not shipped (E3, A3).

## Quantified expected effect

No effect can be stated. The loop sets effort through routing (E4), so the rule would repeat a setting that exists.

## Cost and time to effect

10 + 10 cycles of measures per persona (E2). It breaks D7 when it touches more than one persona.

## Top two risks

1. A longer prompt, against the aim of ADR-0133. Detection: the M2 byte counts, once they exist.
2. A rule that duplicates the routing setting. Detection: the duplication review.
